메뉴바 메뉴 개편 기획

기획: 김기획 · 정리: ai-office · 2026-11-01 · 상태: 대표 결정 대기 · 코드는 아직 바꾸지 않았습니다
한눈에 보기
  • 지금 메뉴바 메뉴는 결재·자동결재·직원 목록 중심으로 잘 되어 있고, 4개 언어 문구도 모두 있습니다.
  • 최근 기능(업데이트 알림, 결재함·업무 보드 바로가기, 바탕화면 비서 켜고 끄기, 플랜 사용률)은 메뉴에 거의 없습니다.
  • ‘전체 멈추기’는 확인 창 없이 바로 모든 직원을 멈춥니다. 실수로 누르면 위험합니다.
  • 맥 화면 맨 위의 앱 메뉴(편집·보기 등)는 직접 만든 적이 없어서 Electron 기본 메뉴가 그대로 나옵니다. 코드에서 확인했습니다.
  • 권고: ‘꼭’ 4가지(A1~A4)를 먼저 하기. 작업 크기는 약 2~3일입니다.
사진에 대해: 실제 메뉴를 펼친 화면은 찍지 못했습니다. 화면 찍기 도구가 화면 전체를 찍고, 찍을 때마다 결재가 필요해서 개인 창이 함께 찍힐 수 있었기 때문입니다. 아래 메뉴 구성은 코드(trayMenu.ts)에서 읽은 것이라 실제 화면과 조금 다를 수 있습니다. 사진은 메뉴바 아이콘 원본만 넣었습니다.

최근 기능과 비교

기능지금 메뉴바판단
업데이트 알림없음. 새 버전이 나와도 메뉴바에서는 알 수 없음꼭
결재함대기 목록만 있고, 결재함 자체를 여는 항목은 없음보강
업무 보드‘할 일 추가(클립보드 글로)’만 있고, 보드 열기는 없음. 이름이 알아듣기 어려움보강
바탕화면 비서‘다시 불러오기’만 있고, 끄기·숨기기는 없음보강
⌘K 비서‘비서에게 말하기’는 있지만 단축키 표시가 없음작은 보강
플랜 사용률없음 (앱 위쪽 칩에만 있음)있으면 좋음
설정없음있으면 좋음
정리할 것눌러도 아무 일 없는 ‘AI Office’ 제목 줄, 자동결재 상태줄이 두 번 나옴, 이미 출시된 기능에 남은 ‘준비 중’ 문구정리

개선안

#개선대표님이 느끼는 변화위험크기
꼭 A1새 버전 알림 줄 + 아이콘 옆 작은 표시앱을 열지 않아도 업데이트를 알고 바로 설치누르면 설치가 시작되므로 확인을 한 번 받음0.5~1일
꼭 A2‘전체 멈추기’ 확인 창실수로 모든 작업이 끊기는 일을 막음자율 진행 중에는 확인 창을 띄울지 결정 필요0.5일
꼭 A3결재함·업무 보드·설정 바로가기메뉴바에서 원하는 화면으로 바로 이동낮음1일
꼭 A4죽은 줄·‘준비 중’ 정리, 쉬운 이름으로 바꾸기메뉴가 짧아지고 이해하기 쉬움낮음0.5일
좋음 B1맥 맨 위 앱 메뉴를 직접 구성 (5개 메뉴, 4개 언어, 단축키 표시, 개발자 도구 숨김)맥 기본 앱처럼 자연스러움복사·붙여넣기 단축키가 계속 되도록 지켜야 함1~1.5일
좋음 B2바탕화면 비서 보이기·숨기기비서를 숨길 수도 있음맥만 해당소
좋음 B3플랜 사용률 한 줄자리를 비우기 전에 남은 한도 확인메뉴가 한 줄 길어짐소~중
좋음 B4맥에서 ⌥+클릭으로 사무실 열기윈도우와 비슷하게 편해짐헷갈릴 수 있음소
좋음 B5결재·질문·외부 대기를 구분 표시하고, 상태 점 옆에 글자 쓰기숫자가 무엇을 뜻하는지 분명해짐낮음소
나중 C1~C4안내 다시 보기 메뉴, 상태별 아이콘 모양, 메뉴에서 바로 지시, 자주 쓰는 순 자동 정렬 — 효과가 적거나 다른 기능과 겹침

대표님이 정할 것

  1. 범위: ‘꼭’ 4가지만 할지, 맨 위 앱 메뉴(B1)까지 할지
    권고: A1~A4 먼저, B1은 그 뒤에 따로
  2. 업데이트 알림: 아이콘 옆에도 표시할지, 메뉴 안에서만 알릴지
    권고: 아이콘 옆 작은 표시 포함
  3. 전체 멈추기 확인 창: 항상 물을지, 자율 진행 중에는 묻지 않을지
    권고: 평소에는 묻고, 자율 진행 중에는 지금처럼 바로 멈춤
  4. 맥 아이콘 클릭: 지금처럼 메뉴만 열지, ⌥+클릭으로 사무실 열기를 더할지
    권고: 지금처럼 메뉴만
  5. 플랜 사용률을 메뉴바에 넣을지 (B3)
  6. 바로가기: 결재함·업무 보드·설정을 모두 넣을지, 자주 쓰는 것만 넣을지

확인한 것 · 못 한 것

  • 코드에서 직접 확인함: 앱 메뉴를 직접 만드는 코드(setApplicationMenu)가 없음, ‘준비 중’ 문구로 가는 분기가 trayMenu.ts에 남아 있음.
  • 못 한 것: 실제 메뉴를 펼친 화면을 보지 못했습니다. 맥 맨 위 앱 메뉴의 실제 항목도 앱을 띄워 봐야 압니다.
  • 개발 단계에서 확인할 것: 업데이트 상태를 메뉴에 전달하는 방법, 결재함·보드·설정 화면을 바로 여는 방법.
