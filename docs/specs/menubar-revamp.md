### 1-5. 화면 캡처
- **못 찍었습니다.** `capture_screen`은 화면 전체를 찍고 매번 대표 결재가 필요해서, 메뉴바만 찍어야 한다는 조건과 개인 창을 피한다는 조건을 지킬 수 없었습니다. 앱을 직접 띄워 메뉴를 열어 보는 확인도 하지 못했습니다. **위 구성도는 코드(`trayMenu.ts`)에서 읽은 것이며 실제 화면과 다를 수 있습니다.**
- 참고용 아이콘 파일: `/Users/joonyoung/ai-office/app/build/trayTemplate.png`, `/Users/joonyoung/ai-office/app/build/trayWin.png`. (사진 파일 새로 만든 것 없음)

### 1-6. 앱 윗부분 메뉴(맥 상단 메뉴줄)
- `Menu.setApplicationMenu`를 부르는 곳이 **저장소에 없습니다**(검색 결과 0건). 따라서 Electron **기본 메뉴**가 나옵니다.
- 예상되는 낡은 점(확인 필요, 실행 화면 미확인):
  - 기본 메뉴 제목·Help 항목이 영어 고정이라 한국어 앱 화면과 어긋남.
  - `Help` 아래 Electron 안내 링크가 앱과 무관한 곳으로 연결될 수 있음.
  - **앱 안의 기능(⌘K 비서, 업무 보드, 결재함, 설정, 업데이트 확인, 안내)이 메뉴에 없음.** 단축키도 메뉴에 표시되지 않아 발견하기 어려움.
  - `View` 메뉴의 개발자 도구·새로고침 항목이 일반 사용자에게 노출될 수 있음.
- 개선 방향: 직접 만든 **간소한 앱 메뉴**(AI Office·편집·보기·창·도움말 5개). 4개 언어 지원.

## 2. 최근 기능과 비교: 빠진 것·낡은 것

| 기능 | 메뉴바 상태 | 판단 |
|---|---|---|
| 업데이트 알림 | **없음.** 새 버전이 있어도 메뉴바에서는 알 수 없음(`updates.ts`는 상태를 가지고 있음) | **빠짐 · 꼭** |

| 업무 보드 | "할 일 추가(클립보드)"뿐. **보드 열기 없음**, 이름이 "클립보드 글로"라 처음 보면 무슨 뜻인지 모름 | 보강 |

| 플랜 사용률 | **없음.** 앱 상단 칩에만 있음. 한도가 얼마 남았는지 모르면 자동결재를 켜고 자리를 비우기 불안 | 있으면 좋음 |

| 설정 | **없음.** 앱 안 설정을 열려면 사무실을 열고 찾아야 함 | 있으면 좋음 |
| 아이콘 숫자 | 결재 외에도 질문·외부 대기를 합산. 의미가 헷갈릴 수 있음 | 유지, 메뉴 안에서 구분 표시 |

### 이제 필요 없거나 정리할 항목
- **"비서에게 말하기 (준비 중)"**(`tray.talkSecretarySoon`)와 **"📱 휴대폰 연결 · 준비 중"**(`tray.phoneSoon`): 비서와 휴대폰 연결이 이미 출시된 기능이면 "준비 중" 대체 문구는 쓰일 일이 없는 낡은 가지입니다. 실제로 이 가지로 가는 경우가 있는지 개발 확인 필요.
- **맨 위 "AI Office" 제목 줄**: 눌러도 되지 않는 죽은 줄. 버전·업데이트 상태를 보여 주는 줄로 바꾸면 쓸모가 생깁니다.
- **자동결재 상태줄이 메뉴에 두 번 나옴**: 부모 메뉴 이름과 하위 첫 줄이 똑같은 글자(`autoApproveLine`).
- **"위험 명령·푸시·외부 전송은 기다려요" 안내**: 안전 판정이 바뀌면(별도 검토 중 `auto-approve-allowlist-review.md`) 문구가 어긋날 수 있어 함께 점검.

## 5. 대표님이 정할 것
1. **범위**: "꼭" 4건(A1~A4)만 할지, 앱 윗부분 메뉴(B1)까지 함께 할지. *(권고: A1~A4 먼저, B1은 그 뒤 따로)*
2. **업데이트 알림**: 메뉴 맨 위에 **눈에 띄게**(아이콘 옆 표시 포함) 할지, 메뉴 안에서만 조용히 할지. *(권고: 아이콘 옆 작은 표시 포함)*
3. **"전체 멈추기" 확인 창**: 항상 물을지, 자율 진행 중에는 묻지 않을지. *(권고: 평소에는 묻고, 자율 진행 모드에서는 지금처럼 바로 멈춤)*
4. **맥에서 아이콘을 눌렀을 때**: 지금처럼 메뉴만(권고), 아니면 ⌥+클릭에 "사무실 열기"를 붙일지.
5. **플랜 사용률**을 메뉴바에 넣을지(B3). 메뉴가 한 줄 길어집니다.
6. **새 항목 노출**: 결재함·업무 보드·설정 바로가기를 모두 넣을지, 자주 쓰는 것만 넣을지.

## 6. 가정과 확인 필요
- 가정: 메뉴바 메뉴 구성은 코드에서 읽은 것이고, 실제 화면은 확인하지 못했습니다.
- 가정: 윗부분 메뉴가 Electron 기본이라는 판단은 `setApplicationMenu` 호출이 없다는 검색 결과에 근거합니다. 실제 항목은 앱을 띄워 보아야 압니다.
- 확인 필요: "준비 중" 대체 문구가 실제로 쓰이는 경우가 있는지(개발).
- 확인 필요: 업데이트 상태를 메뉴에 연결할 때 `updates.ts`의 상태 변경 알림 구조(개발).
- 확인 필요: 앱 안 결재함·업무 보드·설정 화면을 값 하나로 바로 여는 방법이 이미 있는지(개발 검토 시 `open(staffId?)` 확장 필요 여부).
