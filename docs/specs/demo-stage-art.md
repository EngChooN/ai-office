# 데모데이 발표장: 무대 아트와 연출 명세 (이디자)

이 문서는 사무실 아이소 그림체(A 파스텔, `office-iso-art.md`)를 그대로 쓰는 발표장 화면의 명세입니다. 그림은 모두 `app/src/renderer/map/iso/isoArt.ts`의 `artStage*` 함수가 그립니다. 장면(Phaser) 코드는 아래 순서·크기·시간을 따르면 됩니다.

- 단위: 칸(gx, gy), 아트 px(1 아트 px = 화면 2px, `PIXEL`)
- z는 바닥 위 높이(아트 px)입니다.

## 1. 배치 (`STAGE`, 칸 10 × 8)

```
 gy 0 ┌ 뒤 벽: 막 장식(z54~63) · 대형 스크린(x 2.5~7.5, z 20~52) ┐
      │ 막L(x1)                                        막R(x8.55)│
      │ ┌──────────── 무대 x1~9 · y0~3 · 높이 8 ─────────────┐  │
      │ │  대기(2.4,2.3)            연단(5.95,1.5) 발표자(7.0,1.35)│
 gy 3 │ └계단(x1.2~2.2, y3~3.7)── 바닥 조명 ───────────────────┘  │
 gy 4 │ 통로│ 좌석 줄 6석 (x2~8)                           │통로   │
 gy 5 │ 러너│ 좌석 줄 6석                                  │러너   │
 gy 6 │     │ 좌석 줄 6석                                  │       │
 gy 7 │   18석이 넘으면 서서 보는 줄 (gy 7.4, 7명씩)                │
      └───────────────────────────────────────────────────────────┘
```

- **객석:** 기존 강당 좌석 줄 `artHallRow(role, 6)`(키 `meet-hall-6-{seat|back}`)을 gy 4·5·6에 gx 2부터 놓습니다.
- **자리 배정:** `stageSeats(n)`이 가운데 자리부터 채웁니다. 순서는 열 2,3,1,4,0,5입니다.
  - 앉은 직원은 `sit`·`back` 자세로 z = `HALL_SIT_Z`(9)에 둡니다.
  - 18명을 넘으면 맨 뒤에 `stand`·`back` 자세로 세웁니다.
  - 데모데이 발표자는 최대 8명(`DEMO_LINES_MAX`)이라 보통 1~2줄이면 됩니다.
- **걸어 나오기:** 자기 자리 → 가까운 통로(gx 1.5, 같은 gy) → `STAGE.stairs` 네 점(z 0→3→6→8) → `STAGE.waiting` → `STAGE.speaker` 순서로 이동합니다.
  - 걷는 동안은 `walk1`/`walk2`를 0.18초마다 바꾸고, 한 칸에 0.28초가 걸립니다.
  - 발표자는 `front` 방향을 보고, 돌아갈 때는 같은 길을 거꾸로 갑니다.

## 2. 레이어 순서 (뒤 → 앞)

| 층 | 무엇 | 텍스처 키 | 깊이 |
|---|---|---|---|
| 0 | 배경: 벽·카펫·막 장식·꺼진 스크린 | `stage-hall` (`artStageHall`) | 고정 0 |
| 1 | 슬라이드(작업물 사진 / 업무 제목 카드) | 장면이 그림 | 고정 1 |
| 2 | 객석 어둡게 덮는 막 (발표 중만) | 사각형 `STAGE_COLORS.dim` α0.35 | 고정 2 (무대 영역은 비움) |
| 3 | 조각·좌석 줄·직원 | `stage-{platform\|curtainL\|curtainR\|lectern}` · `meet-hall-6-*` · 직원 | 기존 아이소 깊이 정렬(조각 `at`+`box`) |
| 4 | 무대 조명 | `stage-spot` (ADD 섞기, α0.9) | 발표자 깊이 + 0.01 |
| 5 | 이펙트: 박수 손·별·하트·왕관·트로피·꽃가루 | `stage-fx-*` | 55000 (레벨업 연출과 같은 층) |
| 6 | 말풍선(타이핑) · 대표 반응 버튼 | DOM/React 겹침 | 화면 위 |
| 7 | 전환 막 | `stage-curtain-{w}x{h}` | 맨 위 |

- **무대 조각:** 무대(`platform`)는 바닥보다 위, 무대 위 직원보다 뒤에 그립니다. `box`가 3칸 깊이라 기존 정렬로 처리됩니다.
- **연단:** 발표자(7.0, 1.35)의 왼쪽 앞에 있어서 발표자 몸 전체가 보입니다.
- **슬라이드:** `stageScreenQuad()`가 스크린 안쪽 네 꼭짓점을 아트 px로 돌려줍니다. 순서는 왼위·오위·오아래·왼아래이고, 배경 텍스처 기준입니다.
  - 가로 변은 1px 갈 때마다 0.5px씩 내려가는 기울기입니다.
  - 캔버스에 `setTransform((x1-x0)/W, (y1-y0)/W, 0, (y3-y0)/H, x0, y0)`로 슬라이드(W×H)를 그린 뒤 텍스처로 올리면 됩니다. 값에는 `PIXEL`을 곱합니다.
  - 사진은 비율을 유지한 채 가운데를 잘라 채웁니다(cover). 사진이 없으면 연한 바탕 `#eef6fb`에 위쪽 20% 주황 띠(`K.orange`)를 깔고, 업무 제목과 직원 이름을 씁니다.

## 4. 조명

- 발표가 시작되면 객석 막(층 2)을 0.4초 동안 α0 → 0.35로 올리고, 조명(층 4)을 발표자 발밑(`o`)에 0.3초 페이드인으로 켭니다.
- 조명은 2.4초 주기로 α0.8↔0.95 숨쉬기를 반복합니다.
- 발표가 끝나면 둘 다 0.3초 동안 페이드아웃합니다.
- 바닥 조명(무대 앞단 노란 램프 8개)과 벽등은 배경에 그려져 있어 따로 켤 필요가 없습니다.

## 5. 이펙트

| 반응 | 그림 | 연출 |
|---|---|---|
| 발표 끝 박수(자동) | `stage-fx-clap0/1` 18×16 | 앉은 직원 머리 위(z+24)에 직원마다 0~0.3초 늦게 등장합니다. 0.12초마다 0↔1을 바꾸며 1.6초 동안 보이고, 위로 6px 떠오르며 사라집니다. 별 3개가 무대 앞에서 튑니다. |
| 대표 👏 박수 | 위와 같음 + 별 | 객석 전체가 박수 칩니다. 발표자 머리 위에 `stage-fx-star` 5개가 부채꼴(±60°)로 18px 튀어 오르고 0.8초 뒤 사라집니다. 꽃가루 20개를 뿌립니다. |
| 대표 🏆 MVP | `stage-fx-trophy` 20×24 · `stage-fx-crown` 11×5 | 트로피가 스크린 앞 가운데에 0→1.2배(easeOutBack 0.5초)로 나타나고 1.5초 동안 머문 뒤, 발표자 머리 쪽으로 0.6초 동안 줄며 날아갑니다. 도착하면 왕관이 머리 위(z+28)에 붙어 그 데모데이 동안 남습니다. 꽃가루 60개가 화면 위에서 2초 동안 내립니다. 객석 박수도 함께 나옵니다. |
| 대표 💬 한마디 | `stage-fx-heart` 9×8 | 대표 말을 발표자 머리 위에 흰 말풍선(테두리 `K.orange`)으로 2.5초 동안 띄웁니다. 하트 3개가 0.15초 간격으로 위로 24px 떠오르며 사라집니다. |

- **꽃가루:** 2×1 또는 1×2 아트 px 사각형입니다. 아래로 40~70 px/s, 좌우 ±10px 사인 흔들림, 1초에 1바퀴 회전합니다.
- **화면 흔들림:** 쓰지 않습니다. 오래 보는 화면이라 멀미가 날 수 있습니다.
- **동작 줄이기:** 운영체제의 '동작 줄이기'가 켜져 있으면 꽃가루와 튀는 동작을 빼고 페이드만 남깁니다.

## 6. 이동 전환 (사무실 ↔ 발표장)

1. **사무실 → 발표장 (1.6초)**
   - 사무실 카메라가 회의실 쪽으로 0.5초 동안 1.0→1.15배 줌하고, 동시에 `dim`으로 페이드합니다.
   - 막 두 폭(`artStageCurtainPanel(화면 폭/2/PIXEL + 8, 화면 높이/PIXEL)`)이 양옆에서 0.4초에 걸쳐 닫힙니다.
   - 가운데에 "🎤 데모데이" 글자를 0.3초 동안 보여 줍니다.
   - 발표장으로 바꾼 뒤 막이 0.5초 동안 양옆으로 열립니다(easeInOut). 객석은 이미 앉아 있는 상태입니다.
2. **발표장 → 사무실 (0.8초):** 막 없이 `dim` 페이드아웃 0.3초, 사무실 페이드인 0.5초입니다.
3. **마지막 단체 인사:** 리드 총평이 끝나면 무대 위에 발표자 전원이 대기 자리부터 한 줄로 섭니다. `front` 자세로 2px 내려갔다 오는 인사를 2번 하고, 객석 박수와 꽃가루 30개가 나옵니다. 그다음 막이 닫히며 끝납니다.

## 7. 그림 함수 목록 (`isoArt.ts`)

| 함수 / 상수 | 돌려주는 것 | 비고 |
|---|---|---|
| `STAGE` | 배치 상수(칸) | 크기 10×8, 벽 64, 무대·발표자·대기·계단·좌석 줄 |
| `STAGE_COLORS`, `STAGE_CONFETTI` | 색 | 장면 사각형·글자 색은 여기서 가져옵니다 |
| `artStageHall()` | `{ cv, o }` | 배경 한 장. `o`는 발표장 (0,0) 칸 꼭짓점입니다 |
| `stageScreenQuad()` | 네 꼭짓점(아트 px) | 슬라이드를 기울여 얹을 자리 |
| `artStagePieces()` | `StagePiece[]` (`ItemPixels` + `key`·`at`) | 무대(계단·바닥 조명 포함), 막 왼쪽·오른쪽, 연단 |
| `stageSeats(n)` | `{ gx, gy, z, isSeated }[]` | 가운데부터 채우고, 18명을 넘으면 서서 봅니다 |
| `artStageSpot()` | `{ cv, o }` | 반투명 조명(ADD). `o`는 발밑입니다 |
| `artStageTrophy()` | `Cv` 20×24 | 아래 가운데가 바닥 |
| `artStageClap(0\|1)` | `Cv` 18×16 | 벌린 손 / 마주친 손 + 반짝 선 |
| `artStageHeart()` · `artStageStar()` · `artStageCrown()` | `Cv` 11×10 · 11×11 · 13×7 | 외곽선 포함 |
| `artStageCurtainPanel(w, h)` | `Cv` w×h | 전환 막 한 폭. 주름 10px, 아래 금 술 5px |

- 이미 있는 것을 다시 씁니다: `artHallRow`·`hallRowKey`·`HALL_SIT_Z`(좌석), `artPerson`·`drawPersonSet`·`artPersonShadow`(직원).
- 캔버스로 바꿀 때는 `toCanvas(cv)`를 쓰고, 앵커는 `o × PIXEL`입니다.
