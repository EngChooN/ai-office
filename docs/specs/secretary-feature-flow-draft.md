# feature-flow 통합 매뉴얼 본문 초안 (작은·보통·큰 → 하나)

실제 저장은 비서의 비교 카드 기능이 완성된 뒤 QA에서 비서를 통해 해 봐요. 이 문서는 **저장할 본문 초안**이에요. 기존 `~/.claude/skills/feature-flow-small|medium|large`(개인 폴더, `kind: process`)의 단계·지시문을 그대로 살려 합쳤어요.

## 저장 정보 (비서에게 시킬 때 쓸 값)
- 이름: `feature-flow`
- 설명: `기능 흐름: 분석자가 크기를 제안하고 대표가 확정 → 작은(구현→리뷰) / 보통(기획→디자인→구현→리뷰→QA) / 큰(+설계 2안)`
- 종류·범위: 프로세스 매뉴얼(`process`), 사용자 범위(`user`) — 기존 세 개와 같음
- 기존 small·medium·large 삭제는 통합본 확인 뒤 별도 카드로 (`deleteManual`은 위험 등급이라 한 장에 같이 묶지 않아요)

## 확인 필요
- **한 매뉴얼 안에서 크기별로 단계를 건너뛰는 방법이 있는지.** `ProcessStep`에는 조건 분기가 없고(`needsMyCheck`, `onRevise`, `maxLoops`만 있음), 지금은 앞 단계가 "정할 수 있는" 장치가 없어요. 아래 두 방안 중 정해야 해요.
  - **방안 A (권장, 코드 변경 없음):** 첫 단계 '크기 판정'에서 분석자가 크기를 제안하고 대표가 확정한 뒤, 나머지 단계의 지시문 첫 줄에 "확정된 크기가 ○○가 아니면 '해당 없음, 건너뜀'이라고만 보고하고 끝내세요"를 넣어 사실상 건너뜀. 모든 단계가 항상 돌지만 불필요한 단계는 한 줄 보고로 끝나서 비용이 작음. (역할 담당자가 없는 단계는 확인 필요)
  - **방안 B:** 앱에 크기별 단계 분기를 추가. 코드 변경이 필요해서 이번 범위 밖.
- 크기 판단 기준은 아래를 초안으로 하고 대표가 고치세요. (이전 비서 대화 63번에서 대표 확인 대기 중이던 항목)
- 예전 하나짜리 스킬 원문이 있으면 그것이 가장 정확해요. 아래는 현재 세 매뉴얼 기반이에요.

## 본문 (방안 A 기준)

````markdown

name: feature-flow
description: "기능 흐름: 분석자가 크기를 제안하고 대표가 확정 → 작은(구현→리뷰) / 보통(기획→디자인→구현→리뷰→QA) / 큰(+설계 2안)"
kind: process
---

web-flitto feature-flow(small·medium·large)를 하나로 합친 프로세스 매뉴얼입니다. 원본: .claude/commands/feature-flow.md

각 단계 담당은 랩 멤버의 직무로 정해지고, 리뷰·QA에서 revise가 나오면 구현으로 되돌아갑니다(최대 2회).
**크기(작은/보통/큰)는 '크기 판정' 단계에서 확정됩니다.** 이후 단계는 확정된 크기에 해당하지 않으면 "해당 없음, 건너뜀"이라고만 보고하고 끝냅니다.

크기 판단 기준(초안):
- 작은: 문구·스타일·버그 수정처럼 한 화면 안의 국소 변경. 새 컴포넌트·상태 구조 변경 없음. 영향 파일 약 3개 이하.
- 보통: 화면 하나 또는 소수의 화면 추가·변경. 기존 공통 컴포넌트로 가능. 설계 판단이 거의 필요 없음.
- 큰: 여러 화면에 걸친 변경, 새 공통 컴포넌트·상태 흐름·데이터 구조가 필요, 영향 범위가 넓어 설계안이 갈릴 수 있음.
````

## 원본 대비 바뀐 점
- 앞에 '크기 판정' 단계를 추가했어요(분석자 제안 → 대표 확정). 원본 세 개에는 없던 단계예요.
- 단계는 합집합(크기 판정·기획·디자인·설계 패턴·설계 가독성·구현·리뷰·QA)이고, 크기에 안 맞으면 "건너뜀" 한 줄 보고로 끝나요.
- 구현 지시는 크기별 기준 문장을 한 단계에 모았어요. 리뷰는 세 원본이 같아서 그대로예요.
- 디자인 단계의 대표 확인은 대표가 확정했어요: **크기 판정이 '큰'일 때만** 확인을 받아요. `ProcessStep`에 분기가 없어서 `needsMyCheck`는 `false`로 두고, 단계 설명에 "큰이면 대표 확인을 받고, 아니면 바로 진행"이라고 적었어요.
- 원본 large는 디자인에서 확인을 받고 medium은 안 받았는데, 통합본은 large만 확인으로 맞췄어요(대표 확정).
