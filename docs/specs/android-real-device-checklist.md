# 안드로이드 앱 1.0.0 — 대표 실기기 체크리스트

에뮬레이터와 로컬 서버로는 확인할 수 없는 것만 모았어요. 항목마다 "어떻게 → 이렇게 보여야 해요 → 아니면 무엇을 적어 주세요" 순서예요.
결과 표는 `docs/specs/android-qa.md`에 있어요. 시작 전에 PC 앱을 **재시작**해 최신 코드로 켜 주세요(재시작하면 일하는 직원의 작업이 끊겨요).

## 준비
- [ ] PC: Claude Office 최신 빌드로 재시작 → 설정 › 휴대폰 연결이 **꺼져 있는지** 먼저 봐요(기본 꺼짐).
- [ ] 폰: APK 설치(디버그 빌드 말고 릴리스 빌드, 서명한 것). 처음 열면 "QR 코드 찍기" 화면이어야 해요.
- [ ] PC가 켜져 있고 잠자기 설정이 "잠자기 안 함"인지 확인(끊김 화면 테스트 때만 바꿔요).

## 1. 같은 와이파이에서 먼저 (기준선)
- [ ] PC에서 연결 켜기 → 가이드 5단계를 끝까지 진행(포트 확인 → 공유기 자동 설정 → 주소 → QR).
- [ ] 폰 카메라로 QR을 찍어요 → "내 PC 사무실에 연결했어요"가 떠야 해요.
- [ ] 직원 목록, 결정 목록이 PC 화면과 같은지 봐요.
- [ ] 결재 1건을 폰에서 승인 → PC 결재함에서 사라지고 기록에 "📱 원격"이 남아요.
- [ ] 지시를 보내 봐요 → 직원 패널 기록에 📱가 남고, 지시 글에는 📱 표시가 섞이지 않아요.

## 2. LTE 외부망 접속
- [ ] 폰 와이파이를 끄고 LTE로만 접속해요(앱을 닫았다 열기).
- [ ] 공유기 자동 설정(UPnP)이 **성공**했다면: 직원 목록이 뜨는지. 시간(처음 연결까지 몇 초)을 적어 주세요.
- [ ] UPnP가 **실패**했다면: PC 화면의 안내대로 공유기에서 포트를 직접 열고, 같은 방법으로 다시 확인해요.
- [ ] PC 화면의 "외부 주소"가 통신사 공유 주소(CGNAT, 100.64.x.x 등)로 경고되면 외부 접속이 안 될 수 있어요 → 되는지 안 되는지 적어 주세요.
- [ ] 이때 PC 설정 화면의 "최근 접속 기록"에 폰의 외부 IP가 한 줄 남는지 봐요(토큰은 보이면 안 돼요).
- [ ] 공용 와이파이(카페 등)에서도 한 번 해 봐요.

## 3. 공인 IP가 바뀌었을 때
- [ ] DDNS를 쓰는 경우: 공유기를 껐다 켜서 공인 IP를 바꾼 뒤, 폰 앱이 새 주소로 연결되는지(몇 분 걸리는지 적어 주세요).
- [ ] DDNS를 안 쓰는 경우: IP가 바뀌면 "PC에 닿지 않아요" 화면이 뜨고, PC에서 QR을 다시 만들어 찍으면 복구되는지.
- [ ] 바뀐 뒤에도 인증서 지문이 같아서 "연결을 멈췄어요(인증서 불일치)"가 **뜨지 않는지**(같은 PC라서 뜨면 안 돼요).

## 4. 공유기를 거쳤을 때 IP별 잠금
공유기 뒤의 PC는 모든 접속이 공유기 주소로 보일 수 있어요. 잠금이 "한 사람의 실패"로 모두를 막는지 확인해요.
- [ ] 폰(LTE)에서 일부러 틀린 토큰을 5번 넣어요(디버그 빌드 아님 → 앱에서 낡은 QR을 찍거나, QR을 다시 만든 뒤 예전 QR로 연결).
- [ ] 폰에 "잠시 잠겼어요" + 줄어드는 카운트다운이 뜨는지, PC에 "🔒 원격 접속을 잠갔어요" 알림이 뜨는지.
- [ ] 같은 와이파이의 다른 기기(또는 PC 브라우저)에서 정상 토큰으로 접속이 되는지 → 한 곳만 막히면 정상, 전부 막히면 **버그**로 적어 주세요(공유기 때문에 IP가 같아서 다 막힐 수 있어요).
- [ ] 15분이 지나면 자동으로 풀리고 앱이 다시 연결되는지.
- [ ] PC에서 "QR 다시 만들기"를 누르면 잠금이 풀리는지.

## 5. 절전(Doze) 실제 지연
- [ ] 폰을 충전기에서 뽑고, 화면을 끄고, 한 곳에 30분 이상 가만히 둬요(주머니나 책상 위).
- [ ] PC에서 결재를 만들어요(직원에게 파일 수정 같은 일을 시켜요). 만든 시각을 적어요.
- [ ] 알림이 도착한 시각을 적어요 → 지연이 몇 분인지 기록. 앱이 안내하는 "수십 분 지연" 범위에 드는지 봐요.
- [ ] 배터리 최적화 "제한 없음"으로 바꾼 뒤 같은 테스트를 한 번 더 해서 차이를 적어요.
- [ ] 알림을 눌렀을 때 앱이 열리고 결정 목록으로 가는지.
- [ ] 알림 본문에 결재 내용(명령·파일 경로)이 **보이지 않는지**. 잠금 화면에서도 확인해요.

## 6. 화면 회전·키보드
- [ ] 직원 상세의 지시 입력칸을 눌러 키보드를 띄워요 → "지시 보내기" 버튼이 키보드에 **가려지지 않는지**.
- [ ] 긴 지시(여러 줄)를 쓰면서 글자 수 표시와 버튼이 같이 보이는지.
- [ ] 폰을 가로로 돌려요(직원 목록, 결정 목록, 기획안 보기, 지시 입력, 상태 화면 6종). 요약 칸이 너무 커서 목록이 한 줄밖에 안 보이면 적어 주세요.
- [ ] 돌려도 입력하던 글자와 선택한 항목이 사라지지 않는지.
- [ ] 폴더블·작은 화면(5인치대)이 있다면 한 번 열어 봐요.
- [ ] 다크 모드와 글자 크기를 크게(설정 › 디스플레이)했을 때 글자가 잘리지 않는지.

## 7. 끊김·복구
- [ ] PC를 잠자기 상태로 두고 폰에서 열어요 → "PC에 닿지 않아요" + 이유 안내가 뜨는지.
- [ ] PC를 깨우면 "다시 시도"로 복구되는지.
- [ ] Claude Office만 끄면 "PC의 휴대폰 연결이 꺼져 있어요"가 뜨는지.
- [ ] 비행기 모드에서 앱을 열면 오프라인 안내가 뜨고, 끄면 저절로 회복되는지.

## 8. 보안 마무리
- [ ] 연결을 끝낸 뒤 PC의 설정 › 휴대폰 연결을 **끄고**, 공유기에서 그 포트가 닫혔는지(공유기 관리 화면의 포트 목록) 확인.
- [ ] 앱을 지우고 다시 깔면 연결 정보가 남지 않는지(QR을 다시 찍어야 해요).
- [ ] 폰 백업(구글 백업)으로 복원해도 토큰이 따라오지 않는지(복원 뒤 "QR 코드 찍기" 화면).
- [ ] 화면 녹화·최근 앱 화면에 결재 내용이 노출되는지 확인(필요하면 보안 설정으로 가려야 해요).

## 적는 법
- 안 되는 항목은 "항목 번호 + 언제 + 폰 기종·안드로이드 버전 + 앱 화면 캡처"를 임안드·정리드에게 보내 주세요.
- 담당: 폰 화면·알림 → 임안드, PC 서버·인증·잠금·UPnP → 정리드.
