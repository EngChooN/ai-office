## 0. 원칙
- **새 디자인 없음.** 대화는 단체방 말풍선·입력창, 카드는 기획 카드(`PlanCard`)·질문 상자(`QuestionBox`), 현황은 대시보드 패널(`SummaryRow`·`AttentionCard`)을 **그대로** 쓴다. 색은 `index.css` 토큰만.

- 문구는 기획서 6절 지침(쉬운 말, "~해요", 결론 먼저, 바꾸는 일은 "이렇게 할까요?")을 따른다.

## 2. 화면 구성 (home.png)
`Page`(title "비서") 한 장.
- **머리:** 설명 `말로 묻고 시켜요. 무언가를 바꾸는 일은 확인 카드에서 [실행]을 눌러야 해요.` · 오른쪽 `오늘 비서 12.4K 토큰`(`text-muted-foreground text-xs tabular-nums`) · `Button ghost sm` **대화 지우기**(`Trash2Icon`).
- **대화 목록:** 단체방 `MessageList`와 같은 틀(`mx-auto max-w-3xl flex-col gap-3`, 아래로 스크롤 고정).
- **예시 질문 칩 줄:** 입력창 바로 위 한 줄 가로 스크롤. 칩은 회의실 팀·직원 칩 모양(`rounded-full border px-2.5 py-1 text-xs hover:bg-accent`). 누르면 그 문장을 바로 보낸다.
- **입력창:** 단체방 `Composer`와 같은 줄(`Textarea` `field-sizing-content` + 보내기 `Button`). placeholder `비서에게 묻거나 시키기 (예: 개발팀 만들고 프론트 개발자 뽑아 줘)`. 키는 `handleComposerKey` 그대로(Enter 보내기, ⌘+Enter 줄바꿈 — 폰은 폰 배치안 5-3절대로 Enter = 줄바꿈). 첨부는 1차에 없음.
- **빈 상태(대화 없음):** 가운데에 비서 얼굴(크게, `size-12`) · `무엇을 도와드릴까요?`(`font-semibold`) · `사용법을 묻거나, 사무실 현황을 물어보거나, "팀 만들고 직원 뽑아 줘"처럼 시켜 보세요.` · 예시 칩 6개(줄바꿈 배치).

**예시 칩 6개**(완료 기준 ★ 질문에서): `직원은 어떻게 뽑아?` · `지금 다들 뭐 해?` · `결재 기다리는 거 있어?` · `밤사이 뭐 했어?` · `디자이너한테 로그인 화면 시안 맡겨 줘` · `오큐에이 업무 지침 좀 다듬어 줘`
- 직원 이름이 들어간 칩은 **그 사무실에 있는 직원 이름**으로 채운다(없으면 그 칩은 빼거나 일반 문장 "업무 지침 좀 다듬어 줘").

- **한도 100%:** 입력창 위 한 줄 `text-status-waiting text-xs` `한도에 닿아 새 작업 제안은 쉬어요. 현황·사용법 질문은 계속 답해요.`(기획서 7-1, 확인 필요 Q4).

## 4. 카드

### 4-1. 확인 카드 (confirm.png)
`PlanCard`의 틀(`bg-card rounded-xl border p-4 text-sm flex-col gap-3`)에 **대기 테두리** `border-status-waiting`(PlanCard가 대표 확인을 기다릴 때와 같은 표시).
- **머리:** `이렇게 할까요?`(`font-semibold`) + `3단계`(`text-muted-foreground text-xs`). 단계가 1개면 `이걸 할까요?`.
- **단계 줄:** PlanCard 하위 업무 줄(`rounded-lg border p-2 flex gap-2`). 앞에 번호 원(`bg-muted size-5 rounded-full text-[11px]`), 제목 `text-xs font-medium`(`하는 일 — 대상`), 아래 `text-[11px] text-muted-foreground` 핵심 값.
- **카드 안에서 고치기:** 값 선택은 기존 `NativeSelect`(`h-7 text-xs`) — 고용 단계의 `모델: 앱 기본 ▾`·`작업 폴더: 지정 없음 ▾`(목록: 지정 없음 / 랩 폴더 / 최근 폴더 / 폴더 고르기…). 넓으면 두 칸, 좁으면(`@container` md 미만) 한 칸씩.
- **주의(⚠):** 카드 아래 `text-status-waiting text-xs` + `AlertTriangleIcon size-3.5`. 예: `같은 이름 "개발팀"이 이미 있어요. 이름을 고치거나 그대로 하나 더 만들어요.`
- **버튼 줄**(`border-t pt-3`, PlanCard와 같은 자리): 왼쪽 `text-muted-foreground text-[11px]` `10분 안에 실행하지 않으면 다시 확인해요` · 오른쪽 `취소`(ghost) · `고치기`(outline) · `✓ 실행`(기본, `CheckIcon`). 모두 `size="sm"`.
- **[고치기]:** 카드의 단계 제목에 있는 이름 등 글자 값을 `Input h-7 text-xs`로 바꿔 그 자리에서 고친다. 대화로 고치면("모델은 소넷으로") 새 카드가 나오고 이전 카드는 `opacity-60` + 머리 옆 `바뀜` 표시.
- **만료(10분):** 머리 옆 `오래된 제안이에요` + 버튼 줄이 `다시 확인할까요?`(outline) 하나로. [실행] 숨김.
- **실행 중:** 세 버튼 비활성, [실행] 자리 `실행 중…`. 단계 번호 원이 차례대로 결과 표시로 바뀐다.

### 4-2. 실행 결과 (result.png)
같은 카드가 결과로 바뀐다(새 카드를 만들지 않음). 대기 테두리를 지운다.
- 머리: `실행 결과` + 요약(`모두 했어요` / `1번은 됐고 2번에서 멈췄어요`).
- 단계 번호 원 → 결과: **완료** `CheckIcon text-status-working` + `만들었어요` / **실패** `XIcon text-status-error` + 이유 `text-status-error` / **건너뜀** `MinusIcon text-muted-foreground` + `2번이 안 돼서 건너뛰었어요`, 줄 `opacity-60`.
- 실패가 있으면 버튼 줄: `↻ 2번부터 이어서 하기`(기본) + `이미 된 1번은 그대로 둬요`. 모두 되면 버튼 대신 결과 화면으로 가는 링크(`text-primary text-xs` `조직도에서 보기 →`).

### 4-3. 위험 카드 (danger.png)
- 테두리 `border-status-error`, 제목 `이걸 할까요?`.
- 경고 줄 `text-status-error text-xs font-medium` `되돌릴 수 없어요. 대화 기록과 장비 설정이 사라져요.`
- 버튼: `취소`(ghost) · **동사 버튼** `Button variant="destructive"` (`퇴사시키기`·`삭제하기`). [고치기] 없음.
- **주의 카드**(권한을 넓히는 일 등): 확인 카드와 같고 ⚠ 한 줄로 이유를 적는다(대기 테두리 그대로).

### 4-4. 첨삭 비교 (edit.png · partial.png)
카드 틀은 같고 테두리는 기본(`border`).
- 머리: 대상 직원 `Avatar size-6` + `오큐에이 업무 지침 다듬기`.
- **바꾼 이유**: `bg-muted rounded-lg p-3 text-xs`(PlanCard 기획서 영역과 같음), 제목 `바꾼 이유` + 최대 3줄 목록.
- 그 아래 `바뀐 곳 3군데` · 오른쪽 체크박스 `바뀐 곳만 보기`.
- **나란히 비교:** `@container`로 넓으면 2칸(`지금` | `다듬은 안`), 좁으면 위아래. 각 칸 `bg-muted rounded-lg p-3 text-xs`.
  - 지운 말 `<del>` `text-status-error`(취소선), 더한 말 `<ins>` `text-status-working`(밑줄). 색만이 아니라 선 모양으로도 구분된다.
- 버튼: `취소`(ghost, 왼쪽) · `다시 다듬기`(outline) · `일부 적용`(outline) · `✓ 적용`(기본).
- **일부 적용**(partial.png): 다듬은 안의 덩어리마다 체크박스(기본 전부 켬). 끈 덩어리는 `opacity-50`. 버튼 줄이 `3군데 중 2군데 고름` · `돌아가기` · `✓ 이대로 적용`으로 바뀐다.
- **다시 다듬기:** 입력창에 `더 짧게`처럼 요청을 적게 포커스를 옮기고, 새 비교 카드가 나온다(이전은 `바뀜`으로 흐리게).
- **그사이 원문이 바뀜:** 적용 대신 카드 아래 `text-status-waiting` `그사이 내용이 바뀌었어요. 다시 비교할까요?` + `다시 비교`(outline).
- **적용 뒤:** 카드가 `적용했어요` 한 줄 + `적용 전 원문 보기`(접힌 `details`, 복사 가능, `selectable`)로 바뀐다(기획서 4절 7번).

### 4-5. 현황 요약 (status.png · waiting.png)
비서 답 안에 **대시보드 컴포넌트를 그대로** 넣는다.
- **"지금 다들 뭐 해?"**: 한 줄 결론(`지금 **일하는 중 4명**, **확인 필요 2명**, 오류 1명이에요.`) → `SummaryRow`(대시보드 요약 줄 그대로. 타일을 누르면 대시보드로 가서 그 상태로 거름) → 일하는 직원 목록(`rounded-lg border divide-y`, 줄마다 `Avatar size-6`·이름·하는 일 `truncate`·`Elapsed`) → `대시보드에서 보기 →`.
- **"결재 기다리는 거 있어?"**: 한 줄 결론 → **`AttentionCard` 그대로**(오래 기다린 순, 결재는 승인·반려를 바로 누름, 질문은 답하기, 오류는 확인). 기획서는 "각 항목 [승인]/[반려] 확인 카드"라고 했지만, 결재 승인·반려는 결재함·대시보드에서 이미 바로 누르는 동작이라 **같은 컴포넌트로 바로** 하게 했다. **[확인 필요]** 비서에서만 카드를 한 번 더 거치게 할지(4-6절 표).
- 밤사이·아침 브리핑·퇴근 요약은 `Markdown` 목록 + 필요한 곳에 `ActivityFeed`·`UsageCard`(대시보드 컴포넌트)를 같은 방식으로 넣는다.
- 숫자는 조회한 값만 쓴다(지침). 컴포넌트가 스토어 값을 직접 그리므로 말 속 숫자와 다르면 안 된다 → 결론 문장의 숫자도 같은 스냅샷에서 뽑는다.

### 4-6. ⌘K 빠른 창 (quick.png)
지금 화면 위에 뜨는 `DialogContent`(가운데 위쪽 18%, `max-w-xl`). 비서 화면으로 옮겨 가지 않는다.
- 첫 줄: 비서 얼굴(`size-7`) + `Input`(자동 포커스, placeholder `비서에게 묻거나 시키기…`) + `Esc` 표시(`kbd`).
- 답 영역: 비서 말풍선과 같은 `bg-card border rounded-xl px-3 py-2` + `Markdown`. 조회·사용법 답은 여기서 끝난다.
- **바꾸는 일**이면 이 창에서 실행하지 않는다. 답 영역에 확인 카드 대신 `확인 카드를 비서 화면에 만들었어요` + `비서에서 이어 보기 →`(outline)를 보인다. 작은 창에서 실행 버튼을 누르는 실수를 막기 위해서다.
- 아래: `자주 묻는 것` + 예시 칩.
- 대화는 비서 화면의 같은 대화에 쌓인다(빠른 창은 입구일 뿐).
- 키: `⌘K`/`Ctrl+K` 열기·닫기, `Esc` 닫기, `Enter` 보내기. 입력칸에 포커스가 있는 다른 화면에서도 ⌘K는 빠른 창이 먼저 받는다.

| 질문 | 빠른 창 | 비서 화면 |
|---|---|---|
| 사용법·현황(조회) | 답까지 | 같은 대화에 남음 |
| 결재 승인·반려 | `AttentionCard`로 바로(현황 답 안) | 같음 |
| 만들기·고용·배정·설정·첨삭 | "비서에서 이어 보기" | 확인 카드·비교 카드 |

## 5. 폰 폭 390 (phone-*.png)
폰 배치안의 틀(`PhoneShell`)을 그대로 쓴다.
- 상단 바 제목 `비서`, 비서 아이콘 버튼이 선택 모양.
- `Page` 머리는 폰 규칙대로 actions(사용량·대화 지우기)가 설명 아래 줄로 내려간다. **[제안]** 폰에서는 상단 바에 화면 이름이 이미 있으므로 `Page`의 큰 제목(h1)은 숨기고 설명만 남기면 한 줄을 아낀다(모든 화면 공통으로 적용 가능, 폰 배치안에 보탬).
- 말풍선 폭·카드는 같은 컴포넌트가 폭에 맞게 줄어든다. 확인 카드의 모델·폴더 고르기는 한 칸씩, 첨삭 비교는 위아래(`@container` 규칙).
- 예시 칩 줄은 가로 스크롤 한 줄. 입력창은 키보드 바로 위(폰 배치안 5-3절). 키보드가 열리면 아래 탭이 숨는다.
- ⌘K 빠른 창은 폰에 없다(상단 바 버튼이 같은 역할).
