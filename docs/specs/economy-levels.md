# 회사 레벨 10단계 · 회사 자금 · 상점 (설계 초안, 2026-10-21)

사용자 결정: 머니 이름 **회사 자금**, 레벨 **10단계**, 상점 품목 **벽지·바닥 / 가구·소품 / 직원 책상·의자** (직원 옷은 제외).

## 1단계 — 레벨 10단계 + 사무실 규모 개편
레벨마다 사무실이 "확" 바뀌어 보이게: 넓이, 새 공간, 건물 마감(바닥·벽·창)이 함께 오른다.

| Lv | 이름 | 새로 생기는 것 |
|---|---|---|
| 1 | 차고 창업 | 콘크리트 바닥, 접이식 책상, 형광등 |
| 2 | 원룸 사무실 | 장판 바닥, 작은 창, 커피포트 |
| 3 | 작은 사무실 | 칸막이 책상, 화이트보드, 회의 테이블 |
| 4 | 회의실 독립 | 유리벽 회의실, 카펫 |
| 5 | 휴게실·탕비실 | 소파·냉장고·자판기, 원목 바닥 |
| 6 | 층 전체 | 넓은 창, 카페테리아, 리셉션 |
| 7 | 게임 존·수면실 | 탁구대·오락기, 수면 캡슐 |
| 8 | 두 개 층 | 계단, 로비, 수족관 |
| 9 | 옥상 정원 | 잔디·벤치·바비큐 |
| 10 | 캠퍼스 | 트로피 홀, 대리석 바닥, 분수 |

- 경험치 기준을 10단계로 다시 나눈다(지금 Lv.3 · 2,024xp는 새 기준에서 Lv.4~5쯤).
- 레벨업 연출: 축하 창 + 공사 애니메이션(먼지·망치) + 보상 자금.

## 2단계 — 회사 자금
- 버는 법: 직원이 토큰을 쓸수록(경험치처럼) + 업무 완료 보너스 + 레벨업 보상.
- 환율(구현): **1만 토큰 = ₩10만**(100만 토큰 = ₩10만이면 지금까지 일한 게 ₩107만뿐이라 상향), 업무 완료 +₩300만, 레벨업 보상 = 레벨 × ₩500만 — `shared/economy.ts` 상수.
- 잔액은 장부를 따로 들지 않고 `토큰 합계 × 환율 + ledger 합계`로 매번 계산. 레벨 10단계 개편 전에 오른 레벨 보상은 처음 켤 때 한 번 지급(key로 중복 방지).
- 상단 HUD에 잔액, "회계" 화면에 입출금 내역.

## 3단계 — 상점·인벤토리
- 벽지·바닥: 구역별(업무·회의실·휴게실) 적용.
- 가구·소품: 사서 꾸미기 모드로 배치·회수.
- 직원 책상·의자: 직원별로 적용.
- 일부 품목은 레벨 잠금(예: 대리석 바닥 Lv.8).

## 4단계 — 픽셀아트·마감
- 새 품목 스프라이트, 미리보기, 업데이트 소식·코치마크·문서 갱신.

# 2차: 돈을 벌고 싶게 만드는 요소 (2026-10-21 결정)
사용자 결정: 품목 대폭 확장 + 컬렉션·세트 보상 + 오늘의 특가·한정판 + 업적·일일 미션. 아이템은 **행동만 바꾼다**(AI 성능·경험치 효과 없음).

## A. 품목 대폭 확장
- 가구 45종 이상, 벽지·바닥 각 12종, 책상·의자 각 10종.
- 등급: 일반 · 희귀 · 전설(수억~수십억 원대 목표품: 로봇 비서, 우주선 모형, 황금 엘리베이터 등).
- 상점 필터(등급·가격·살 수 있는 것만), 카드에 등급 테두리.

## B. 가구가 직원 행동을 바꾼다
- 놓은 가구마다 쉬는 직원이 찾아가는 자리가 생긴다: 커피머신(☕ 내려 마시기), 피아노(🎵 연주), 고양이(🐱 쓰다듬기), 오락기(🕹️), 주크박스(🎶 춤), 책장(📖 독서), 수족관(🐠 구경), 러닝머신(🏃) 등.
- 가구별 말풍선 대사.

## C. 컬렉션·세트
- 세트 6~8개(카페·게임·정원·서재·럭셔리·펫·할로윈…). 다 모으면 1회 보너스 자금 + 특별 장식.
- 상점 "도감" 탭: 전체 수집률, 세트별 진행도.

## D. 업적·일일 미션
- 일일 미션 3개(매일 바뀜): 업무 n건 완료, 토큰 n 사용, 회의 1번, 결재 n건 처리 등 → 보상 자금.
- 업적: 누적 마일스톤(업무 100건, 직원 10명, 회사 Lv.10, 컬렉션 50%…) + 배지.
- 받을 보상이 있으면 사이드바 배지.

## E. 오늘의 특가·한정판
- 매일 바뀌는 특가 3개(30~50% 할인, 날짜로 정해 모두 같은 결과).
- 시즌 한정: 할로윈(10월), 크리스마스(12월), 설날(1~2월), 벚꽃(3~4월) — 기간에만 판매.
