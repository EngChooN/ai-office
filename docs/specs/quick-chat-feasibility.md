# 빠른 대화(임시 직원 세션) 타당성 검토 (2026-11-26)

코드는 수정하지 않았고, 코드를 읽어서 판단했습니다. 실제 실행은 확인하지 못했습니다.

## 요구
직무 없는 간단한 일을 시키려 직원을 만들기 부담스럽다 → 세션형 대화방, 임시 직원 자동 배정, 시작 때 Claude/GPT 선택, 입력창 옆 모델 선택.

## ① GPT(Codex) 지원 · 모델 교체
- **Codex 직원은 이미 지원됩니다.** 직원에 엔진 칸(`provider: 'claude' | 'codex'`)과 모델 칸이 있고, 고용 때 엔진을 고릅니다. 엔진별 준비 상태(미설치·로그아웃·준비됨)도 앱이 압니다.
- **엔진 교체**(`changeEngine`)는 있습니다. 단, 쉬는 중일 때만 되고, 바꾸면 **이전 대화 맥락이 끊기고 새 대화로 시작**합니다(기존 코드가 그렇게 설계됨).
- **같은 엔진 안의 모델 교체**(`updateStaff`의 model)는 됩니다. 새 모델은 다음 지시부터 적용되는 것으로 추정합니다(미확인).
- 결론: 시작 때 Claude/GPT 선택은 **가능**. 입력창 옆 "모델 선택"은 같은 엔진 안이면 가능, **엔진 간 중간 교체는 맥락이 끊김**을 화면에 알려야 합니다.

## ② 임시 직원을 기존 직원 구조로 재사용
- 직원 한 명 = 저장 기록 + 책상 자리(`nextDesk`) + 사무실 그림 + 대화방 + 사용량 기록. 임시 직원도 그대로 만들면 **사무실에 한 명이 늘어 자리를 차지하고, 직원 목록이 어지러워집니다.**
- 급여: 직원 개인 월급은 없고, 하루 토큰 사용량이 '업무 수당'으로 기록됩니다. 임시 직원도 쓰면 **기록에 섞입니다**(전용 구분 필요).
- 선례: 튜토리얼 "연습 직원"(`isPractice`)이 사무실·인사·기록에서 빠지는 길을 이미 갖고 있습니다. 같은 방식의 '임시' 표시를 재사용하는 것이 가장 안전합니다.
- 정원·성장 영향: 회사 규모·인원 수로 정하는 규칙이 임시 직원을 세면 의도치 않게 영향이 납니다. **임시 직원은 인원·책상·회의 정원 계산에서 제외**해야 합니다(확인 필요: 인원 기반 규칙 전체 목록).

## ③ 세션 보관/재개
- 직원마다 세션 id를 저장하고, 터미널에서 이어 하기도 지원합니다. 대화가 길면 새 대화로 자동 넘기는 규칙(`sessionRotate`)이 있고 이전 대화는 지워지지 않습니다.
- 빠른 대화도 같은 방식으로 **세션 id를 목록에 보관**하면 재개됩니다. Codex는 일부 기능(세션 열기 등)이 Claude와 다르게 분기되어 있어 확인이 필요합니다.
- 필요한 정책: 보관 개수·기간, 닫을 때 삭제 여부, 보관 목록 화면.

## 대표 결정 (직접 선택, 2026-11-26)
원칙: **"어렵게 생각하지 말고 Claude Code의 세션 대화방처럼 쓴다."** 새 안전 장치를 만들지 않고 기존 동작을 따른다.
1. 1차에서 **파일 수정 허용**
2. 작업 폴더를 안 골라도 **홈 폴더 수정을 막지 않음** (폴더 선택 필수 아님)
3. 파일 수정 결재는 **옵션**으로 제공 — 설정에서 고름. 기본은 Claude Code처럼 **매번 묻기**, 옵션으로 자동 허용 등 (기존 결재 방식 그대로)
4. 대화는 **계속 보관**(기간 제한 없음, 직접 지울 때까지)
5. 끝난 뒤에도 사무실 그림에 **방문자 배지** 표시
6. 수당은 **따로 둔다**(기존 수당·보고서 합계에 안 섞음)
7. 삭제하면 **AI 쪽 세션 파일도 항상 같이 지움**

## 결정에 따른 영향 (간소화)
- **결재**: 새 규칙을 만들지 않고 직원의 기존 결재 방식을 빠른 대화에 그대로 적용. 빠른 대화용 기본값은 '매번 묻기'. (확인 필요: 기존 결재 방식 종류·이름. GPT 엔진도 같은 방식으로 동작하는지)
- **폴더**: 안 고르면 홈 폴더에서 일함(기존 직원과 같은 동작).
- **삭제**: 개별·선택 삭제 화면. 삭제 시 대화 기록, AI 세션 파일, 방문자 배지가 함께 사라짐. 확인 창 한 번. 되돌릴 수 없음을 안내.
- **용량**: 자동 삭제 없음. 목록에 개수·대략 용량만 표시.
- **방문자 배지**: 책상·인원·정원·수당 계산에서 제외(연습 직원이 빠지는 길 재사용). 많으면 '+N'. 그림은 시안 컨펌 후 제작.
- **수당**: 빠른 대화 사용량은 따로 합산, 기존 합계에 넣지 않음.

## ④ 단계 제안 (한 장 정리)
**1차**
- '빠른 대화' 버튼 → Claude/GPT 선택 → 임시 직원 자동 생성(자리·정원·수당 제외).
- Claude Code 세션 대화방처럼: 파일 수정 가능, 결재 옵션(기본 매번 묻기), 폴더 미선택 시 홈 폴더.
- 입력창 옆 모델 선택(같은 엔진 안만).
- 계속 보관 + 목록·삭제 화면(세션 파일까지 삭제).
- 방문자 배지(시안 컨펌 먼저). 안드로이드 제외.

**2차**
엔진 중간 교체(맥락 인수인계), 정식 직원 승격, 검색, 저장량 경고, 안드로이드.

## 위험 (줄임)
1. 임시 직원·방문자 배지가 인원·정원·수당에 섞이는 부작용(가장 큼).
2. 홈 폴더 수정이 가능해 실수 위험은 남음. 완화는 '매번 묻기' 기본값 하나로 한다(대표 결정).
3. 보관이 쌓임 → 목록의 용량 표시와 삭제 화면으로 대응.
4. 엔진 중간 교체 시 맥락 끊김, Codex 미설치·로그아웃 안내.
