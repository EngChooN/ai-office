# 소품 연출 가이드 (연출③ → 연출④-2 개정)

상위 업무: [연출④] 소품 연출. 분류표는 `furniture-motion-catalog.md`를 봐요. 시트는 `office-iso-art/motion/`에 있고, 생성기는 `app/scripts/motion-pilot.mts`(+ 묶음 파일 `app/scripts/motion/bundle1~4.mts`)예요. 상품 전체 시트 목록·측정표는 `furniture-motion-sheets.md`를 봐요.

## 1. 공통 규칙
- **늘 움직이는 것(A)**: 2~4초에 한 번 도는 은은한 반복이에요. 눈에 거슬리지 않게 바뀌는 픽셀은 그림의 10~15% 안으로 두고, 큰 위치 이동이나 번쩍임은 쓰지 않아요.
- **반응**: 150~250ms예요. 강도는 둘로 나눠요.
  - 호버: 약하게. 그림은 그대로 두고 밝기를 +8% 올리거나 1px 들어 올려요. 프레임을 새로 그리지 않아요.
  - 클릭: 분명하게. 반응 프레임 2~4장을 쓰거나 상태를 바꿔요(B). 한 번만 재생해요.
- **프레임 상한**: 반복 4~8장, 반응 2~4장, 상태 그림은 상태마다 1장이에요.
- **프레임 간격**: 반복 주기를 장수로 나눠요. 반복은 1장에 300ms 이상이 되게 해요(C는 쓰는 동안만 돌아서 예외로 300ms).
- **움직임 줄이기**(시스템 '애니메이션 제거' 또는 prefers-reduced-motion): 아래 표의 '대체 그림' 한 장만 보여 주고 반응은 빼요. B의 켜고 끄기 기능은 그대로 둬요.
- **정지·로딩**: 화면 밖이거나 앱이 백그라운드면 멈춰요. 시트는 필요할 때 불러오고, 지금 보는 레벨 것만 올려요. 동시에 움직이는 소품 수에 상한을 두고, 넘치면 화면 가운데에서 가까운 것부터 움직여요.

## 2. 종류별 규칙

| 종류 | 장수 | 반복 주기 / 간격 | 반응 길이 | 움직임 줄이기 대체 그림 |
|---|---|---|---|---|
| A 늘 움직임 | 반복 4~8장 | 2~4초 / 장당 300~500ms | 호버만 (+8% 밝기) | 반복의 0번 장(멈춘 기본 그림) |
| B 눌러서 켜고 끄기 | 꺼짐 1장 + 켜는 순간 1~2장 + 켜짐 반복 4~6장 | 켜짐 2초 / 장당 500ms | 클릭 200ms (켜는 순간 장) · 끌 때는 바로 꺼짐 장 | 꺼짐 = 꺼짐 장, 켜짐 = 켜짐 반복의 첫 장 |
| C 직원이 쓸 때 | 대기 1장 + 쓰는 중 반복 4장 | 쓰는 동안만 1.2초 / 장당 300ms | 없음 (기존 '쓰기' 장면 시간을 그대로 따름) | 대기 = 대기 장, 쓰는 중 = 반복의 첫 장 |
| D 업무 상태 | 꺼짐 1장 + 일하는 중 반복 4장 + 끝남 효과 2~3장 | 일하는 중 2초 / 장당 500ms | 끝남 효과 250ms, 한 번 | 꺼짐 장 / 일하는 중 첫 장 (끝남 효과는 뺌) |
| E 지나가면 | 반응 2~4장 | 반복 없음 | 직원이 근처에 오면 200ms 한 번 · 같은 소품은 3초 안에 다시 반응하지 않음 | 멈춘 기본 그림 |
| F 행사 때 | 반응 2~4장 (공통 반짝임은 그림 없이 효과로도 가능) | 행사 동안 1초 간격으로 최대 3번 | 250ms | 멈춘 기본 그림 (효과 없음) |
| G 시간대 | 낮 1장 + 밤 1장 (밤에 반복이 있으면 4장까지) | 밤 반복이 있을 때만 3초 | 바뀔 때 250ms 페이드 | 지금 시간대의 1장 |

- 여러 종류를 함께 붙이면(예: TV = B + F) 상태 종류(B·C·D·G)가 바탕 그림을 정하고, 순간 종류(E·F)는 그 위에 한 번 겹쳐요. F 반응은 효과로 처리하면 새 그림이 필요 없어요.
- **B 상태 저장**: 켜고 끈 상태는 소품마다 저장해서 앱을 다시 열어도 남아요. 저장된 상태가 없으면 꺼짐으로 시작해요. 켜짐 상태에서 화면 밖에 나가면 반복만 멈추고, 켜짐 상태는 그대로예요.

## 3. 시트 규격 (기존 그림 기준)
- **해상도**: 기존 텍스처와 같아요. 아트 픽셀로 그리고 PIXEL ×2로 키워요(칸 하나 = 아트 32×16 = 화면 64×32). 외곽선 1px, 같은 팔레트(isoArt.ts의 `K`)를 써요.
- **칸 크기**: 프레임 칸은 그 소품의 `artItem` 그림과 같은 크기예요(가로 (w+d)×16+6, 세로 (w+d)×8+높이+6 아트 px). 기준점(anchor)도 기존 텍스처와 같아서 바꿔 끼우기만 하면 돼요. 음표·연기처럼 위로 올라가는 덧그림이 있으면 칸 위쪽만 늘려요(가로는 그대로, 기준점은 manifest에 적힌 값).
- **0번 장**: 꺼짐·대기·늘 움직임의 첫 장은 기존 그림과 같게 둬요. 시트를 붙여도 평소 모습이 바뀌지 않아요.
- **배치**: 오브젝트마다 시트 1장이에요. 가로는 프레임, 세로는 방향(r0~r3)이에요. 모양이 같은 방향은 행을 함께 써요(분수는 1행). 화면이 안 보이는 방향은 0번 한 장만 둬요(TV r1·r2).
- **레벨별 변형**: 가구·소품 그림은 레벨에 따라 바뀌지 않아요. 레벨에 따라 바뀌는 것은 방(바닥·벽 마감)뿐이에요. 그래서 시트는 소품당 한 벌이고, '현재 레벨 시트만 로드'는 그 레벨에 놓인 소품의 시트만 올린다는 뜻이에요.
- **같은 그림을 쓰는 상품**은 시트를 함께 써요. 분수: `lv-fountain` ↔ `prop-fountain`. 커피머신: `coffee-machine` ↔ `prop-coffeeCorner`·`lv-espresso-bar`. 단, 커피 코너와 에스프레소 바는 모양이 달라서, 김과 표시등 위치만 옮긴 별도 시트가 필요한지 구현 단계에서 확인해요.
- **파일**: `docs/specs/office-iso-art/motion/{id}.png` 형식의 투명 RGBA PNG예요. `manifest.json`에 칸 크기, 기준점, 방향→행, 클립(프레임 번호·ms), 대체 그림 번호를 적어요. 기존 `items/` 그림은 건드리지 않아요.

## 4. 파일럿
| 시트 | 종류 | 구성 | 대체 그림 |
|---|---|---|---|
| `lv-fountain.png` | A | 6장, 3초 반복. 물줄기 높이가 살짝 오르내리고, 반짝이는 마디가 흘러가고, 물방울이 떨어지고, 수면 물결이 퍼져요. 1행(네 방향 같음) | 0번 |
| `tv.png` | B | 꺼짐 1장(유리 반사광), 켜는 순간 1장(가운데 흰 줄, 200ms), 켜짐 4장(하늘·언덕 화면, 해가 움직이고 주사선이 내려가요. 2장마다 채널 색이 바뀌어요). r0·r3는 6장, 뒷면 방향 r1·r2는 1장 | 꺼짐 0번, 켜짐 2번 |
| `coffee-machine.png` | C | 대기 1장(기존 그림과 같음), 쓰는 중 4장(김 두 가닥이 피어오르고, 커피 줄기가 떨어지고, 표시등이 초록으로 깜빡여요). 김은 네 방향 모두, 줄기와 표시등은 앞면이 보이는 r0·r3에만 있어요 | 대기 0번, 쓰는 중 1번 |

- **TV 상품은 코드에 없어요.** 시트는 2×1칸의 시험 그림으로 만들었어요. 상품을 따로 추가할지, B 규칙을 `lv-projector`나 `arcade`에 옮길지는 대표 결정이 필요해요.
- **메모리 절약 여지**(④ 측정 뒤 판단): TV 시트는 r1·r2 행의 빈 칸 10개가 메모리를 차지해요. 행마다 길이를 다르게 쌓거나(아틀라스), ×1 아트 px로 올리고 화면에서 키우면 메모리를 약 1/4로 줄일 수 있어요.
