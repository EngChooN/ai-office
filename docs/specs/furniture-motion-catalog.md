# 소품 연출 분류표 (연출④-1)

상위 업무: [연출④] 소품 연출 — 1/7단계. 기준 파일: `app/src/shared/economy.ts`(SHOP_ITEMS), `app/src/shared/iso/furniture.ts`(FURNITURE), `app/src/shared/iso/actions.ts`(ITEM_ACTIONS).

## 범위와 규칙
- 대상: 가구·소품(상점) + 레벨 전용(lv-*) + prop-* 소품 + 책상·의자 = **130개**. 벽지·바닥은 칸에 놓는 물건이 아니라 표면이라 제외했어요.
- 종류: A 늘 움직임 / B 눌러서 켜고 끄기 / C 직원이 쓸 때 / D 업무 상태 / E 지나가면 / F 행사 때 / G 시간대. 한 상품에 여러 개 가능.
- **파일럿 3종 고정**: 분수=A, TV=B, 커피머신=C.
- 같은 모양의 상품(예: `prop-fountain`↔`lv-fountain`, `coffee-machine`↔`prop-coffeeCorner`·`lv-espresso-bar`)은 그림 한 벌을 같이 써요.
- 우선순위: 상=파일럿·눈에 잘 띄고 효과가 큼 / 중=보통 / 하=효과가 작거나 그림 비용 대비 이득이 적음.

## 확인 필요
- **TV는 신규 상품이에요.** 코드에 `tv` id가 없어서 대표 지시로 이번에 추가해요(원래 '새 상품 추가'는 제외 범위였으나 TV 한 개만 예외). 상품 추가에 필요한 값은 **확인 필요**: 가격·해금 레벨·칸 크기·배치 방식(`economy.ts` 상점 등록 + `furniture.ts` 규격). 구현 단계(정리드)에서 기존 비슷한 상품(`lv-projector`, `arcade`)을 기준으로 제안하고 대표 확인을 받아요.
- 분류표의 '기존 동작을 바꾸는 항목': 책장·커피머신 등 C 종류는 기존 '쓰기' 장면(ITEM_ACTIONS 이모지·말풍선)에 그림만 덧붙이고 시간은 안 바꾸는 전제예요. B(눌러서 켜고 끄기)를 붙인 상품 중 **현재 클릭 시 열리는 메뉴가 있는지는 확인 필요**(구현 단계에서 점검).
