## 0. 요약

1. 레벨은 **1~20**이다. Lv.20까지 지금 이 회사 속도(하루 약 5,000 경험치)로 **약 3개월**이 걸린다. 앞쪽 레벨은 몇 시간, 뒤쪽은 몇 주가 걸린다.
2. 지금 회사 경험치는 **26,192**이다(실제 DB를 읽기 전용으로 계산). 새 기준에서는 **Lv.10**이고 Lv.11까지 1,808이 남았다(지금 속도로 반나절).
3. 층은 **4레벨마다 한 번**만 늘어 1층에서 5층까지 간다(Lv.6·10·14·18). 같은 층수 안에서는 외관 꾸밈과 바닥·벽·창, 구역, 전용 가구만 좋아진다.
4. 바닥 칸은 **Lv.1 8×8에서 Lv.20 24×24**까지 거의 매 레벨 1칸씩 넓어진다. 모든 층이 같은 크기다.
5. 레벨업 보상은 지금 장부 키(`levelup:{레벨}`)와 금액 공식(레벨 × ₩500만)을 **그대로** 쓴다. 이미 받은 Lv.2~10 보상은 키가 같아 자동으로 다시 들어가지 않고, Lv.11부터만 새로 받는다.
6. 상점 `minLevel`은 **같은 경험치 기준**으로 옮긴다. 지금 살 수 있던 물건이 다시 잠기는 일이 없다. Lv.11~20에는 레벨 전용 가구를 새로 채운다.
7. 꾸미기는 "버튼 아래 서랍 → 꺼내기 → 칸 미리보기(초록/빨강) → 돌리기 → 확정 → 다시 넣기" 순서다. PC는 마우스와 단축키, 폰은 탭과 떠 있는 버튼으로 조작한다(6절).

### 1-1. 이 회사의 실제 값 (2026-10-24, DB 읽기 전용)
- 고용 직원 12명, 직원 경험치 합 24,992 → **회사 경험치 26,192**. 옛 기준으로는 Lv.10(9,000)을 이미 크게 넘었다. 일감에 적힌 "대략 Lv.10 근처"는 **"이미 최고 레벨인 Lv.10"**이다.
- 하루 경험치(고용 직원 기준): 10-21 9,124 · 10-22 2,759 · 10-23 9,593 · 10-24 3,483(오늘, 진행 중). **평균 약 5,000/일**. 기록은 10-20부터만 있다.
- 장부에는 `levelup:2`~`levelup:10`이 이미 있다(합계 ₩2억 7천만, 10-21 지급).
- 팀 층: PO 팀·백엔드 팀이 1층이고, 나머지는 지정하지 않았다.

> 주의: 회사 경험치는 **지금 고용 중인 직원**만 더한다. 직원을 내보내면 회사 경험치가 줄어 레벨이 내려갈 수 있다(내보낸 직원 몫 356). 지금도 같은 구조라 이번 범위에서 고치지는 않고, 7절 Q7로 올린다.

- 레벨은 장부에 저장하지 않고 **경험치로 매번 계산**한다(지금과 같음). 그래서 문턱표만 바꾸면 재계산이 끝나고, 데이터를 고칠 일은 없다.
- 옛 Lv.5~10 사용자는 새 기준에서 레벨 숫자가 **낮아질 수 있다**(예: 옛 Lv.10, 9,000 → 새 Lv.8). 이때 줄어드는 것을 정리하면 다음과 같다.
  - **층수:** 옛 Lv.10 3층 → 새 Lv.8 2층. 3층에 둔 팀은 지금 규칙(`clampFloor`)대로 그릴 때만 1층으로 보이고, 저장값은 그대로라 레벨이 오르면 돌아간다.
  - **상점:** 4절 규칙으로 다시 잠기는 물건이 없다.
  - **보상:** 회수하지 않는다(5절).
  - 업데이트 소식에 "레벨이 20단계로 바뀌어 숫자가 달라질 수 있어요. 산 물건과 자금은 그대로예요"를 넣는다.

## 4. 레벨업 보상 — 이미 받은 보상을 다시 주지 않기

1. **키와 공식을 그대로 둔다.** 장부 키 `levelup:{lv}`와 금액(레벨 × ₩500만)이 옛 표와 새 표에서 같다. 그래서 새 Lv.N에 도달해도 `levelup:N`이 이미 있으면 `INSERT OR IGNORE`가 무시한다.
2. 이 회사의 경우:
   - `levelup:2`~`10`(₩2억 7천만)이 이미 있으므로, 개편 직후 새 Lv.10이 되어도 추가 지급은 0원이다.
   - Lv.11에 오를 때 `levelup:11` ₩5,500만부터 받는다.
3. 옛 레벨이 새 레벨보다 높은 사용자(예: 옛 Lv.10 → 새 Lv.8)는 새 Lv.9·10 보상을 이미 받은 상태라, 그 레벨에 다시 올라도 받지 않는다. 더 받은 몫은 **회수하지 않는다**(자금을 잃지 않는다는 원칙).
4. 장부 표시(라벨)는 지급 당시 이름이 남는다(예: "Lv.8 두 개 층 달성 보상"). 고치지 않는다.
5. 구현 메모: `checkCompanyLevel`이 `COMPANY_LEVELS[lv - 1].title`로 라벨을 만들므로 20개 표로 바꾸면 그대로 동작한다. `rewardedLevel`은 메모리 값이라 앱을 켤 때마다 2~현재 레벨을 다시 시도하는데, 키 덕분에 중복이 없다.

> 대안(7절 Q5): 보상 공식을 바꾸고 싶으면 키를 `levelup2:{lv}`로 새로 쓴다. 이때 개편 시점 새 레벨 이하는 "이미 받음"으로 표시하고(`levelRewardBaseline` 설정 값), 그보다 높은 레벨만 지급한다. 공식을 바꿀 이유가 없으면 권하지 않는다.

## 6. 꾸미기 서랍 흐름

### 6-1. 개편 때 한 번
- 놓여 있던 상점 가구(`placed`)를 **모두 서랍으로 돌려보낸다**. `owned` 개수는 그대로다.
- 바뀌는 점: 상점에서 사면 **서랍에 들어간다**(지금처럼 바로 1층에 놓지 않는다). 상점의 구매 알림 문구는 "서랍에 넣었어요. 사무실 '꾸미기'에서 꺼내 놓으세요."로 바꾼다.
- 벽지·바닥은 서랍에 넣지 않는다. 지금처럼 구역(업무·회의·휴게)에 적용하는 방식을 유지한다. 칸 단위로 바꿀지는 범위 밖이다.

### 6-2. 서랍 열기
- 맵의 **"🪑 꾸미기"** 버튼(지금 오른쪽 위 현황판)을 누르면 버튼 아래로 서랍이 펼쳐진다. 버튼 글자는 "✓ 꾸미기 끝내기"로 바뀐다. 외관을 보고 있었으면 지금처럼 안으로 들어간다.
- **서랍 카드** 하나에 보이는 것:
  - 그림
  - 이름
  - **칸 크기** "1×2"
  - **남은 개수** "2개 남음 (3개 중)" = 가진 수 − 놓은 수
  - 남은 개수가 0이면 카드를 흐리게 하고 "모두 놓음"으로 표시한다. 누르면 놓인 위치를 깜빡여 보여 준다.
- 서랍 위쪽 줄:
  - 분류 탭: 전체 · 책상·의자 · 가구 · 소품 · 레벨 전용
  - 정렬: 최근 산 순 · 칸 크기 순
  - "남은 것만" 거르기
- 지금 보고 있는 **층**에 놓는다. 층을 바꾸면 서랍은 그대로 열려 있고 놓을 층만 바뀐다(층별 배치는 지금 "1층만"에서 확장 — 박패턴 확인).
- 업무 모드에서는 꾸미기 버튼을 숨긴다(지금 규칙 확인 필요).

### 6-3. 단계별 흐름

```
[서랍]  ─꺼내기─▶  [들고 있음: 칸 미리보기 초록/빨강]  ─돌리기(반복)─┐
   ▲                         │  ▲                                  │
   │                         │  └──────────────────────────────────┘
   │                 확정(초록일 때만)        취소
   │                         ▼                  │
   │                    [놓임] ◀────────────────┘ (서랍으로 돌아감, 개수 그대로)
   │                         │ 다시 고르기
   │                         ▼
   └──── 서랍에 넣기 ── [선택됨: 옮기기 · 돌리기 · 서랍에 넣기]
```

| 단계 | 화면 | PC (마우스·키보드) | 폰 (터치) |
|---|---|---|---|
| ① 꺼내기 | 서랍 카드 | 카드 **클릭**: 가구가 마우스 커서에 붙는다. 또는 카드를 맵으로 **끌어** 놓는다 | 카드 **탭**: 서랍이 반쯤 접히고, 가구가 지금 보이는 화면 가운데에서 가장 가까운 빈 칸 위에 뜬다 |
| ② 위치 고르기 | 가구가 차지할 칸이 바닥에 **초록**(놓을 수 있음) 또는 **빨강**(안 됨)으로 칠해진다. 가구 그림은 반투명 | 마우스를 움직이면 칸 단위로 착착 붙는다. 방향키로 한 칸씩 옮길 수 있다 | 떠 있는 가구를 **끌면** 칸 단위로 붙는다. 맵 이동은 **두 손가락** 끌기, 확대·축소는 두 손가락 벌리기 |
| ③ 돌리기 | 1×2 → 2×1처럼 차지하는 칸이 바뀌고 다시 판정한다 | **R 키** 또는 **마우스 오른쪽 클릭**(90° 시계 방향). Shift+R은 반대 방향 | 가구 옆 떠 있는 **⟳ 버튼** 탭 |
| ④ 확정 | 초록일 때만 놓인다. 놓이면 짧게 "툭" 내려앉는 효과(움직임 줄이기면 생략) | **클릭** 또는 Enter. 빨강에서 클릭하면 가구가 살짝 흔들리고 이유 한 줄을 보여 준다 | 떠 있는 **✓ 버튼** 탭(빨강이면 비활성 + 이유 한 줄). 손가락을 떼는 것만으로는 확정하지 않는다(실수 방지) |
| ④-1 이어 놓기 | 같은 가구가 남아 있으면 한 개 더 | **Shift+클릭**으로 확정하면 같은 가구를 다시 든다 | ✓ 옆 **"하나 더"** 버튼 |
| ⑤ 취소 | 들고 있던 가구가 서랍으로 돌아간다 | **Esc** | 떠 있는 **✕ 버튼**, 또는 가구를 서랍 위로 끌어다 놓기 |
| ⑥ 놓인 가구 고르기 | 꾸미기 중 놓인 가구를 고르면 테두리와 작은 메뉴 [옮기기][돌리기][서랍에 넣기] | 가구 **클릭**하면 선택. 바로 **끌면** 옮기기(② 상태). 선택 중 R = 돌리기(제자리에서 돌려서 겹치면 빨강, 원래 방향 유지) | 가구 **탭**하면 선택 + 메뉴. **길게 누른 뒤 끌기**로 옮기기(짧은 끌기는 맵 이동과 구분) |
| ⑦ 서랍에 넣기 | 가구가 사라지고 서랍 카드 남은 개수가 +1 | 메뉴 [서랍에 넣기], **Delete/Backspace**, 또는 가구를 **서랍 위로 끌어다 놓기** | 메뉴 [서랍에 넣기], 또는 서랍 위로 끌어다 놓기 |
| ⑧ 끝내기 | 서랍이 닫힌다 | "✓ 꾸미기 끝내기" 또는 Esc(들고 있는 게 없을 때) | "✓ 꾸미기 끝내기" |

- **저장:** 확정·돌리기·넣기마다 바로 저장한다. "저장" 버튼은 없다. 되돌리기(Ctrl+Z)는 이번 범위에 넣지 않고 7절 Q8로 올린다.
- **빨강 이유 (한 줄):**
  - "바닥 밖이에요"
  - "다른 가구와 겹쳐요"
  - "계단·엘리베이터·문 자리예요" (고정 칸)
  - "길이 막혀요" (직원이 어떤 자리에도 걸어갈 수 없게 되는 경우, 박패턴 설계에서 판정 방식 확정)
- **직원이 서 있는 칸:** 놓을 수 있다. 직원이 옆 칸으로 비켜 걷는다.
- **책상·의자:**
  - 놓인 책상·의자 중 빈 자리에 직원이 앉는다.
  - 서랍에 넣어서 자리가 직원 수보다 모자라면 확인 문구를 띄운다: "자리가 n개 모자라요. 모자란 만큼 기본 자리를 자동으로 놓을게요". 기본 자리는 빈 칸에 자동으로 생기고, 서랍 개수와는 상관없다.
- **폰:**
  - 새 폰 앱(v2)은 PC와 같은 화면 묶음이라 같은 흐름이 그대로 동작한다.
  - 화면이 좁으면 서랍은 버튼 아래 펼침 대신 **화면 아래에서 올라오는 판**으로 보일 수 있다. 일감의 "버튼 아래" 요구와 부딪혀 7절 Q6으로 올린다.
  - 떠 있는 버튼(⟳ ✓ ✕ 하나 더)은 손가락 크기(40px 이상)로 한다.
  - 예전 폰 앱(v1)에는 사무실 맵이 없는 것으로 알고 있다(확인 필요). 있다면 꾸미기 버튼을 숨겨 깨지지 않게 한다.
- **키보드만으로:** 서랍 카드에서 Tab으로 고르고 Enter로 꺼낸다. 방향키로 옮기고 R로 돌리고 Enter로 확정한다.
