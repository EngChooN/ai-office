# 첫 업무 튜토리얼 시나리오 대본 (0.13.0)

연습 회사 구성과 시나리오 2종('업무 맡기기', '회의 열기')의 단계별 대본이에요. 구현(정리드·강백엔)과 디자인(이디자)이 이 문서대로 만들고, QA(오큐에이)가 이 문서의 "넘어가는 조건"과 시간 예산으로 검증해요.

- 진행은 모두 **모의 진행**이에요. 실제 AI 호출은 없고(토큰 0), 매번 같은 결과가 나와요.
- 화면과 버튼은 **진짜 화면**이에요. 사용자가 누를 곳만 하이라이트하고, 그 사이는 대본이 자동으로 이어요.
- 확인 필요(구현 시 정할 것)는 문서 끝 "열린 질문"에 모았어요.

## 2. 시나리오 A — 업무 맡기기 (목표 55초 이내)

연습 업무: **"로그인 화면 만들기"**

| # | 사용자가 누를 곳 | 안내 한 줄 | 넘어가는 조건 | 화면에 나오는 문구 | 예산 |
|---|---|---|---|---|---|

합계: 약 49초 (사용자 반응 시간을 더해도 1분 안).

### 이리드의 기획안 문구 (A4)

- 제목: 로그인 화면 만들기 — 기획안
- 목적: 이메일과 비밀번호로 로그인하는 화면을 만든다.
- 요구사항: ① 이메일·비밀번호 입력 ② 비밀번호 보기/숨기기 ③ 틀렸을 때 안내 문구
- 범위: 화면과 입력 검사까지. 서버 연동은 이번엔 제외.
- 완료 기준: 잘못된 입력에 안내가 뜨고, 올바르면 다음 화면으로 넘어간다.
- 하위 업무: 디자인 → 박디자 / 구현 → 최코드
- 하단 문구: 연습용 기획안이에요. 실제로는 이리드 같은 리드가 이런 기획안을 올려 대표님 확인을 받아요.

### 결과 카드 문구 (A6)

- 제목: 로그인 화면 만들기 — 결과 보고
- 요약: 로그인 화면을 만들고 입력 검사를 붙였어요.
- 바뀐 점: ① 이메일·비밀번호 입력창 ② 비밀번호 보기/숨기기 ③ 틀렸을 때 안내 문구
- 담당: 박디자(디자인), 최코드(구현)
- 하단 문구: 연습용 결과예요. 진짜 업무에서는 직원이 한 일과 바뀐 파일이 여기에 정리돼요.

| # | 사용자가 누를 곳 | 안내 한 줄 | 넘어가는 조건 | 화면에 나오는 문구 | 예산 |
|---|---|---|---|---|---|
| B1 | 사이드바 '회의실' | 여러 직원의 생각이 필요하면 회의를 열어요. | 회의실 화면이 열림 | (없음) | 3초 |

| B3 | 결정 사항 카드의 '할 일로 올리기' | 회의에서 나온 결정은 버튼 한 번으로 할 일이 돼요. | 업무 보드 '할 일'에 카드 2개 생김 | 결정: 로그인 화면을 먼저 끝낸다. → 할 일 카드 "로그인 화면 마무리" / 결정: 그다음 가입 화면 디자인을 시작한다. → 할 일 카드 "가입 화면 디자인" | 5초 |
| B4 | 사이드바 '업무 보드' | 회의 결과로 만든 카드를 확인해요. | 업무 보드가 열리고 새 카드 2개 하이라이트 | 안내: 카드가 만들어졌어요. 이제 담당자를 골라 일을 맡기면 돼요. | 5초 |
| B5 | '끝내기' | 회의록은 회의실에 남아요. 마무리할까요? | 완료 처리 | 축하 화면(7장) | 3초 |

합계: 약 38초.

## 4. 공통 규칙

- 각 단계는 앞 단계의 "넘어가는 조건"을 채워야 다음으로 가요. 엉뚱한 곳을 눌러도 막지 않고 안내 한 줄만 다시 하이라이트해요.
- 모든 단계에 '이 단계 건너뛰기'(자동 처리 후 다음 단계)와 '튜토리얼 끝내기'를 둬요.
- 자동 진행 대기(타이머)는 '지금 보기'로 바로 넘길 수 있어요.
- 시나리오 중간에 앱을 끄면 처음부터 다시 시작해요(진행 상태는 저장하지 않아요).
- 시나리오 선택 화면 문구: 한 사이클 해 보기 — 업무 맡기기 / 회의 열기 / 건너뛰기.

## 5. 축하 화면 (7장 공통)

- 제목: 해냈어요! 🎉
- 본문(A): 업무를 맡기고, 승인하고, 결과까지 받았어요. 진짜 직원도 똑같이 일해요.
- 본문(B): 회의를 열고, 결정을 할 일로 바꿨어요. 진짜 직원도 똑같이 의견을 내요.
- 보상 줄: 회사 자금 +N (금액 확인 필요)
- 버튼: 진짜로 해 보기 (직원 고용 + 내 폴더 연결) / 다른 시나리오 해 보기 / 연습 회사 정리
