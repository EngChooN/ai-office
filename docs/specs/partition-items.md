# 파티션·가벽 상품 설계 (파티션-1)

상위 업무: 파티션·가벽 상품 추가 — 1/4단계. 기준: `app/src/shared/economy.ts`(가격대·minLevel), `app/src/shared/iso/furniture.ts`(규격), `app/src/shared/i18n/dict/game.ts`(4개 언어 이름).

- 크기는 r0(기본 방향) 기준 `[w, d]`. 모두 `layer: 'object'`, `kind: 'deco'`, 앉는 자리·쓰는 자리 없음(`spec(w, d)`), 회전 가능(회전하면 1×2·1×3이 됨).
- 상점 카테고리는 `furniture`(가구·소품). 시즌 한정 아님.
- 모두 서로 비슷한 용도가 겹치지 않도록 나눴어요: 낮음 둘은 책상 칸막이용(짧은 것/긴 것), 높음 둘은 공간 나누기용(기둥 대신 쓰는 1칸 / 길게 막는 3칸).

## 가격 근거 (기존 상품과 균형)
- 기준: 이동식 화이트보드 2×1 ₩5M(Lv3), 원형 러그 2×2 ₩5M(Lv2), 소파 2×1 ₩12M(Lv3), 트로피 장식장 2×1 ₩35M(Lv6), 벽지 ₩5~28M.
- 칸당 가격: 패브릭 ₩2.0M → 유리 ₩3.3M → 화이트 가벽 ₩5.0M → 원목 가벽 ₩6.7M. 높은 쪽이 비싸고(길을 크게 막고 가림), 어느 것도 소파·장식장보다 싸게 둬서 장식 가구 가격대를 넘지 않아요.
- 전부 ₩3,000만 미만이라 등급은 `common`(`rarityOf` 기준).
- 해금: 책상 칸막이는 직원이 늘기 시작하는 Lv.2, 높은 가벽은 방 구조를 꾸밀 수 있는 Lv.3~4. 가구 해금 범위(Lv.1~8) 안쪽에 둬서 초반에 막히지 않게 했어요.

## 다음 단계에 넘기는 값 (구현·설계 참고)
- **설명 문구**(`item.<id>.desc`)는 구현 단계에서 4개 언어로 같이 넣어요. 제안 한국어: 패브릭 "책상 사이를 나누는 낮은 천 칸막이" / 유리 "탁 트인 낮은 유리 칸막이" / 화이트 가벽 "공간을 나누는 흰 벽" / 원목 가벽 "따뜻한 원목 칸막이 벽".
- **길막음**: 모두 길(`shared/iso/path`)을 막는 물건이에요. 출입구·자리로 가는 길을 완전히 막는 배치는 기존 '도달 가능한지 확인'으로 막아요(2단계 담당).
- **가려짐**: 낮음 2종은 직원을 가리지 않는 물건(그리기 순서만 적용), 높음 2종은 `depth.ts`의 `hidesMover`·`WALL_FADE` 대상으로 해요. 투명도 값은 3단계에서 확정 — 확인 필요.
- **그림**: 4종 모두 새 그림 필요(담당 이디자). 재질 느낌: 패브릭=회색 천, 유리=하늘색 반투명, 화이트=매트 흰색, 원목=월넛 원목 결.
- **소품 연출 표**: 4종 모두 '움직이지 않음'(이유: 구조물이라 움직일 장면이 없음)으로 `furniture-motion-catalog.md`에 등록해요(우선순위 하).
- **확인 필요**: 크기 2×1 높은 가벽은 이번에 만들지 않았어요(1×1과 3×1 조합으로 대체). 필요하면 추가 요청.
