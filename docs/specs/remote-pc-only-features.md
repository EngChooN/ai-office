# 원격에서 못 하는 기능 분석표 (PC 전용 기능)

작성: 김기획 · 2026-11-18 · 코드는 읽기만 했고 고치지 않았습니다. 실기기로 눌러 본 확인은 없습니다.

## 한눈에 보기

- 휴대폰·다른 PC로 원격 연결하면, 호출 규칙표(`app/src/main/remote/v2.ts`)에서 **"P(PC 전용)" 34개 동작**이 막힙니다. 서버가 "휴대폰에서는 할 수 없어요. PC에서 해 주세요"(422)로 돌려보냅니다.
- 그 밖에 **S(제한 허용)** 동작은 되지만 위험한 칸(작업 폴더, 승인 방식, Bash 허용 등)은 PC 값으로 고정됩니다.
- 사용자가 가장 자주 부딪히는 것은 **결과물 열기**와 **첨부 열기**입니다. 결과물 카드가 "PC에서 열어 주세요"로만 보입니다.
- 휴대폰 앱(안드로이드 셸)은 일부를 대신 처리합니다(경로 입력, 첨부 내려받기, 안내 문구). 다른 PC 화면(피어 보기)에 같은 대신 처리가 있는지는 **확인 필요**입니다.

규칙표 분류: R 그대로 · S 제한 허용 · P PC 전용 · C 이 폰 연결이 끊김(확인 필요) · U 올리기 경로로.

## 사용자가 PC 전용 안내를 보는 화면

화면 안내가 있는 곳: 결과물 카드, 직원 패널, 설정(원격 상태·화면 캡처·훅), 장비(연결 도구) 탭, 채용 창, 매뉴얼 목록·편집, 도움말(연습), 연결 설정, 리뷰 탭(되돌리기 버튼 숨김). 대부분 "PC에서 바꿀 수 있어요." 한 줄입니다.

## 안내 문구 점검 (쉬운 말 관점)

- 결과물 카드: "PC에서 열어 주세요"만 보이고 **왜 안 되는지, 대신 뭘 할 수 있는지**가 없습니다. 가장 고치기 좋은 곳입니다.
- 일반 안내: "PC에서 열어 주세요. 휴대폰에서는 할 수 없는 기능이에요." 다른 PC에서 접속한 경우에도 "휴대폰"이라고 나옵니다. 문구를 "원격 화면에서는"으로 바꾸는 것이 좋습니다(추정).
- 터미널·로그인·QR 안내는 이유와 PC에서 어디로 가야 하는지가 있어 좋습니다.

## 상위 5개 개선 후보 (추천)

1. **결과물 미리보기·내려받기** — 중요도 상, 난이도 중. 원격에서 가장 아쉬운 부분입니다. 파일 내용을 연결된 PC에서 받아 와 미리보기로 보여 주고, 큰 파일은 크기 상한과 안내를 둡니다. 경로 검증이 필수입니다(원격이 임의 파일을 읽지 못하게).
2. **첨부 사진 깨짐 해결 + 첨부 열기를 내려받기로 통일** — 중요도 상, 난이도 하~중. 사진 주소가 "지금 화면을 띄운 PC"만 가리켜서 다른 PC 화면에서는 깨지는 것으로 **추정**합니다(실행 확인 전). 연결된 PC에서 받아 와 보여 줍니다.
3. **"밖에서 열기·폴더에서 보기"를 "내려받기"로 바꾸기** — 중요도 중, 난이도 하. 원격에서 의미 없는 버튼을 쓸모 있게 바꿉니다. 2번과 함께 하면 효율적입니다.
4. **찾은 파일 열기를 내려받기·미리보기로** — 중요도 중, 난이도 중. 1번 방식을 재사용합니다.
5. **PC 전용 안내 문구 통일** — 중요도 중, 난이도 하. "휴대폰" 대신 "원격 화면", 왜 안 되는지와 PC에서 할 방법 한 줄 추가. 기능 수정 없이 문구만 고칩니다.

제외 이유: 터미널·로그인·연결·훅·MCP·QR은 보안과 직결돼 이번 범위 밖(서명·보안 모델·연결 방식 변경 금지)이고, 사용 빈도도 낮습니다.

## 확인하지 못한 것

- 앱을 실제로 띄워 눌러 본 확인은 없고, 코드만 읽었습니다.
- 다른 PC 화면(피어 보기)에서 첨부·결과물이 어떻게 보이는지, 안드로이드 셸의 첨부 요청 가로채기 범위는 이 문서에서 확인하지 못했습니다.
- 중요도·난이도는 추정입니다. 사용 빈도 통계는 없습니다.
