## 공통 규격 및 제작

- 개별 시안: 1024×1024px RGBA PNG.
- 기존 `app/build/icon.png`에서 읽은 둥근 사각형 알파를 그대로 재사용했다. 타일 경계는 (96,96)–(928,928), 크기는 832×832px이며 사방 96px는 투명하다. 원본 파일을 수정하지 않았다.
- 생성 그림은 정사각형으로 제작한 뒤 832px로 축소하고 기존 알파로 내보냈다. 제품 코드로 그림을 그리거나 제품 코드를 수정하지 않았다.
- 그림 생성: 내장 `image_gen` 도구, `imagegen` 스킬. 생성 원본은 `originals/`에 보존했다. 최종 프롬프트는 `prompts.json`의 공통 프롬프트와 시안별 프롬프트를 이어 붙인 것이다.
- 기준: 기존 아이콘 및 `docs/icon-drafts/` 3종, `isoArt.ts`의 크림 #faf5ec·원목 #d6ae7a·라벤더 #8f80e6·민트 #8fd6c2·하늘 #9fe3ff·자두 윤곽 #3a2a32. 기존 픽셀 그림의 색감을 가져오되 새로운 그림체의 시안을 탐색했다.

## 시각 검수 및 제안

- 5종 모두 밝은 바탕·어두운 바탕에서 외곽과 여백을 확인했다.
- 32px에서는 A의 건물, B의 얼굴·책상, C의 말풍선·체크, D의 사무실 바닥, E의 4분할 창이 서로 다른 실루엣으로 남는다.
- 16px에서는 C의 밝은 얼굴과 민트 결재 표시가 가장 단순하게 남는다. B는 얼굴·책상·노란 말풍선의 색 구획이 남는다. A·D·E는 직원 표정과 소품을 읽기 어렵다. 16px에서 모든 세부를 알아볼 수 있다는 의미는 아니다.
- **디자인 추천: C** — 작은 크기에서 구별되는 정도와 대화·결재 상징을 우선할 때. 사무실 장면 자체를 강조하면 A, 친근한 직원을 강조하면 B를 우선 검토한다.
- 선택 후 작은 크기 전용 단순화, 실제 Dock에서의 광학 크기 확인, 플랫폼별 변환은 후속 작업이다. 대표 선택 전이며 icns·ico·트레이·안드로이드·사이트 적용과 커밋은 진행하지 않았다.
