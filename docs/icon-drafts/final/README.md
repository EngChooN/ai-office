# 확정 아이콘 에셋 작업 기록

확정 방향: `../v3/pixel-office-light-gradient.png`의 밝은 라벤더→회보라 배경과 도트 사무실. 대표가 확정함.
`pixel-office-refined-candidate.png`는 픽셀 경계가 또렷한 후보 원본(그림만 가져다 씀). 타일 색은 v3에서 잰 값을 쓴다.

## 지금 방식 (2026-10-30, 정리드)

배포 아이콘은 모두 `app/scripts/icon.mjs final` 한 번으로 만든다. 두 단계로 나뉜다.

| 단계 | 입력 → 출력 | 언제 |
|---|---|---|
| 1. 추출 `node scripts/icon-extract.mjs <후보 PNG> scripts/icon-art/art-grid.png` | 후보 그림 → 칸당 1px 작은 PNG(57×55칸, 16색) | 후보 그림이 바뀔 때만. 결과를 눈으로 보고 커밋 |
| 2. 생성 `node scripts/icon.mjs final` (app 폴더) | `art-grid.png` + `icon-art/small.mjs` → 27개 파일 + 비교 시트 | 언제든. 같은 Node면 같은 바이트 |

- **추출:** 어두운 외곽선을 벽으로 두고 바깥에서 채워 "바깥"을 정한다(고정 좌표·색 거리 임계값 없음). AI 그림이라 칸 간격이 조금씩 달라서(평균 15.1×14.7px) 칸 경계를 줄마다 동적 계획법으로 찾고, 칸마다 가운데 픽셀의 중앙값을 k-평균으로 16색으로 줄인다. 자동으로 못 잡은 2칸은 `PATCH` 목록에 손질로 남겼다.
- **16·32px:** 큰 그림을 줄이면 인물이 뭉개져서 `icon-art/small.mjs`에 칸을 직접 찍어 두었다(텍스트라 diff로 리뷰 가능). 24px은 32px에서, 48px 이상은 1024 마스터에서 줄인다.
- **안드로이드:** 배경은 그라데이션 벡터(`drawable/ic_launcher_background.xml`), 전경은 가운데 66dp 원 안에 들도록 칸 크기를 자동 계산(1칸 1dp). 레거시·원형 PNG는 배경+전경을 합쳐 가운데 72dp를 잘라 만든다. monochrome은 역할별 진하기 3단계(외곽선·머리·모니터 100%, 책상·옷·화분 70%, 벽·바닥 35%).
- **윈도우 알림 영역:** 1024를 16으로 줄이면 알아볼 수 없어 `trayWin.png`(16)·`trayWin@2x.png`(32) 전용 파일을 쓰도록 `tray.ts`를 바꿨다.
- **사고 방지:** 원본 검사(그림 비율 40% 이상, 외곽선 존재, 한 덩어리, 팔레트 밖 색 0) → 임시 폴더에 쓰기 → 다시 읽어 검사(크기, 모서리 투명, 타일 색이 아닌 그림 비율, ico 7종·icns 10조각, 전경 안전 영역) → 모두 통과해야 실제 경로로 복사. 하나라도 실패하면 종료 코드 1, 배포 파일은 그대로.
- `apple-touch-icon.png`는 **일부러 불투명**(iOS가 모서리를 깎고 투명은 검게 칠함).
- 비교 시트 `comparison-16-32-128-512.png`: 실제로 쓴 파일을 다시 읽어 그린다. 위 = 흰 배경, 가운데 = 어두운 배경(원본 v3, 16 1×·4×, 32 1×·4×, 128, 512, 트레이 새것·예전 방식), 아래 = 안드로이드 원·스쿼클 마스크, 레거시·원형, 단색.

## 설계 결정 (최가독·박패턴 두 안 비교)

- **채택:** 추출/생성 분리 + 원자적 교체·검사(박패턴), 외곽선 바깥 채우기·작은 격자 PNG 원본·16/32 손그림 텍스트·monochrome 진하기 단계·레거시를 adaptive 합성에서 파생·Node 내장만 사용(최가독, 두 사람 공통).
- **최가독 안 중 안 따른 것:** 한 번에 원본→산출물 실행. 추출은 휴리스틱이라 흔들리면 산출물이 조용히 바뀐다.
- **박패턴 안 중 바꾼 것:** 트레이 전용 16px은 "시트를 보고 결정"이었는데, 시트에서 1024→16 축소본이 알아볼 수 없어 이번에 넣었다. `make_icons.py`는 지우는 대신 폐기 표시만 했다(삭제 명령이 막혀 있음). `iconUrl` 고정은 후속 과제.
- **구현 중 바뀐 것:** 칸 크기를 하나로 맞추는 방식은 계단이 깨져서 줄마다 경계를 찾는 방식으로 바꿨다. icns의 `icp6` 조각은 iconutil이 48px로 읽어 빼고, iconutil이 만드는 것과 같은 10조각으로 맞췄다.
