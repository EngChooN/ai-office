# AI Office 아이콘 방향 시안 v3

이디자 · 2026-10-30 · 대표 확정 전 디자인 제안

대표 피드백: 앱의 도트 사무실을 활용하고, 기존 시안의 일반적인 AI 이미지 느낌을 줄인다. v2 C안 추천은 이번 방향의 추천으로 대체한다.

## 산출물

- `pixel-office-concept.png`: 도트 직원·원목 책상·모니터·화분을 중심으로 만든 단일 아이콘 방향 이미지. 불투명 바탕이 포함된 생성 원본이며 배포용 아이콘이 아니다.
- `pixel-office-presentation.png`: 확대 시안과 사무실 참고 장면, Dock 배치 예시를 담은 이미지. 오른쪽 사무실도 생성 과정에서 재현된 참고 이미지이며 원본 캡처가 아니다. Dock은 합성 시안으로 실제 적용 화면이 아니다.
- `prompts.json`: 내장 image_gen 도구에 사용한 프롬프트. imagegen 스킬 적용.

## 디자인 제안

로봇·안테나·말풍선 얼굴·승인 체크를 빼고, 앱에서 실제로 경험하는 '직원이 책상에서 일하는 작은 사무실'을 대표 상징으로 삼는다. 크림 벽, 회청색 바닥, 원목 책상, 주황 의자, 도트 인물, 자두색 윤곽을 기존 사무실에서 가져왔다. 배경 타일은 라벤더 계열이다.

## 확인한 범위와 후속 정리

확대 시안의 계단형 윤곽, 직원·책상·식물 구성과 참고 화면의 연결을 눈으로 확인했다. 생성 결과에는 부드러운 명암과 일정하지 않은 픽셀 크기가 일부 남았다. 기존 스프라이트를 그대로 재사용한 완성 에셋은 아니다. 적용 예시는 배치 방향 확인용이며 실제 16·32px 인식성 검증을 대신하지 않는다.

방향 확정 후 일정한 픽셀 격자·제한된 색 수로 정리하고, 작은 크기에서는 바닥 타일과 식물 세부를 덜어낼 것을 제안한다. 기존 아이콘 알파와 광학 여백 일치, 투명 바탕, 플랫폼별 크기와 실제 Dock 검수는 후속 작업이다. 제품 소스·배포 아이콘·커밋 변경 없음. 구현과 플랫폼 적용은 방향 확정 후 정리드·프론트엔드에 전달한다.
