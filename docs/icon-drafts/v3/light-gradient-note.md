대표 요청: 그라데이션은 유지하고 밝은 도트 그래픽에 어울리도록 배경을 밝게 조정.

결과: `pixel-office-light-gradient.png`. 내장 image_gen으로 `pixel-office-dark-gradient.png`를 참조해 수정했다. 밝은 라벤더에서 회보라로 이어지는 배경으로 조정했으며 인물·책상·모니터·식물·벽·바닥 구성 유지를 요청했다. 결과 이미지를 직접 확인했으며 기존 사무실 구성과 배경 밝기 개선을 확인했다. 생성 편집이므로 원본 도트와 픽셀 단위로 동일함을 보장하지 않는다.

사용 프롬프트: 기존 도트 사무실 아이콘을 편집 대상으로 하여 둥근 사각 배경만 밝게 바꾼다. 상단 왼쪽 밝은 라벤더 #B5ACCC, 중간 #9693B3, 하단 오른쪽 회보라 #777B99 정도의 은은한 그라데이션을 목표로 한다. 인물·의자·모니터·화분·크림 벽·파란 바닥의 배치, 크기, 색과 외부 흰 여백을 유지한다. 텍스트나 새 요소는 추가하지 않는다. 색상은 생성 방향을 위한 제안값이며 출력의 측정값이 아니다.

제품 코드와 배포 아이콘은 변경하지 않았다.

## 개발 인계 기준

- 최종 기준 이미지: `docs/icon-drafts/v3/pixel-office-light-gradient.png`. 도트 사무실 구성과 밝은 그라데이션을 기준으로 적용한다.
- 색상 참고: 위 프롬프트의 색은 제안값이다. 최종 이미지를 시각 기준으로 삼으며 새 글꼴·텍스트·버튼 상태·동작·애니메이션은 추가하지 않는다.
- 원본에는 둥근 타일 밖 흰 여백이 포함되어 있다. 플랫폼 아이콘용 투명 영역과 광학 여백은 기존 배포 아이콘 규격에 맞춰 정리해야 하며, 원본 전체를 단순 축소한 결과를 완성본으로 간주하지 않는다.
- 플랫폼별 크기·마스킹·반응형 표시 및 패키징 방식은 정리드와 프론트엔드가 기존 프로젝트 규칙에 맞춰 결정한다. 16·32px 식별성과 Dock·실제 앱 표시를 확인한다.
- 적용 후 결과 화면 1~2장을 이디자에게 전달해 시각 검수를 요청한다. 현재 승인 범위는 방향 확정이며 적용 완료를 뜻하지 않는다.
