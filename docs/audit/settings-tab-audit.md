참고: 코드 주석에는 "일반·AI·업무·사무실·연결" 5분류라고 적혀 있으나 실제는 4개입니다(AI와 업무가 한 탭).

## 2. 문제 목록과 이동 제안

| # | 문제 | 유형 | 제안 |
|---|---|---|---|
| A | 데스크 펫(25)이 '연결' 탭 | 주제 불일치 (가장 심함) | → **사무실** 탭 (꾸미기 성격). 대안: 일반 |
| B | 트레이 아이콘(24)이 '연결' 탭 | 주제 불일치 | → **일반** 탭, '로그인할 때 자동 실행' 바로 옆 (앱 동작 묶음) |
| C | 근무시간(20)이 '사무실' 탭 | 주제 불일치 | → **AI·업무** 탭, 자동결재 근처 (일정·시간 성격) |
| D | 업무 모드(8)가 'AI·업무' 탭 | 이름 때문에 놓이지만 실제는 화면 성격 | → **일반** 탭 '화면 모드' 아래 (회사용 화면). 대안: 유지 |
| E | 외부 직원 훅 2개(14·15)가 AI·업무 맨 아래 | 찾기 어려움 | → **연결** 탭 (외부 Claude Code와 잇는 기능). 또는 AI·업무 안에서 위로 |
| F | 색 테마(3, 일반)와 사무실 테마(16)가 이름이 비슷 | 찾기 어려움·혼동 | 이름 정리: 3 → '앱 강조 색', 16 → '사무실 색 분위기'. 위치는 유지 |
| G | 자동결재(9)·자동 승인 규칙(10)·직원 화면 캡처(11)·비서 웹 검색(12)이 'AI·업무'에 섞임 | 탭이 비대(항목 9개, 가장 김) | 소제목 3개로 나눔: 'AI 연결'(7) / '결재·자동화'(9·10·14·15) / '직원 동작'(11·12·13) |
| H | '자동결재'(9)와 '자동 승인 규칙'(10)이 비슷한 이름, 직원 패널 장비의 '결재 없이'와도 중복 느낌 | 중복·혼동 | 설정 설명에 "전체 기본값 / 직원별은 직원 패널 장비" 한 줄 추가. 기능 합치기는 확인 필요 |
| I | 비서 웹 검색(12)과 직원 장비의 웹 권한 | 중복 느낌 | 이름을 '비서 웹 검색'으로 두되 설명에 "직원별 웹 권한은 직원 패널" 추가 |
| J | 소품(18)에 '잡담' 체크가 섞임 | 이름 불일치 | '소품'과 '직원 잡담 말풍선'으로 분리 |
| K | 직원별·방별 설정이 앱 전역 설정과 분리돼 있어 어디서 바꾸는지 모름 | 찾기 어려움 | 각 섹션 설명 끝에 "직원별은 직원 패널 › 장비" 바로가기 링크 |

## 3. 이동 후 모습 (제안안)

- **일반**: 언어 · 화면 모드 · 색 테마 · **업무 모드(D)** · 로그인 자동 실행 · **트레이 아이콘(B)** · 업데이트 · 안내
- **AI·업무**: AI 계정 · 자동결재 · 자동 승인 규칙 · **근무시간(C)** · 직원 화면 캡처 · 비서 웹 검색 · 토큰 절약
- **사무실**: 사무실 테마 · 낮과 밤 · 소품 · 잡담 · 배치 초기화 · **데스크 펫(A)**
- **연결**: 휴대폰 연결 · 다른 PC 연결 · **외부 직원 훅 2개(E)**

효과: 연결 탭이 '연결 4개'로 주제가 맞고, 사무실 탭은 꾸미기만 남습니다.

## 4. 확인 필요 / 주의

- 이동은 `SettingsPage.tsx`의 섹션 위치만 옮기면 되고, 저장 키는 바뀌지 않습니다(예상). 단 `SECTION_CATEGORY`(바로가기 섹션 → 탭 매핑)와 다른 화면에서 `requestSettingsSection`으로 여는 곳이 있어 함께 확인해야 합니다.
- E는 대표 판단이 필요합니다(AI·업무에 둘지 연결로 옮길지). 훅은 윈도우 미지원 안내가 붙어 있어 연결 탭에서도 동일하게 표시해야 합니다.
- H의 '자동결재'와 '자동 승인 규칙' 실제 효과 중복 여부는 정리드 확인이 필요합니다.
- 설정 화면 밖(직원 패널 장비·프로필, 회사 화면)에 있는 설정은 이번 점검 범위가 아닙니다.
- 4개 언어 사전(ko/en/ja/zh)은 제목 변경(F·J) 시 함께 수정해야 합니다.
