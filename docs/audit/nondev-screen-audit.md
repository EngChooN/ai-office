# 비개발자 관점 전체 화면 점검 (복잡·불친절 목록)

- 방법: 앱을 직접 열지 않고 `app/src/shared/i18n/dict/*.ts`의 한국어 문구와 `renderer/features/*` 구성을 읽어 정리했다. 화면 배치는 확인 필요.
- 제외(1~5번에 이미 포함): 모바일 레이아웃, 직원 패널 장비·프로필 문구, @ 멘션 버그, 설정 탭 분류, 휴대폰·PC 연결.
- 코드는 고치지 않았다. 우선순위: 상 = 첫 사용에서 막힘/오해 위험, 중 = 헤맴, 하 = 다듬기.
