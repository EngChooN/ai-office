# 도우미 표시 화면 검수 — 2026-11-25 · 이디자

기준: `handoff.md`. 대상: 커밋 전 작업 폴더 코드. 코드는 고치지 않았습니다.

**어떻게 봤나**
- PC는 시험 앱(`~/claude-office-qa-jeong` 데이터, CDP 9447)을 띄워 확인했습니다.
- 휴대폰은 모바일 미리보기(가짜 셸) 360·320 폭에서 확인했습니다.
- 도우미 상태는 **가짜로 넣었습니다**. 3명은 도는 중이고, 1명은 끝난 상태입니다.
- 확인을 마친 뒤 시험 앱과 미리보기를 모두 껐습니다.

## 고쳐야 함
1. **휴대폰 따로 한 줄(HelpersBar) 맨 앞에 "·"가 혼자 붙습니다.**
   - 앞에 상태 글자가 없는데도 "· 도우미 3명과 함께"로 보입니다.
   - 따로 한 줄일 때는 점을 빼 주세요. 그림: `phone360-light-helperbar.png`
2. **휴대폰 320에서는 자리가 넉넉해도 "×3"으로 줄어듭니다.**
   - 따로 한 줄의 폭은 약 296인데, 기준이 320이라 늘 "×3"이 됩니다.
   - 실제 문구는 130~140폭이면 들어갑니다(4개 언어 측정).
   - 따로 한 줄은 기준을 낮추거나(예: 200) 줄이지 않는 쪽을 권합니다.
   - 상태 줄 안에 붙는 버튼은 지금 기준(320)을 그대로 둬도 됩니다.

## 괜찮음 (작은 제안)
3. 라이트 모드에서 끝난 줄은 전체 불투명도가 .7이라 초록 "끝남"이 흐립니다(대비 약 3:1, 추정). 줄은 흐리게 두더라도 "끝남" 글자만은 불투명도를 1로 두는 것을 권합니다. 이 .7은 제가 인수 자료에 적은 값입니다.
4. PC 장비 탭이 좁아서 경고 줄 끝의 "요."만 다음 줄로 넘어갑니다. 설명 줄의 "맡겨/요."도 마찬가지입니다. 앱 전체의 줄바꿈 방식이라 이번 기능만의 문제는 아닙니다. `word-break: keep-all`을 쓰면 낱말 단위로 넘어갑니다(선택).
5. 시안과 다른 점 2가지는 그대로 좋습니다. 스위치는 앱의 다른 스위치와 같은 크기이고 카드 전체를 눌러도 됩니다. 휴대폰 세로 화면에는 도우미 줄을 따로 한 줄로 넣었습니다.

## 확인 필요 (결함 아님, 추정)
- 휴대폰 미리보기에서 정리드 자리에 "2층 회의 중" 말 풍선이 떠 있으면 ×N이 그 밑에 가려 안 보였습니다. 설계대로 말 풍선이 먼저 보인 것입니다. 다만 말 풍선이 오래 떠 있는 상태라면 ×N이 계속 안 보입니다.
- PC 직원 패널의 도우미 줄은 진행 줄이 있을 때만 나옵니다. 지시 없이 스스로 일하는 중이면 안 보일 수 있습니다.
- 실제 휴대폰·안드로이드 앱에서는 보지 않았습니다.
