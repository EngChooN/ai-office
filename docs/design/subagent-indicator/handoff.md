# 도우미(서브에이전트) 사용 중 표시 — 개발 인수 자료

2026-11-25 · 이디자 → 정리드 · 시안: `subagent-indicator-v1.html` (캡처 `shot-1.png`, `shot-2.png`)

## 대표 확정 사항
- 사무실 표시: **A안 — 머리 위 말풍선 "×N"**
- 화면 이름: **"도우미"** (서브에이전트라는 말은 화면에 쓰지 않음. "분신"은 포크 기능 이름이라 피함)
- 휴대폰에서도 PC와 똑같이 켜고 끌 수 있음

## 공통 규칙
- N = **지금 동시에 일하는 도우미 수**(끝난 도우미 제외). 앱이 이 값을 셀 수 있는지는 **확인 못 함** → 정리드 확인 필요.
- **N ≤ 1이면 아무 표시도 하지 않음**(혼자 일할 때와 구분이 안 됨). N ≥ 2부터 표시.
- 설정이 꺼진 직원에게는 표시하지 않음.
- 업무 모드에서는 사무실 말풍선만 숨기고 카드·머리말 표시는 유지(제안, 대표 미확인).
- 색은 하드코딩하지 말고 **테마 토큰**을 씀(색 테마 5종 × 라이트·다크 모두 자동 대응). 아래 hex는 라벤더 테마 기준 확인용.

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `--primary` | `#6C5CE7` | `#9B8CFF` | 칩 글자·아이콘, 머리말 문구, 스위치 켬 |
| `--card` | `#FFFFFF` | `#201F2D` | 카드·머리말 바탕 |
| `--border` | `#DEDAF0` | `#34314A` | 스위치 끔, 구분선 |
| `--muted-foreground` | `#66627F` | `#A7A3C4` | 설명 글, 경과 시간 |
| `--status-working` | `#1C7C46` | `#4ADE80` | "끝남" 글자 |
| `--status-waiting` | `#9A5B00` | `#F2C94C` | 설정 경고 줄 (빨강 쓰지 않음) |

## 아이콘 "도우미" (새로 필요)
겹친 두 사람. 16×16 viewBox, `currentColor`. 뒷사람 불투명도 .45. 화면 크기 14×14. SVG 원본은 시안 HTML의 `<symbol id="helper">` 그대로 사용.

## ① 사무실 말풍선 (Phaser 캔버스)
- 위치: 직원 머리 위, 기존 감정 말풍선 자리(`y = -58`, 아래 가운데 기준). 이름표 위.
- 모양: 기존 감정 말풍선과 같은 틀 — 흰 바탕 `#FFFFFF`, 외곽선 `#2E2A40`(감정 말풍선 OUT 색) 2px, 모서리 깎음, 아래 꼬리, 오른쪽 아래 그림자 2px `rgba(0,0,0,.25)`.
- 내용: 도우미 아이콘 + "×N", 글자 `#4B3BC7` 굵게. 안쪽 여백 위아래 3 · 좌우 5, 아이콘-숫자 간격 3 (시안 확대 기준, 실제 크기에서 감정 말풍선과 높이를 맞춰 비율 조정).
- 사무실 캔버스는 앱 테마를 따르지 않으므로 **라이트·다크 같은 색**.
- 동작: 감정 말풍선과 달리 **사라지지 않고 계속 떠 있음**. 위아래 2px, 1.6초 주기로 천천히 흔들림.
- 겹칠 때: 감정 말풍선이 뜨는 동안 감정 말풍선을 먼저 보여 주고, 끝나면 "×N"으로 돌아옴(제안 — 시안에서는 "×N" 우선으로 적었으나 감정 연출이 짧아 이쪽이 자연스러움, 대표 미확인).
- N이 바뀌면 숫자만 바꿈. 0~1이 되면 서서히 사라짐.

## ② 직원 카드 · 업무 목록 줄 — 칩
- 높이 22 · 좌우 여백 8 · 모서리 완전 둥글게(999) · 아이콘-글자 간격 4 · 글자 12px 굵기 600 · 줄바꿈 금지.
- 바탕 `--primary` 14% (투명과 섞기), 테두리 1px `--primary` 35%, 글자 `--primary`.
- 직원 카드: 상태 글자("작업 중") **바로 옆**, 간격 6. 문구 = "도우미 N".
- 업무 목록 줄: **맨 오른쪽 고정**, 제목이 대신 말줄임(…). 문구 = "×N". 도우미가 없는 줄엔 칩 없음.

## ③ 채팅 · 업무 상세 머리말
- 상태 줄(12px, `--muted-foreground`)에 " · " 뒤로 이어 붙임: 아이콘 + "도우미 N명과 함께", `--primary` 굵기 600.
- 오른쪽 펼침 버튼: 높이 32, 최소 폭 44(휴대폰 손가락 크기), 기본 **접힘**.
- 펼친 목록: 머리말 아래 구분선 1px `--border`, 바탕 `--card`에 `--primary` 5% 섞음, 여백 위아래 8 · 좌우 14.
  - 한 줄: 높이 여백 5, 간격 8 — 번호 칸 22×22(모서리 7, `--primary` 18% 바탕, 글자 11px 굵게) · 회전 표시 10px · 도우미가 받은 일 제목(말줄임, **번역하지 않음**) · 경과 시간(`--muted-foreground`, 고정폭 숫자).
  - 끝난 도우미: 번호 자리에 ✓, 줄 전체 불투명도 .7, 오른쪽에 "끝남"(`--status-working` 굵게). 끝난 줄은 펼침 안에서만 보임.
- 모두 끝나면 상태 줄의 문구는 사라지고, 펼침에 "도우미 N명이 끝냈어요"만 잠깐 남김.
- 휴대폰 폭 360: 4개 언어 모두 한 줄 안에 들어감(시안에서 확인). **320에서 넘치면** 문구 대신 "×N" 칩으로 바꿈.

## ④ 직원 설정 — 켜기 스위치 (PC·휴대폰 동일)
- 카드: 여백 14 / 16, 모서리 18. 제목 14px 굵게, 설명 12px `--muted-foreground`, 제목-설명 간격 2.
- 스위치: 44×26, 손잡이 20 흰색, 안쪽 3. 켬 `--primary`, 끔 `--border`. **줄 전체를 눌러도 켜지고 꺼짐.**
- 경고 줄: 설명 아래 8, ⚠ + 문구, 12px 굵기 600, `--status-waiting`. 켜짐·꺼짐 상관없이 항상 보임.
- 켤 때 확인 창은 두지 않음(경고가 늘 보이므로).
