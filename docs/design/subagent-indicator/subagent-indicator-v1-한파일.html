추천 조합 (대표 미확인) — ① 사무실: A안 머리 위 말풍선 "×3" · ② 카드·목록: 칩 "도우미 3" (아주 좁으면 "×3") · ③ 머리말: 상태 줄에 "도우미 3명과 함께" + 눌러서 각 도우미가 뭘 하는지 펼치기 · ④ 설정: 스위치 + 노란 경고 한 줄.
이유: 사무실에 이미 있는 감정 말풍선(💡❤️🎵)과 같은 모양이라 새로 배울 게 없고, 작은 화면·작은 캐릭터에서도 숫자가 읽힙니다. "3/5"는 전체 개수를 미리 알 수 없어(추정) 틀린 숫자가 나올 위험이 있습니다.
이름 제안: 화면에는 "서브에이전트" 대신 "도우미"(Helpers · ヘルパー · 助手). "분신"은 외부 직원 포크에 이미 쓰고 있어 피했습니다.

인계개발에 넘길 때 필요한 것 (확정 후)

· 도우미 수 = "지금 동시에 일하는 도우미 수"(끝난 것 제외) — 이 숫자를 앱이 실제로 알 수 있는지는 확인 못 함(정리드 확인 필요).
· 칩 색: 테마 --primary 14% 배경 + 35% 테두리, 글자 --primary. 사무실 말풍선: 흰 바탕 + 2px 진한 테두리(기존 감정 말풍선 규격 따름).
· 문구 키 예: 도우미 N / ×N / 도우미 N명과 함께 / 설정 제목·설명·경고 — 4개 언어 위 시안 문구 그대로.
· 표시하지 않는 경우: 도우미 0~1명, 설정이 꺼진 직원, 업무 모드에서는 사무실 그림 표시만 숨김(카드·머리말은 유지) — 제안.
