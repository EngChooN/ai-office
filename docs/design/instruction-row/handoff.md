## 앞머리·끝머리 나누기 (보이는 모양만, 저장 글은 그대로)
- 맨 앞 `[○○의 도움 요청]` / `[○○의 지시]` / `[업무 매뉴얼: ○○]` → **보낸 곳 칩**: 11px, 높이 18px, 둥근 끝, 테두리 `--border`, 바탕 `--card`, 글자 `--muted-foreground`. 안에 13px 동그라미(첫 글자, 도움 요청·지시는 `--accent-a`, 매뉴얼은 `--status-waiting`) + **이름(굵게, `--foreground`)** + `· 도움 요청`/`· 지시`/`· 주간 보고(매뉴얼 이름)`.
  - 4개 언어 원문 형식: `staff.msg.helpRequest`, `staff.msg.delegated` 사전 값 참고 (en `[Help request from X]`, ja `[Xからの助けの依頼]`, zh `[X 的求助]` 등).
- 칩 바로 뒤 `[제목]`이 있으면 → 칩 옆 **굵은 제목** 12.5px (괄호 뗌).
- 맨 끝 `(끝나면 결과를 ○○에게 보고하세요)` → 본문 아래 **작은 회색 안내** 11px `↩ 끝나면 ○○에게 보고`.
- 앞머리가 없으면(대표가 직접 쓴 지시) 칩 없이 배지만.
- 매뉴얼 지시의 `"○○" 스킬(매뉴얼)을 사용해서 처리해 주세요.` 문장은 칩이 대신하므로 숨기는 것을 제안(정리드 판단).

## 긴 지시 접기
- 본문이 4줄을 넘으면 4줄까지만(끝에 …) + 아래 `더 보기 (N줄) ▾`(11.5px, 주 색, 굵기 500). 펼치면 `접기 ▴`.
- 접힘 상태는 화면에서만 기억(새로 열면 접힘). 대표가 방금 보낸 지시도 접힘으로 시작하는 것을 제안.
- 'N줄'은 계산이 어려우면 숫자 없이 `더 보기`만 써도 됩니다.
