④ 리본 버튼 1차

구현 메모 (정리드님께)

  1. 한 장의 캔버스: 화면마다 눈송이 DOM을 만들지 말고, 투명 <canvas> 하나에 그립니다. pointer-events:none, aria-hidden="true". ①은 앱 바탕 바로 위·내용 아래(z-index), ②는 사무실 캔버스 위에 같은 방식으로 한 장 더.
  2. 켜기·끄기 설정: snowEffect: 'off' | 'light' | 'normal' 하나로 저장(기본 'light', 추천안). 크리스마스 묶음 테마일 때만 설정 줄을 보여 주고 효과도 그때만 돕니다. 다른 테마로 바꾸면 값은 남겨 두되 효과는 멈춤.
  3. 움직임 줄이기: matchMedia('(prefers-reduced-motion: reduce)')가 켜져 있으면 움직이지 않고 멈춘 눈을 한 번만 그리고 끝(수는 절반). 설정을 바꾸면 바로 따라가도록 change 이벤트를 듣습니다. 앱에 이미 같은 방식이 있습니다(LiveMiniView, levelUpFx).
  4. 가볍게 돌리기
    • 눈송이 수 = 화면 넓이 × 밀도, 그리고 상한: 약하게 40 / 보통 80. 휴대폰(좁은 화면·터치)은 상한을 절반.
    • 휴대폰·저사양은 초당 30장으로 제한(프레임 하나 건너 그리기). 데스크톱은 60.
    • 캔버스 해상도는 기기 배율을 최대 1.5배까지만(눈은 작아서 차이가 안 보임).
    • 창이 숨겨지거나(visibilitychange) 화면 밖이면(IntersectionObserver) 멈춤.
    • 그림자·블러 금지. 동그라미 두 겹(몸통 색 + 가운데 흰 점)과 결정 모양은 선 3개로.
    • 프레임이 계속 느리면(예: 2초 평균 24장 미만) 눈송이 수를 자동으로 절반으로.
  5. 움직임: 위에서 아래로 일정 속도 + 좌우로 살짝 흔들림(사인파, 폭 6~20px) + 아주 약한 바람. 바닥에 닿으면 위에서 다시 시작. 쌓이는 효과는 없음.
  6. 설정 견본 맛보기(③): 캔버스 없이 CSS만 — 견본 동그라미 안 점 무늬 배경을 6초에 한 번 아래로 흘림. 움직임 줄이기면 멈춤. 이 시안의 .sw.snowy 그대로 쓰면 됩니다.
  7. 색 토큰: 테마 블록에 --snow-core, --snow-edge, --snow-alt(섞이는 테마 색 눈, 약 30%) 추가. 값은 아래 개발 전달 CSS에 들어 있습니다. 캔버스는 시작할 때와 테마가 바뀔 때 이 값을 읽어 씁니다.
  8. 참고 코드: 이 시안 파일 맨 아래 <script>의 Snow가 위 규칙대로 만든 견본입니다(디자인 확인용, 그대로 쓰지 않아도 됨).
