## 고른 이유(시안에 적은 근거, 대표가 별도 이유를 말하지는 않음)
- ① 이미 쓰는 화면이라 새로 배울 게 없고 칸 폭이 그대로다.
- ② 직원 화면의 개수 타일과 같은 틀이라 익숙하고, 한 번 내려 보면 전부 보인다.
- ③ '대표가 할 일은 위 노란 띠'로 결재 띠와 통일되고 공간을 적게 쓴다.
- ④ 직원 상태색(초록·노랑·회색·빨강)과 겹치지 않아 '대기'·'오류'로 잘못 읽히지 않는다. 안드로이드 주황 강조색·노을 테마와도 안 겹친다. 글자+아이콘이라 색 구별이 어려워도 보인다.
- ⑤ 사무실에서도 '누가 나를 기다리나'만 보이고, 기존 그림을 재사용한다.

## 고르지 않은 안을 뺀 이유(시안 기준)
- ①B 칸반과 다른 화면이 생김 / ①C 일의 흐름이 덜 보임
- ②B 다른 상태를 보려면 매번 눌러야 함, 360폭에 탭 5개 빠듯 / ②C 접힌 안에 재검토 표시가 숨음
- ③B 높이를 더 차지, 휴대폰은 옆으로 넘겨야 함 / ③C 대기 카드가 흩어짐
- ④B 주황 버튼·노란 대기 표시와 헷갈림 / ④C 빨강이 오류로 읽히고 카드가 높아짐
- ⑤B 사무실을 볼 때 대기를 놓침 / ⑤C 말풍선이 겹치고 대기가 묻힘

## 개발 전달 기준 (확정된 안 기준)
- 상태 칩: 높이 20px, 글자 11px 굵게, 점 7px. 할 일 status-idle, 진행 중 status-working, 대표 응답 대기 status-waiting(연한 노랑 바탕·노랑 테두리), 검토 중 primary, 완료 status-working 점. 이름은 `workStatus.state.*` 문구.
- 대기 시간: `waitLabel` 문구 그대로, status-waiting 굵게 11px, 1분마다 새로 그림(`useNow`).
- 대기 띠(데스크톱): 보드 맨 위 높이 36px, 둥근 10px, 노랑 테두리·연한 노랑 바탕, 왼쪽 '!' 원(20px) + "대표 응답 대기 N건" + 일 칩(제목 + 대기 시간) 오래된 순, 넘치면 '+N건', 오른쪽 '모두 보기 ›'. 0건이면 띠를 숨김. `ApprovalBand` 선례.
- 대기 줄(안드로이드): 개수 타일 아래 고정, 두 줄(건수 / 가장 오래된 일 · 대기 시간), 누르는 높이 48dp 이상, 누르면 대기 목록.
- 재검토 칩: 서버 값이 '필요'일 때만. '아님'·'판단 불가'는 표시 없음. 높이 18~20px, 1.5px 파랑 테두리·연한 파랑 바탕·파랑 글자, ↻ 아이콘 11px. 완료 카드는 제목·담당만 불투명도 .6, 칩은 흐리지 않음. 안드로이드에는 파랑 색 값을 새로 추가.
- 안드로이드: 카드 모서리 12dp, OfficeCard·StatusBadge·SummaryTiles 재사용(최가독 조사), 타일은 대기·진행 중·검토 중·완료 4개, 대기 타일은 노랑 강조.
- 사무실 말풍선: `emoteArt` 감정 말풍선 틀 + `ask` 아이콘, 대기 동안 사라지지 않음, 마우스를 올리면 설명 상자(직원 이름 · 대표 응답 대기 / 일 이름 · 대기 시간). 다른 상태는 띄우지 않음.
