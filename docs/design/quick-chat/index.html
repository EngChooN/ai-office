최근 3명이 회색 '방문' 이름표와 대화 제목 앞부분을 달고, 빈 바닥을 천천히 걸어 다닙니다(조금 흐리게). 나머지는 '+N'.

좋은 점 누가 어떤 대화인지 바로 보입니다. 아쉬운 점 이름표가 늘어 정식 직원 이름표·말풍선과 겹치기 쉽습니다(이 시안에서도 겹침 주의).

세 안 공통 규칙

  • 책상·자리를 차지하지 않음. 책상 수·회사 레벨에 영향 없음.
  • 사무실에 그리는 방문자는 최근 3명까지, 나머지는 '+N'.
  • 방문자를 다시 열면 '대화 중' 점선 동그라미로 옮겨 감. 지난 대화를 삭제하면 방문자도 사라짐.
  • 결재 '!'·말풍선은 대화 중 임시 직원에게만 뜸. 방문자는 띄우지 않음.
  • 업무 모드(게임 요소 숨김)에서는 직원 목록 맨 아래 '임시·방문자' 한 줄로만 보임.

개발 전달 기준 (대표 확정 뒤 정리드님께)

색·모양

  • 임시 직원 강조색: 라이트 #0B6DA1 / 바탕 #E3F2FB, 다크 #5CC8FF / #16303F — 지금 앱의 정보(파랑) 색을 그대로 씀. GPT 이름표만 초록(#0F7B63/#E2F5EF, 다크 #4FD1B0/#123029).
  • 임시 = 1.5px 점선 테두리(버튼·이름표·아바타·사무실 이름표). 정식 직원 요소에는 점선을 쓰지 않음.
  • 시작 카드: 폭 208, 모서리 14, 고른 카드 2px 주색 테두리 + 4px 옅은 링 + 오른쪽 위 체크.
  • 모델 칩: 높이 30(휴대폰 40), 알약 모양, 로고 16px. 펼친 목록 폭 250, Claude/GPT 묶음 제목 아래 모델.
  • 휴대폰 누르는 곳은 모두 44px 이상.

동작

  • 진입: 대화방 목록 맨 위 '＋ 빠른 대화' / 휴대폰은 방 고르기 목록 맨 위. 빠른 대화 세션은 목록 맨 아래 '빠른 대화' 묶음(최근 3 + 모두 보기).
  • 시작: Claude/GPT 중 하나 필수. 작업 폴더는 선택(안 골라도 경고·차단 없음). '파일 고칠 때: 매번 묻기 / 자동 허용' 작은 전환 단추, 기본 매번 묻기. 같은 설정을 설정 화면 '빠른 대화' 칸에도 둠. 로그인 안 된 쪽 카드는 흐리게 + '로그인 필요'.
  • 지난 대화: 지우기 전까지 계속 보관. 데스크톱은 마우스 올리면 휴지통, 휴대폰은 왼쪽으로 밀어 삭제. 확인 문구에 '앱의 대화 기록과 세션 파일을 함께 지웁니다' 명시. 작업 폴더 파일은 건드리지 않음.
  • 모델 바꾸기: 같은 쪽 안에서는 대화 그대로. Claude↔GPT 전환은 요약을 넘긴다는 안내(대화 안 회색 줄) 표시.
  • 끝내기: 닫기 = 일 멈춤 + 기록 보관 + 사무실 방문자로 남김 / 채용하기 = 고용 창을 미리 채워 열기.
  • 사무실: 대화 중은 계단 입구 옆 점선 동그라미. 끝난 대화는 방문자(⑤ A·B·C 중 대표가 고른 안). 자리 차지 안 함, 최근 3명 + '+N'.

정하지 않은 것 (구현 전에 확인 필요)

  • GPT 쪽 모델 목록 — 지금 앱 코드에서 GPT 모델 이름 목록을 찾지 못해 '기본' 하나만 그렸습니다.
  • Claude↔GPT 전환 때 기억을 실제로 어떻게 넘길지(요약 넘김은 이디자 제안, 대표 미확인).
  • 방문자 배지 A·B·C 중 어느 안으로 갈지(A는 이디자 추천, 대표 미확인).
  • 임시 직원 비용을 급여 명세서·예산 한도에 어떻게 넣을지.
  • 영어·일본어·중국어 긴 문구, 실제 앱 반영 화면은 아직 보지 않았습니다.
