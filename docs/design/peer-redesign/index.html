상태와 동작 기준

원격이 꺼져 있으면 역할 버튼을 비활성화하고 원격 켜기에서 기존 원격 가이드로 이동합니다. 네트워크는 확인 가능한 상태만 표시하고, 판별하지 못하면 사용자에게 확인을 안내합니다. 연결 정보는 주소와 코드를 함께 복사하고 한 칸에서 해석합니다. 직접 입력과 보안 확인값은 접어 둡니다. 시간 만료 시 새 정보 생성으로 이어집니다. 성공하면 해당 PC의 직원 고르기를 엽니다. 오류 이름 접두어는 표시하지 않고 상황별 다음 행동을 보여 줍니다.

시안의 코드·주소·직원은 예시이며 버튼은 동작하지 않습니다. 네트워크 자동 판별과 오류별 실제 분류, 원격 가이드 연결 방식은 개발 확인이 필요합니다. 모바일 화면은 표시하지 않습니다.
