개발 전달 기준

시각 예시이며 버튼과 QR은 실제로 동작하지 않습니다.

배치와 모양

  • 기존 카드·대화상자·배지와 테마 토큰을 재사용합니다. 예시는 라벤더 라이트입니다.
  • 카드 안쪽 여백 20px, 요소 간 8~16px, 모서리 12~16px을 기준으로 기존 구성 요소에 맞춥니다.
  • 좁은 창과 휴대폰에서는 한 열로 배치하고, 긴 파일명은 줄바꿈해 끝까지 볼 수 있게 합니다.
  • 지도 직원 모습은 기존 캐릭터를 사용합니다. 이 시안의 글자 아바타는 자리 표시입니다.

상태와 확인

  • IP와 코드 입력, 코드 만료, 카메라 권한·실패, 연결 중·실패·재연결을 구분합니다.
  • 직원 선택은 선택 수를 표시하고 0명일 때 추가를 막습니다. 원격·연결 끊김은 글자와 색으로 함께 표시합니다.
  • 연결 대기 취소와 만료 후 처리는 실제 구현에서 명확히 확인합니다. 대기 시간은 설계 초기값입니다.
  • 충돌 시 전체 반영을 막는 표현은 보수적 시안입니다. 해결 흐름과 부분 반영 가능 여부는 개발 검토가 필요합니다.
  • 키보드 초점, 라이트·다크와 6개 테마, 4개 언어, 실제 PC·휴대폰을 구현 후 확인합니다.
