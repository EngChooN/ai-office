용어를 다룰 때 지킬 점

  • ‘AI 서비스’는 Claude·Codex 같은 선택을 뜻하고, 모델은 그 안의 구체적인 이름이므로 하나로 합치지 않습니다.
  • 연결 도구는 MCP로 구현되어도 사용자가 연결하는 서비스와 사용 가능 상태를 먼저 보여 줍니다.
  • 자동 허용과 금지는 서로 다른 설정입니다. ‘안전’ 같은 모호한 말로 묶지 않습니다.

적용 시 반드시 함께 보여 줄 정보

  • AI 서비스 변경은 연결 상태·변경 가능 조건과 대화가 새로 시작된다는 확인이 필요합니다.
  • 모델은 다음 지시부터 적용됩니다. 장비 변경은 현재 일을 마친 뒤 다음 지시부터 적용됩니다.
  • 휴대폰에서 바꿀 수 없는 권한과 서비스별로 다른 옵션은 해당 조건을 그대로 알립니다.
