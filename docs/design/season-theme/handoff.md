# 계절·테마 가구 디자인 인계

2026-11-15 · 이디자 · 중간 시안 `furniture-concept.png`. 실제 앱 캡처가 아닌 생성 이미지이며 개별 투명 스프라이트나 최종 등록본이 아니다. 좌→우, 위→아래: 벚꽃 화분, 비치 파라솔, 수박 주스 바, 단풍나무, 벽걸이 액자, 벽시계, 샹들리에, 한지 등, 다도 테이블, 우주 관제 콘솔, 책상 미니 화분, 업적 트로피 선반.

기존 사무실은 밝은 파스텔과 보라 포인트, 2:1 비스듬한 시점, 작은 픽셀 단위의 외곽과 명암을 사용한다. 시안은 분위기 참고용이며 실제보다 세부가 많다. 기존 가구 크기와 선 두께에 맞춰 단순화하고, 기존 벚꽃나무와 새 벚꽃 화분의 크기·형태를 구분한다. 기획의 12종 중 별도 해변 테마 가구는 파라솔과 수박 주스 바를 활용하는 제안이다. 봄·여름·가을 한정과 상시 해변 세트가 같은 품목을 공유할지, 세트 완성 조건과 판매 시기·가격은 기획 및 기존 규칙을 확인해 정한다.

개발 담당: 기존 `isoArt.ts`의 품목 정의와 `shared/iso/furniture.ts`의 크기·방향 규격, 상점 품목·세트 및 각 언어 이름·설명을 함께 연결한다. 기존 방식은 네 방향을 생성한다. 시계의 실제 시간 표시, 벽·천장 배치, 책상 위 배치, 트로피의 실제 업적 연동은 그림만으로 완성되지 않으므로 데이터·배치·동작 지원을 확인하고 불가능한 부분을 별도 보고한다. 자동으로 업적을 달성한 듯 보이게 하거나 시계가 실시간으로 움직인다고 단정하지 않는다. 시안의 의자·방석·장식은 형태 참고이며 추가 품목으로 약속하지 않는다.

기존 봄(3월 15일~4월 30일)과 가을(10월 1일~11월 30일) 판매 기간이 정의되어 있고 여름은 확인한 부분에 없다. 기간과 세트 구성이 적절한지는 담당자 확인 필요. 업적 부분, 박패턴이 작업 중인 지도·창 그림, 다른 사람의 미커밋 변경은 건드리지 않는다. 실제 배치 후 네 방향·겹침·선택·저장 및 다시 열기·상점·계절 경계·언어 이름을 확인하고, 12종을 사무실에 놓은 실제 스크린샷과 타입 검사·관련 테스트 결과를 남긴다. 동시 작업 중인 파일은 소유자와 조율한다.

생성 도구: 내장 이미지 생성 도구. 요청: 기존 사무실 이미지를 참고해 파스텔 픽셀아트, 2:1 시점의 위 12종을 글자 없이 4×3으로 보여 주는 중간 시안. 제품 코드·테스트는 이 작업에서 변경하거나 실행하지 않았다.
