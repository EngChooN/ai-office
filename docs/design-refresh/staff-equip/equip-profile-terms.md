- 3칸 [막기·결재 받기·결재 없이] ↔ 지금 묶음: 인터넷 검색 = 웹 금지/없음/웹 자율, 프로그램 실행 = 프로그램 실행 금지/없음/프로그램 실행 자율. '보기만 하는 실행은 결재 없이' = 읽기만 자율, '위험한 것은 항상 막기' = 위험한 실행 금지.
- 파일 만들기·고치기, 화면 찍기는 지금 '막기' 묶음이 없어 2칸만 둠(새 기능 아님).
- 맡기는 정도 3단계(2안·3안)는 새 묶음 제안: 하나하나 확인 = 묶음 모두 끔 / 보통 = 파일 수정 자율 + 웹 자율 + 위험한 실행 금지 / 믿고 맡기기 = 보통 + 프로그램 실행 자율. 세부를 직접 바꾸면 '직접 고름'으로 표시.
- 휴대폰에서 PC 전용인 항목(도구 권한·작업 폴더·브라우저 자동 허용·공용 로그인·직접 추가)은 지금처럼 🔒 PC 표시.

- 프로필 '결재 방식: 수정은 자율'(approvalMode acceptEdits)과 장비 '파일 수정 자율'(allowedTools Edit/Write…)이 실제로 같은 효과인지. 같으면 한 곳(장비)으로 합치기 제안.
