# 업데이트 소식 개선 — 최종 설계 (정리드, 2026-11-12)

근거: brief.md · plan-writing.md(김기획) · design-readable.md(최가독) · design-pattern.md(박패턴) · design-view.md(이디자)
대표 결정(2026-11-12): G1 지난 버전 한 줄 접기 · G2 새 버전 카드에서 바로 설치 · G3 건너뛴 버전은 보이되 힘 뺌 · G4 여러 버전은 카드 하나로 묶기

## 1. 작성 형식 (CHANGELOG 4개 언어 · release-notes)
```
## [1.3.0] - 2026-11-12
PC 앱 전용: …            ← 있을 때만 한 줄 (### 앞 본문 = 기기 안내)

### 한눈에 보기          (en At a glance · ja ひと目で · zh 一览)
- **새 기능** 내 PC 여러 대를 연결해 오가요
- **개선** …
- **수정** …

### 새 기능 / ### 개선 / ### 버그 수정   ← 상세 (김기획 규칙: 1~2문장, 5·4·4개 이하)
```
- 요약 줄 앞 종류 말은 굵은 말. ko 새 기능/개선/수정 · en New/Better/Fixed · ja 新機能/改善/修正 · zh 新功能/改进/修复(이디자 배지 글자와 같음). 화면은 이 말을 뽑아 배지로 바꾼다.
- 김기획 작성 규칙(줄 수·길이·넣지 않는 것·구분 기준)을 CHANGELOG 머리말 '쓰는 규칙'에 옮긴다.
- 요약 필수: **1.3.0부터**(아직 게시 전이라 다시 씀). 1.2.0 이하는 그대로 둔다(소급 없음).

## 2. 선택과 이유
| 쟁점 | 선택 | 이유 / 채택하지 않은 안 |
|---|---|---|
| 요약 소제목 | `한눈에 보기` (김기획) | 대표 말 "한눈에"와 같고 쉬운 말. `요약`·`핵심`도 무난하나 화면엔 소제목을 안 보이므로 작성자에게 뜻이 분명한 쪽 |
| 종류 표시 | 굵은 말 `**새 기능**` (박패턴) | md로 읽어도 자연스럽고 파싱이 확실. 김기획 `새 기능 · `는 구분 기호가 본문과 섞일 수 있음. 최가독 '표시 없음'은 대표 요구(한눈 구분)에 약함 |
| 다음 버전 출처 | `latest` 확인은 그대로, 새 버전 발견 때만 `releases?per_page=10` 별도 조회 (박패턴) | 자체 업데이트 경로를 건드리지 않음. 최가독 '목록으로 교체'는 호출 수는 같지만 설치 경로 위험 |
| 넘기는 모양 | `UpdateStatus.news: Release[]`(main이 언어 섹션 고르고 파싱·크기 제한) | 화면이 마크다운 원문을 다루지 않음. 새 IPC 채널 없음. 설치 진행률 emit(최대 100회)에 실려도 수십 KB라 허용 |
| 원격 글 표시 | `Markdown`에 `isUntrusted` — 링크·이미지·화면 이동을 글자만 남김 (박패턴) | 저장소 계정 탈취 대비, 비용 prop 1개 |
| 화면 | 이디자 안 그대로: 머리줄 종류별 개수, 요약 배지, "바뀐 점 n가지 모두 보기", 지난 버전 한 줄, 새 버전 카드에 [지금 업데이트] | 대표 G1~G4 확정 |
| 개선 아이콘 | 듀오톤 `improve` 추가 | 지금은 🔧도 벌레 아이콘이라 개선·수정 구분이 안 됨 |
| 범위 밖 | 안내 창(AppUpdate) 요약화, 휴대폰 앱 다음 버전 소식, 1.2.0 이하 소급 | 세 안 모두 후속으로 봄 |

## 3. 구현 (정리드)
- `shared/changelogParse.ts`: `summary` 종류·4개 제목, `parseSections` 추출, `summaryItems`(굵은 말 → 종류)
- `shared/updateCheck.ts`: `RELEASES_API_URL`, `UpdateStatus.news`, 순수 함수 `parseNewsList`
- `main/updates.ts`: `available`이 되면 그 버전 소식을 한 번 읽어 둠(실패는 조용히, 다음 확인 때 다시)
- `renderer`: `UpdatesPage`(새 버전 카드·버전 카드·지난 버전 줄), `ReleaseNotes`(WhatsNew 공용), `markdown.tsx` `isUntrusted`, `MoreToggle` 문구 prop, 아이콘 `improve`, 사전 키
- 시험: `changelog.test`(요약 첫 섹션·3~5줄·종류 말 4개 언어 일치·1.3.0부터 필수), `updateCheck.test`(parseNewsList)
- CHANGELOG 4개 언어·`docs/release-notes/1.3.0.md`: 1.3.0을 새 규칙으로 다시 씀(김버전과 조율 — 버전 반영 커밋·형식 시험은 김버전)
