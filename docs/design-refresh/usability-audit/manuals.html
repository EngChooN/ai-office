매뉴얼 추가 화면 개편 시안

왼쪽: '+ 새 매뉴얼'을 누르면 만드는 방법 3갈래가 먼저 나옵니다. '말로 설명해서 만들기'가 맨 앞의 큰 칸이고 직원이 0명이어도 보입니다. 오른쪽: 직접 만들기 창은 한글 '매뉴얼 이름'만 받고 내부 이름은 앱이 만듭니다. 저장이 막히면 아래에 이유와 빈 칸 바로가기를 한 줄로 보여 줍니다. 단계마다 '다시 보내기·최대 횟수'는 '이 단계 설정'으로 접었습니다. 근거는 김기획 사용성 분석(audit.md) 1부·우선순위 1~4번이고, 용어는 glossary.md를 따랐습니다.

① 만드는 방법 고르기 (진입 3갈래)

목록 위 버튼을 '+ 새 매뉴얼' 하나로 합칩니다. 누르면 이 창이 뜨고, 종류(한 명/여러 명)는 방법을 고른 다음에 묻거나 AI가 정합니다.

바뀌는 점

  • 말로 설명해서 만들기(맨 앞·추천): 한 칸에 적고 '초안 만들기'를 누르면 AI가 종류·이름·설명·단계를 채운 ② 편집 창이 열립니다. 쓰는 AI는 기본값이 '앱 기본 AI'입니다. 직원이 0명이어도 이 칸은 그대로 보입니다. 직원에게 맡기려면 '쓰는 AI 바꾸기'에서 고릅니다.
  • 예시에서 고르기: 자주 쓰는 업무 4개를 바로 보여 주고, '예시 8개 모두 보기'로 ④를 엽니다.
  • 직접 만들기: 종류를 버튼 이름 대신 질문으로 고릅니다. 예시를 한 줄씩 달았습니다.
  • 목록 카드 제목은 한글 이름이고, 내부 이름은 작은 글씨로 둡니다. 아직 아무에게도 {{teach}}하지 않은 매뉴얼은 노란 표시로 알립니다.
  • 목록이 비어 있을 때도 이 3갈래를 페이지 안에 그대로 펼쳐 보여 줍니다(빈 화면 안내 겸용).

정리드 확인

  • 직원 없이 '앱 기본 AI'로 초안을 만들 수 있는지 확인이 필요합니다. 지금 초안 기능은 직원을 골라야 합니다.

② 직접 만들기 창 — 한글 이름 · 저장 막힘 이유

기본으로 펼쳐 두는 칸은 매뉴얼 이름, 언제 쓰나요, 단계(무엇을·누가·지시)뿐입니다. 나머지는 단계 카드 안 '이 단계 설정'과 맨 아래 '더 자세히 설정'으로 접습니다. 이 그림은 '여러 명이 이어서 하는 업무'에서 칸 2개가 빈 상태입니다.

이름

  • 사용자는 매뉴얼 이름만 한글로 자유롭게 씁니다.
  • 칸 아래에 앱이 만든 내부 이름(영문 소문자·숫자·하이픈)을 작게 보여 줍니다. 직접 고치려면 '더 자세히 설정'에서 바꿉니다.
  • 내부 이름이 다른 매뉴얼과 겹치면 앱이 뒤에 -2를 붙입니다. 이 때문에 저장이 막히지는 않습니다.

저장이 막힐 때

  • 저장 버튼은 흐리게 두고, 바로 왼쪽에 이유를 한 줄로 씁니다. "저장하려면 N곳을 채워 주세요: [언제 쓰나요] [2단계 지시]"
  • [ ] 부분을 누르면 해당 칸으로 이동하고 칸이 빨갛게 표시됩니다. 빈 칸 아래에도 한 줄 안내를 붙입니다.
  • 다 채우면 같은 자리에 "저장할 수 있어요"가 초록색으로 뜹니다.
  • '언제 쓰나요' 설명은 입력하면 사라지는 회색 예시 글자에 두지 않고, 칸 아래에 늘 보이게 둡니다.

단계

  • '맡을 역할'은 '누가 하나요(직무)'로 바꾸고 직무 칩으로 고릅니다. 직원이 없어도 기본 직무 칩(개발자·디자이너·기획자·검토자)이 보입니다.
  • 칸 아래에 흐름 미리보기를 한 줄 둡니다. 다시 보내기가 있으면 ↩로 표시합니다.

③ '이 단계 설정'과 '더 자세히 설정'을 펼친 모습

'수정 필요하면 [되돌리지 않음]'과 '최대 N번'은 단계 카드 안 '이 단계 설정'에 접고, 문장으로 풀어 설명을 붙였습니다. 저장 위치·내부 이름·공통 안내는 '더 자세히 설정'으로 내렸습니다.

단계 설정 문구 (현재 → 시안)

  • 끝나면 내 확인 🙋 → 끝나면 내가 확인하기 + "결재함에 올라와요. 내가 승인해야 다음 단계로 넘어가요."
  • 수정 필요하면 [되돌리지 않음 ▾] → 고칠 게 있으면 [○단계로 다시 보내기 ▾] + "이 단계 담당이 '고쳐야 해요'라고 판단하면 고른 단계부터 다시 해요."
  • 최대 [2] 번 → 다시 보내기는 최대 [2]번까지 + "넘으면 멈추고 나에게 확인을 물어봐요." (현재 앱 동작 그대로, office.ts 확인)
  • 첫 단계에는 되돌아갈 앞 단계가 없으므로 '다시 보내기'를 아예 숨깁니다.
  • 접혀 있을 때도 요약 한 줄로 지금 값을 보여 줍니다. 예: "내 확인 켬 · 1단계로 다시 보내기(최대 2번)"

더 자세히 설정

  • 어디서 쓰나요: 모든 일에서 (추천) / 특정 폴더 일에서만. 기본값을 '모든 일에서'로 바꾸자는 audit 5번은 이번 범위 밖이라 표시만 했습니다.
  • 내부 이름: 앱이 만든 값이 미리 들어 있고, 고치면 그 자리에서 규칙을 검사합니다.
  • 공통 안내: 모든 단계 담당에게 같이 전할 말입니다(선택).
  • 열고 닫는 방식은 채용 창의 '자세히 설정 / 간단히 보기'와 같습니다.

④ 예시에서 고르기

예시를 고르면 이름·설명·단계가 채워진 ② 창이 열립니다. 예시마다 몇 단계인지, 누가 하는지를 미리 보여 줍니다. 목록은 audit 1-4의 후보를 바탕으로 만든 예시이고, 문구는 기획 확정이 필요합니다.

규칙

  • 위쪽 칩으로 '한 명이 / 여러 명이'를 나눠 볼 수 있습니다.
  • 카드를 누르면 오른쪽에 단계 미리보기가 나오고, '이걸로 시작'을 누르면 ② 창이 열립니다.
  • 예시의 직무 칩은 내 회사에 없는 직무여도 그대로 둡니다. 이 경우 ② 창에서 "이 직무의 직원이 아직 없어요 · 채용하기"를 보여 줍니다(실제 동작은 확인 필요).

정해야 할 것

  • 예시 8개의 이름과 단계 문구는 김기획이 확정해야 합니다.
  • 예시를 앱에 넣어 둘지, 직원 마켓처럼 받아 올지 정해야 합니다.

⑤ 저장 직후 — '{{teach}}'로 바로 이어 가기

'교육'이라는 말을 '{{teach}}'로 바꿨습니다. 저장하면 창을 닫지 않고, 같은 창에서 누가 이 매뉴얼을 쓸지 고르게 합니다. 여러 명이 이어서 하는 업무는 랩·팀을, 한 명이 하는 업무는 직원을 고릅니다.

용어 (현재 → 시안)

  • 교육 / 교육하기 → {{teach}} / N곳에 {{teach}}
  • 🎓 교육 0 (목록 카드) → {{taught}} 곳 0. 0이면 노란색 "아직 아무도 안 써요"를 표시합니다.
  • 교육받은 직원만 이 매뉴얼을 꺼내 써요 → {{taught}} 직원만 이 순서대로 일해요.
  • 칩만 쓰던 것을 체크 상자가 있는 줄로 바꿔, 골랐는지 아닌지 테두리 색 말고도 알 수 있게 했습니다.

흐름

  • 저장 → 완료 표시 → 고르기 → '{{teach}}' → 목록으로 돌아갑니다.
  • '나중에'를 누르면 목록 카드에 "아직 아무도 안 써요 · {{teach}}" 버튼이 남습니다.
  • '모두에게 {{teach}}'는 맨 위 한 줄로 둡니다. 추천 표시 여부는 정해야 합니다.

용어 메모

  • 지시대로 '{{teach}}'를 썼습니다. audit 1-2의 '쓸 수 있게 하기'를 쓰려면 TERMS 한 곳만 바꾸면 됩니다.
