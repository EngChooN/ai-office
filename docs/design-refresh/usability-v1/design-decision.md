## 공유 후 보완(설계자 회신 반영)
- 15. **편집 창 닫기 유실 확인**(박패턴): `isDirty(form, initial)`이면 닫을 때 확인. 3갈래 창의 요청 문장은 초안 실패·되돌아오기 때 지우지 않는다.
- 16. **초안 중 창 닫기**(박패턴): 호출은 취소하지 않되 닫힌 뒤 결과가 오면 편집 창을 열지 않는다. 시험 1건 추가.
- 17. **직원 `''` 원격 통과**(최가독): `v2.ts` 검증과 `draftManual` 진입부에서 빈 문자열이 통과·분기되는지 구현 첫 단계에서 확인하고, 직원 `''` 시험을 넣는다.
- 18. **팩 가져오기 비교**(최가독): "같은 이름·다른 내용" 비교에서 `title`은 제외. 같은 이름이 이미 있으면 기존 제목 유지.
- 참고: 같은 한글 제목을 두 번 만들면 파일 이름만 달라 목록에서 구분이 어렵다 — 이번 범위에선 감수(중복 제목 저장 시 안내 문구는 다음 차수 후보).

## 채택하지 않은 것
- B의 "편집 폼 파일 유지": 이번 변경 뒤 폼 크기를 보면 분리가 읽기 쉽다(1번).
- B의 편집 창 초안 상자 + 확인창: 3번으로 상황 자체를 없앰.
- A의 시간 기반 슬러그·`null` 직원 허용·팩 형식 미변경: 6·7·9번 이유.
- 저장 위치 기본값 "모든 일에서": 요구 범위 밖. 이번엔 안 바꾼다.

## 구현 전 확인할 것(정리드)
- 업무 보드·대화방 빈 화면 렌더 위치 grep 확정, `EmptyGuide`는 결재함부터 바꿔 시각 동일 확인 후 적용.
- 템플릿 role 문구는 그 언어의 흔한 직무명이어야 `stepMember` 매칭이 됨 → 김기획 문구 기준.
- QA(오큐에이): `title:` 있는 스킬을 Claude Code·Codex 직원이 정상 호출하는지 실제 확인.
