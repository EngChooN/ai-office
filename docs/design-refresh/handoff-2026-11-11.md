## 2. 페이블 모델 선택 — 시안 3 "카드형 목록"
- 시안: `fable-model/fable-model.html` (3열), `fable-model-*.png`
- 고용 창(`HireDialog`) 모델 칸: Segmented 대신 **세로 라디오 카드 목록**. 순서 **기본 → Fable → Opus → Sonnet → Haiku**.
  - 카드: 높이 약 36px, 둥근 14px, 테두리 `--border`, 선택 시 테두리 `--primary` + 3px 링(ring 22%). 왼쪽 라디오 16px · 이름(폭 92px, 굵게) · 한 줄 설명(`--muted-foreground` 12px) · 오른쪽 사용량 점 5칸(7px, 채움 `--primary`, 빈칸 `--border`).
  - Fable 옆 "NEW" 배지(연보라 바탕 18% + `--primary` 글자, 9.5px 굵게).
  - 목록 아래 오른쪽 작은 설명: "● 사용량(많을수록 한도가 빨리 참)".
  - 결재 방식 칸은 모델 칸 **아래로** 내림(고용 창 세로 약 150px 늘어남).
- 직원 패널 프로필 모델 드롭다운: 순서 동일, 항목 오른쪽에 같은 사용량 점, 기본 모델 아래 구분선. 머리 줄 표기는 "Fable"(버전 숫자는 설명에만).
- 설명 문구(한국어 기준, 4개 언어 사전 필요): 기본 "알아서 골라요 (추천)" · Fable "가장 어려운 일 · 가장 느림" · Opus **"아주 똑똑해요 · 느리고 사용량이 많아요"**(기존 "가장 똑똑해요"에서 바꿔야 Fable과 겹치지 않음) · Sonnet 기존 · Haiku 기존.
- **확인 필요**: 페이블 실제 사용량 배율이 조사서에서도 확인되지 않아 점 개수(Fable 5·Opus 4·Sonnet 3·Haiku 1)는 임시값입니다. Codex 직원은 지금처럼 드롭다운(변경 없음).
