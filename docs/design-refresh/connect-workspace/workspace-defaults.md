# 워크스페이스 — 가능성 조사 요약 + '확인 필요' 상 6개 추천 기본값

정리드 · 2026-11-12 · 확정안: 마법사 4장 + 1안 상단 드롭다운 · 조사 원문 `../workspace-feasibility.md`

## 가능성 결론
**지금 구조로 만들 수 있습니다.** 휴대폰 앱이 이미 "PC의 사무실을 원격으로 띄우는" 방식(`/v2/call` + `/v2/events`)이라, 같은 화면 코드를 데스크톱에서도 다시 쓸 수 있습니다. 먼저 풀어야 할 것은 셋입니다.
1. **열쇠가 PC당 휴대폰 공용 1개** → 기기별로 끊을 수 없음. 다른 PC 연결용 열쇠 칸(최대 8개, 하나씩 끊기 가능)에 '화면 보기' 권한을 더해 **기기별 열쇠**로 바꿉니다.
2. **원격에서 PC 전용 기능은 막힘**(폴더 고르기·로그인·화면 모드 등), **비용·토큰 값은 오지 않음** → 원격 화면에서 숨기거나 비워 두는 디자인 보완이 필요합니다.
3. **보안 구멍**: 원격에서 '기본 작업 폴더'(`defaultCwd`)를 바꿀 수 있어 "원격은 작업 폴더를 못 정한다" 원칙이 우회됩니다. 워크스페이스보다 먼저 고칩니다.

## 확인 필요 '상' 6개 — 추천 기본값

| # | 쟁점 | 추천 기본값 | 이유 |
|---|---|---|---|
| 1 | 다른 PC 결재를 어디까지 띄울까 | **보고 있는 PC 결재만 화면 전체에.** 다른 PC는 드롭다운 이름 옆 **숫자 점**, 그리고 **기기 알림만** 'PC 이름 · 직원 · 내용'으로 띄움(누르면 그 PC로 전환). 이 PC의 결재함·바탕화면 비서·메뉴 막대 배지에는 **섞지 않음** | 결재함에 섞으면 어느 PC 것인지 헷갈려 잘못 승인할 위험. 알림까지 막으면 다른 PC 결재를 놓침. 합쳐 보기는 써 보고 나중에 |
| 2 | 두 기기가 같은 PC를 동시에 볼 때 충돌 | **먼저 누른 쪽이 이김.** PC가 이미 '이미 처리됨'(409 `already_decided`)으로 막고 있으니 늦은 쪽 카드는 "다른 기기에서 이미 처리했어요 (승인/반려)" 한 줄로 바뀌고 사라짐. **지시는 충돌 아님** — 둘 다 기존 대기 메시지 순서대로. 설정은 마지막 저장이 이기고 양쪽 화면이 실시간으로 바뀜 | 서버 판정은 이미 있어 문구·화면만 추가. 잠금(한 기기만 조작)은 불편 대비 이득 적음 |
| 3 | '3대'의 기준 | **보는 쪽 기준**: PC는 이 PC 빼고 다른 PC 3대, 휴대폰은 PC 3대. **보이는 쪽**(한 PC에 붙는 기기)은 새 제한 없이 기존 열쇠 칸 한도 **8대**(PC+휴대폰 합)를 그대로 | 기존 한도 재사용이라 새 규칙·문구가 필요 없음. 8칸이 차면 이 PC 설정의 '연결된 기기'에서 끊게 안내 |
| 4 | 끊김 처리 | **8초 유예 뒤** '끊김' 표시(안드로이드 기존 값과 같음) → 마지막 화면 회색, **보내기·결재 버튼만 막음**. 다시 연결은 1→2→4…**최대 30초 간격, 횟수 제한 없음**(보는 동안). 입력 중 글은 PC별로 그대로 보존. 다시 붙으면 **놓친 기록은 이어 받기**(Last-Event-ID), 저쪽 앱이 재시작됐으면 전체 화면을 새로 받음 | 끊긴 동안 아예 보내지 않으니 중복 전송이 생기지 않음. 이어 받기는 이미 서버에 있음 |
| 5 | 휴대폰 열쇠·배터리 | 열쇠 3개를 **PC마다 따로 암호화 저장**. 실시간 연결은 **보고 있는 PC 1개만** 유지 → 배터리는 지금과 같음. 다른 PC는 앱이 열려 있을 때 1분마다 가볍게 숫자만 확인, 앱이 닫혀 있으면 기존 15분 백그라운드 확인이 3대를 차례로 돌며 결재 알림 | 실시간 3개 유지는 배터리·데이터 부담 대비 이득이 작음. 15분 확인은 이미 있는 구조 |
| 6 | 기존 PC 짝·데려온 원격 직원 이전 | 기존 짝(12자리 코드)은 **다시 짝짓지 않고 '연결된 PC' 목록으로 자동 이전**. 단 '화면 보기'는 처음 열 때 **저쪽 PC에서 한 번 허락**(결재 카드). 데려온 원격 직원 자리는 없애되, **진행 중인 일은 끝난 뒤 정리**하고 연결 대기 일은 먼저 보낸 뒤 비움. 휴대폰의 기존 연결 1개는 목록의 첫 PC로. 저쪽 PC가 옛 버전이면 "그 PC를 업데이트해 주세요" 안내 | 데려오기는 직원 단위 원격 조작이라 화면 보기보다 권한이 좁음 → 넓히는 순간에 저쪽 동의를 받는 것이 안전. 진행 중 일을 끊지 않음 |

### 같이 정하면 좋은 '중' 항목 (계획에 반영한 기본값)
- 8자리 코드 대신 **기존 12자리 코드 + 인증서 지문 확인 글자** 재사용(12번) — 새 짝짓기 체계를 만들지 않음.
- 이름·색은 **보는 쪽 기기에 저장**(11번).
- 원격에서 막을 설정은 **기존 PC 전용 목록 그대로**(7번), 비용 칸은 원격일 때 '이 PC에서만 보여요'로 비움.
- 꺼짐/잠자기/앱 닫힘 구분은 1단계에서 하지 않음(10번, 시안대로 한 가지).
- '누가 보고 있어요' 표시(9번)·다른 PC 파일 열기(8번)는 2단계 이후.
