# 소개 사이트 안 3 구현 — 설계 결정 (정리드, 2026-11-17)

두 설계안: `impl-design-readable.md`(최가독) · `impl-design-pattern.md`(박패턴). 두 안이 큰 방향에서 같아 공통안을 그대로 채택하고, 나뉜 부분만 아래처럼 정했다.

## 채택
- **같은 `site/index.html`을 고쳐 쓴다**(두 안 공통). 머리말·테마·언어 고르기·다운로드 버튼·버전 조회 스크립트는 그대로, 본문 칸·스타일·사전만 바꿨다. 검사·빌드 스크립트가 이 파일 모양에 기대고 있어서다.
- **체험 대본은 언어와 무관한 뼈대 한 벌 + 사전 키(`exp.*`)**, 레벨 이름은 배열 키(`lv.names` 7개·`lv.unlocks` 4개)(두 안 공통). JS가 그리는 칸이라 언어별 정적 페이지에는 비어 있고, 정적으로 보여야 하는 버튼 글자만 `data-i18n`.
- **그림은 미리 잘라 둔 파일**(두 안 공통). 이름은 박패턴 안 `feat-*.webp`/`-dark`, 건물은 박패턴 안 `assets/building/lv1~7.webp` 한 벌.
- **움직임 줄이기**: 자동 재생 없이 끝 상태를 바로 그린다(두 안 공통). 대화 칸만 `aria-live`, 상태 줄·자리 4칸은 읽기에서 뺐다(박패턴 안).
- **검사 보강**(박패턴 안): `check-i18n.mjs`가 화면 코드가 쓰는 `exp.*`/`lv.*` 키가 4개 언어에 다 있는지, 배열 길이, 베타·시험판 문구, 건물 그림 7장, 언어별 페이지의 `../assets` 경로·`undefined`를 본다. `build-langs.mjs`의 JSON-LD 사진 목록에서 없는 `staff-mix`를 뺐다.

## 채택하지 않은 것 · 바꾼 것
- **06·08 "화면 예시" 표시**(박패턴 안): 실제 캡처로 바꿀 수 있어 필요 없어졌다. 06은 AI 사용 비용 화면(Claude·GPT 사용량), 08은 직원 현황 화면을 모의 데이터 미리보기로 찍었다.
- **열리는 것 표시**: 전달 자료의 "휴게 코너 Lv.3~"는 앱 표(`officeLevel.ts`)와 달라 앱 기준(커피 코너 Lv.2 · 탕비실·휴게실 Lv.7 · 강당 20명 Lv.16 · 대표실 Lv.20)으로 고쳤다.
- **옛 칸 삭제**: 사용법·새 소식·비서·안심·스타일·휴대폰·제한 사항·FAQ·마지막 권유 칸을 지웠다(두 안 공통 추천, 전달 자료 순서표에 없음). 휴대폰 첫 화면 '다른 플랫폼' 줄은 '다른 기기' 버튼(다운로드 칸으로)으로 대신했다.
- 머리줄의 GitHub 버튼은 '무료 다운로드' 버튼으로 바꾸고 GitHub는 꼬리로 옮겼다(전달 자료 1번).
