- 확정: 2026-11-17 대표 선택 "안 3 · 직접 보내 보기"
- 시안: `docs/design-refresh/site/site-redesign-drafts-v2.html?plan=3` (탭 안 3, 라이트·다크, PC 1280·휴대폰 390)
- 대표 피드백 반영: 레벨 막대(안 2에서 가져옴) 유지, "최근에 좋아진 점(새 소식)" 칸 없음, 기능은 글만 쓰지 말고 실제 화면과 함께
- 담당: 디자인 이디자 → 구현 정리드·프론트엔드 (사이트 코드 `site/`)

## 1. 페이지 순서 (위 → 아래)

| 순서 | 칸 | 핵심 내용 |
|---|---|---|
| 1 | 머리줄 | 로고 · 메뉴(보내 보기 · 꾸미기 · 기능 · 다운로드) · 언어 · 무료 다운로드. 휴대폰 폭에서는 메뉴가 둘째 줄 가로 스크롤(숨기지 않음) |
| 2 | 첫 화면(체험) | 왼쪽: 제목 "직원에게 메시지 한 줄, 그게 전부예요" · 설명 · 예시 메시지 버튼 4개 · 다운로드 버튼. 오른쪽: 단체방 체험 창 + 사무실 자리 4칸 |
| 3 | 핵심 2 · 사무실 꾸미기 | 모으기 → 사기 → 놓기 3칸 + 레벨 막대(Lv.1~20, 건물 그림 7단계) |
| 4 | 그 밖의 핵심 7가지 | 실제 앱 화면과 설명을 번갈아 놓은 줄 7개(03~09) |
| 5 | 다운로드 | Mac · Windows · 안드로이드 카드, 내 기기 강조 |
| 6 | 꼬리 | 버전 · 업데이트 소식 · 피드백 · 후원 · GitHub 링크 |

## 2. 첫 화면 체험(가장 중요)

- 예시 버튼 4개: `@디자인팀 로그인 화면 시안 두 가지`(팀에게) · `이번 주 회의록 정리해 줄 사람?`(안 부르고) · `@전체 오늘 한 일 짧게 보고`(모두에게) · `@팀장 회원가입 개선 맡아 줘`(큰 일)
- 누르면 대본이 재생된다: 대표 말풍선 → 받음 → 직원 답 → (결재 카드 또는 기획 확인 카드) → "대표님이 승인했어요" → 완료. 간격: 상태 바뀜 0.45초, 말풍선 0.9초.
- 위쪽 직원 상태 줄(쉬는 중·받음·작업 중·대표님 확인 기다림·완료)과 아래 사무실 자리 4칸(초록 테두리 = 일하는 중, ! = 확인 필요)이 대본과 함께 바뀐다.
- 처음 열면 첫 번째 대본이 자동 재생. 다른 버튼을 누르면 처음부터 다시.
- **창 머리에 "체험용 화면 · AI 사용 없음"을 꼭 표시**(실제 앱으로 오해 방지).
- 대본은 시안 HTML의 `SCRIPTS` 그대로 사용 가능. 4개 언어 번역 필요.

## 3. 사무실 꾸미기 칸

- 3칸: ① 모으기(회사 자금 칩) ② 사기(상점 101종, 벽지 15·바닥재 14) ③ 놓기(초록 칸 = 놓을 수 있음, 빨간 칸 = 안 됨+이유 한 줄)
- 레벨 막대: 막대를 밀거나 단계 버튼을 누르면 건물 그림·이름·열리는 것이 바뀐다.

| 레벨 | 건물 | 층 |
|---|---|---|
| 1~2 | 차고 | 1 |
| 3~5 | 1층 상가 | 1 |
| 6~9 | 벽돌 건물 | 2 |
| 10~13 | 3층 오피스 | 3 |
| 14~17 | 유리 사옥 | 4 |
| 18~19 | 5층 타워 | 5 |
| 20 | 캠퍼스 | 5 |

  열리는 것 표시: 휴게 코너(Lv.3~) · 20명 강당(Lv.16~) · 대표실(Lv.20). 근거 `docs/specs/office-iso-levels.md`.
- 아래 한 줄: "업무 모드에서는 레벨·상점·사무실 그림을 모두 숨겨요"
- 처음 값 Lv.7.

## 4. 기능 7가지 줄

| 번호 | 제목 | 그림 |
|---|---|---|
| 03 결재 | 중요한 일은 먼저 물어봐요 | `chat` 캡처 일부(승인·반려 카드) |
| 04 팀장 | 큰 일은 팀장이 나눠 맡겨요 | `inbox` 캡처 일부(기획 확인 카드) |
| 05 비서 | 말로 앱을 써요 | `secretary` 캡처 일부(밤사이 요약) |
| 06 AI | Claude·GPT 직원을 한 사무실에 | 작은 화면 흉내(Claude/GPT 고르기 + 사용률 칩) |
| 07 연결 | 휴대폰·다른 PC | `phone-chat` 캡처를 휴대폰 틀에 |
| 08 안심 | 대시보드·급여 명세서·업무 모드 | 작은 화면 흉내(숫자 4칸 + 사용률 막대 + 업무 모드 스위치) |
| 09 도구 | 업무 보드·회의실·매뉴얼·예약 업무 | `board` 캡처 일부 |

- PC: 그림 1.2 : 글 1 가로 배치, 짝수 줄은 좌우 반대. 그림 칸 비율 16:10. 휴대폰 폭: 그림 위, 글 아래.
- 캡처 자르기 기준(왼쪽, 위, 오른쪽 — 비율): 03 `.36,.555,.68` · 04 `.145,.245,.50` · 05 `.285,.15,.62` · 09 `.14,.44,.62`. 실제 구현은 미리 잘라 둔 그림 파일을 쓰는 편이 가벼움(구현 판단은 개발에 맡김).

## 5. 색·글꼴·크기

- 색: 지금 사이트 라벤더 `#6D5BEF`(다크 `#9B8CFF`) · 핑크 `#D6409A`(다크 `#FF7AC6`) + 사무실 그림 색 벽돌 `#E9B9B1` · 바닥 `#B3BEE6` · 원목 `#E8C799`. 꾸미기 칸 배경은 벽돌 색을 연하게 깐 세로 그라데이션.
- 제목: 첫 화면 46px(휴대폰 30px) · 칸 제목 36px(26px) · 본문 15~17px. 글꼴은 지금 사이트와 같음.
- 칸 위아래 여백 88px(휴대폰 52px). 카드 모서리 14~18px.
- 바뀌는 기준 폭: 700px 이하에서 한 줄 배치.

## 7. 정해지지 않은 것

- 체험 대본과 레벨 이름의 영어·일본어·중국어 문구(번역 담당 필요)
- 건물 그림 7장은 개발 자료 그림(`docs/specs/office-iso-art/exterior-1~7.png`)이라 지금 앱 외관과 다를 수 있음 — 실제 앱에서 레벨별 외관을 새로 찍을지
- 06·08 카드는 HTML로 흉내 낸 작은 화면 — 실제 캡처(직원 추가 창·대시보드)로 바꿀지
- 첫 화면 체험의 움직임을 줄이기 설정(움직임 줄이기)에서 멈출지
