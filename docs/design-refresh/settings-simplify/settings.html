설정·장비 탭 정리 시안

왼쪽: 설정은 찾기 칸과 '자주 쓰는 설정'을 맨 위에 두고, 분류마다 기본만 보이게 하고 나머지는 '더 보기'로 접었습니다. 개발자용은 맨 아래 '개발자용 자세히'로 숨겼습니다. 오른쪽: 직원 장비 탭은 'AI가 할 수 있는 일'을 카드마다 {{ask}}·{{auto}}·{{block}} 3단계로 고르고, 서비스 연결에는 추천 버튼을 붙였습니다. 문구와 기본·더 보기·개발자용 분류는 김기획 용어집(glossary.md)을 따랐습니다.

① 설정 기본 화면

찾기 칸 → 자주 쓰는 설정 5칸 → 고른 분류의 기본 항목 → 접힌 '더 보기' → 맨 아래 '개발자용 자세히'. 칸마다 한 장씩 있던 카드를 한 묶음 안 줄 목록으로 바꿔 세로 길이를 절반 가까이 줄였습니다.

바뀌는 점

  • 찾기 칸: 설정 이름·설명·같은 뜻 말(예: '어둡게' → 화면 모드)로 찾습니다. ⌘K / Ctrl+K로 바로 들어갑니다.
  • 자주 쓰는 설정(용어집 3절): 자동결재와 남은 시간 · AI 계정 상태 · 사용량 아끼기 모드 · 업무 모드 · 언어와 화면 모드. 그 자리에서 바로 바뀌고, 분류 안 같은 항목과 값이 같습니다.
  • 분류마다 기본은 늘 보이고, '더 보기 N'은 접혀 있습니다. 한 번 펼치면 다음에도 펼친 채 둡니다.
  • 개발자용(터미널의 Claude 알림·질문 받기, 개발 빌드의 미리보기 2개)은 각 분류 맨 아래 '개발자용 자세히'에 접어 둡니다. 영어 이름(hooks 등)은 여기서만 보입니다.
  • 사무실 분류는 모두 꾸미기라 6개 전부 '더 보기'에 들어갑니다. 업무 모드를 켜면 '사무실 그림이 숨겨져 있어요' 안내만 보입니다.
  • 켜기/끄기 한 칸은 체크 상자 대신 오른쪽 스위치로 통일합니다.

정해야 할 것

  • 업무 모드를 일반으로 옮길지(용어집은 settings-tab-audit 참고라고 적음). 시안은 일반에 둠.
  • 자주 쓰는 설정 고정 5칸으로 둘지(시안은 고정, 사용 빈도 자료 없음).

② 설정 찾기

글자를 치면 분류를 넘어 결과만 모아 보여 줍니다. 결과 줄에서 바로 바꿀 수 있고, '어디에 있나'를 작게 적어 둡니다. '더 보기'에 접힌 항목도 찾아집니다. 개발자용은 따로 한 줄로 알려 줍니다.

규칙

  • 제목·설명·같은 뜻 말에서 찾고, 맞은 글자를 칠합니다.
  • 결과를 누르면 그 분류로 가서 해당 줄을 잠깐 칠해 줍니다('더 보기'면 펼쳐서).
  • 결과가 없으면 '비슷한 말' 몇 개와 피드백 보내기를 보여 줍니다.
  • 개발자용 항목은 숨겨 둔 동안 찾아지지 않습니다.

같은 뜻 말 예시

  • 어둡게·밤·다크 → 화면 모드
  • 휴대폰·폰·QR → 휴대폰 연결
  • 알림·외부 → 외부 직원 실시간 알림
  • 결재·승인·자리 비움 → 자동결재, 자동 승인 규칙

③ 직원 장비 탭 — AI가 할 수 있는 일

직원 패널의 장비 탭입니다. 맨 위 한 줄로 지금 상태를 세어 보여 주고, 할 수 있는 일마다 {{ask}}·{{auto}}·{{block}}을 색으로 구분합니다. 고른 칸 아래에 '그러면 어떻게 되는지' 한 줄을 적어 줍니다. MCP·스킬·셸 같은 말은 화면에서 쓰지 않습니다.

바뀌는 점

  • 3단계 이름은 용어집대로 {{ask}} · {{auto}} · {{block}}입니다. 지시서의 묻기/자동/막기는 앱 안 다른 화면(결재함·프로필)과 맞추려고 쓰지 않았습니다.
  • 3단계 색: {{ask}}=노랑(결재함과 같음), {{auto}}=초록, {{block}}=회색.
  • 고른 칸 아래에 '그러면 어떻게 되는지' 한 줄을 적습니다.
  • '프로그램 실행'의 세부 2개(보기만 하는 실행, 위험한 것 항상 막기)는 '세부 조정'으로 접습니다.
  • 연결된 서비스는 켜기와 상태만 보여 줍니다. 아래 추천 연결 버튼을 누르면 ④ 창이 그 서비스를 고른 채 열립니다.
  • '더 보기 4': 자동결재 중 브라우저, 프로그램 인터넷 쓰기, 가벼운 AI, 켠 서비스는 결재 없이.
  • MCP·스킬·셸·Bash 같은 말은 '개발자용 자세히' 안에만 둡니다.

정해야 할 것

  • '화면 찍기'처럼 {{auto}}가 위험한 칸은 2단계로 둘지 정해야 합니다.
  • '프로그램이 인터넷 쓰기'를 개발자용으로 옮길지 정해야 합니다(용어집에서도 확인 필요로 남김).

④ 서비스 연결 창 (추천 연결)

'+ 서비스 연결' 또는 추천 버튼을 누르면 뜨는 창입니다. 자주 쓰는 서비스를 카드로 골라 로그인만 하면 연결되게 하고, 주소를 넣는 기존 방식은 맨 아래 '주소로 직접 연결'로 내립니다. 서비스 목록과 로고는 예시입니다.

흐름

  • 카드 고르기 → '연결' → 브라우저 로그인 → 돌아오면 장비 목록에 '사용 가능'으로 추가.
  • 카드마다 'AI가 할 수 있는 일'을 한 줄로 씁니다(읽기만 / 읽고 쓰기).
  • 이미 연결한 서비스는 '연결됨'으로 보입니다.
  • '직접 연결'을 누르면 추가 창이 주소 탭 하나만 보여 줍니다. 프로그램 실행·설정 붙여넣기 탭은 개발자용으로 숨깁니다(용어집).

정리드 확인

  • 추천 목록을 앱에 넣어 둘 수 있는지, 로그인만으로 연결되는 서비스가 어떤 것인지(서비스마다 다름).
  • GPT 직원에게도 같은 목록을 보여 줄 수 있는지.

⑤ 구성표 — 지금 항목이 어디로 가나 (용어집 기준)

김기획 용어집 1절 분류표를 따랐습니다. 없애는 항목은 없고 자리만 옮깁니다. 굵게=기본, 회색=더 보기(접힘), 빨강=개발자용 자세히(접힘). ★=자주 쓰는 설정에도 나옴.
