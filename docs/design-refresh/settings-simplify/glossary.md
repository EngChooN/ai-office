# 설정·장비 탭 쉬운 말 용어집 (이디자 시안용)

- 대상: `SettingsPage.tsx`, `EquipmentTab.tsx`, `McpSection.tsx`, `McpAddDialog.tsx`
- 기준: 현재 한국어 사전(`shared/i18n/dict/*.ts`)을 읽어 정리. 앱을 직접 열어 보지 않았음(배치는 확인 필요).
- 한국어 제안만 적었고, 4개 언어 키는 구현 단계에서 처리.
- 참고: 장비 탭은 앞선 장비·프로필 개편 문구(`연결된 서비스`, `결재 없이` 등)가 사전에 이미 반영돼 있다. 그래서 장비 쪽 "현재"는 그 문구이고, 남은 어려운 말만 다시 제안했다.
- 분류 기준: **기본** = 처음 화면에 펼쳐 둠 / **고급** = '더 보기' 접이식 / **개발자용(숨김)** = 기본으로 숨기고 '개발자용 자세히'에서만 노출.

## 3. 설정 상단 '자주 쓰는 설정' 후보 (5개)

대표가 가장 자주 만지거나, 막히면 일이 멈추는 순서로 골랐다. 사용 빈도 데이터는 없어 판단 근거는 화면 목적이다(확인 필요).

1. **자동결재 켜기/끄기 + 남은 시간** — 자리 비울 때마다 만짐
2. **AI 계정 연결 상태** — 끊기면 직원이 일을 못 함
3. **사용량 아끼기 모드** — 비용 걱정이 있을 때 한 번에 켜는 스위치
4. **업무 모드** — 회사에서 쓰려고 게임 요소를 끌 때
5. **앱 언어 / 화면 모드(밝게·어둡게)** — 처음 한 번 바꾸는 개인 취향(한 칸에 묶음)

제외한 것: 휴대폰·다른 PC 연결(5번 개편에서 자체 가이드가 생김), 외부 직원 알림(개발자용).

## 4. 구현 시 주의

- 이름을 바꾸면 `SECTION_CATEGORY`와 `requestSettingsSection` 호출부, 4개 언어 사전을 함께 고쳐야 함(점검표 settings-tab-audit.md 참고).
- '개발자용(숨김)'은 완전 삭제가 아니라 접힌 영역이다. Bash·MCP·hooks 같은 영어 이름은 거기서만 볼 수 있게 한다.
- 샌드박스는 사전에 없어 지금은 바꿀 문구가 없다. 나중에 화면에 생기면 위 제안을 쓴다.
- 앞선 장비·프로필 개편(`docs/design-refresh/staff-equip/`)과 문구가 충돌하지 않게 용어를 맞췄다.
