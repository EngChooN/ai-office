# 업무 모드 스위치 — 왼쪽 메뉴 맨 아래 (개발 전달)

작성: 이디자 · 2026-11-16 · 받는 사람: 정리드
결정: 대표가 위치 시안 4개 중 **④ 왼쪽 메뉴 맨 아래**를 고름 (시안 `wm-4-dark.png`).
이 문서의 나머지(설정 화면 처리·알리는 방법·문구)는 **이디자 추천안(대표 미확인)** 입니다.

## 1. 한 줄 요약

PC 앱 왼쪽 메뉴(`Sidebar.tsx`) 맨 아래, **'피드백 보내기' 바로 위**에 "업무 모드" 스위치 줄 하나를 추가한다.
값은 설정 화면의 기존 항목과 **같은 값**(`settings.isWorkMode`)이다. 새 설정 없음.

## 2. 그림

| 파일 | 내용 |
|---|---|
| `wm-4-dark.png` | 대표가 고른 원래 시안 (다크) |
| `wm-final-dark.png` · `wm-final-light.png` · `wm-final-retro.png` | 이 문서 규격대로 다시 그린 확정 미리보기 (꺼짐 / 켜짐) |
| `handoff-preview.html?v=4&mode=dark\|light\|retro` | 미리보기 원본 |

미리보기 창은 실제 1400px 화면을 줄여 그린 것이라 **크기는 아래 수치를 따른다** (그림의 px을 재지 말 것).

## 3. 위치·순서

```
nav (w-44 = 176px, p-2)
├─ 메뉴 스크롤 영역 (flex-1, overflow-y-auto)   ← 그대로
├─ [새] 업무 모드 줄                              ← 여기
├─ 피드백 보내기 (FeedbackButton)
└─ 후원하기 (DonateButton)
```

- 스크롤 영역 **밖**(아래 고정 묶음)에 둔다 → 창이 낮아도 메뉴만 스크롤되고 스위치는 늘 보인다.
- 업무 모드를 켜면 위 메뉴에서 '사무실'·'상점'이 빠지는 건 지금 동작 그대로(`visibleGroups`). 스위치 줄 자체는 켜짐·꺼짐 모두 같은 자리에 있다.

## 4. 크기·간격 (기본 테마 = 라벤더·블루 등 모든 일반 테마 공통)

옆 줄(FeedbackButton·DonateButton)과 같은 규칙을 쓴다.

| 항목 | 값 |
|---|---|
| 줄 전체 | `flex items-center gap-1.5 rounded-md px-2.5 py-1.5 text-xs` (옆 버튼과 같음), 높이 ≈ 28px |
| 위 구분선 | 줄 위에 `border-t` 1px (`--border`), 구분선 위 여백 `mt-1`(4px), 구분선과 줄 사이 `pt-1`(4px) |
| 아이콘 | lucide `BriefcaseIcon` `size-3.5`(14px), `shrink-0` |
| 글자 | "업무 모드" `flex-1 truncate whitespace-nowrap` (옆 버튼과 같음) |
| 스위치 | 기존 `components/ui/switch.tsx` 그대로 (`h-4 w-7` = 28×16px), 줄 오른쪽 끝 |
| 누르는 범위 | **줄 전체**를 눌러도 켜지고 꺼짐 (스위치만이 아니라). 마우스 올리면 `hover:bg-accent/60` (옆 버튼과 같음) |

접근성: 스크린리더에는 **스위치 하나**로 읽혀야 한다(`role="switch"`, `aria-checked`, 이름 = "업무 모드"). 버튼 안에 버튼(Switch)을 넣지 않게 구조는 정리드 판단에 맡김. 키보드 Tab으로 닿고 Space로 바뀌어야 함.

## 5. 켜짐 / 꺼짐 모양과 색

색은 모두 **기존 토큰**만 쓴다. 새 색 없음.

| | 꺼짐 | 켜짐 |
|---|---|---|
| 글자 | `text-muted-foreground` (옆 '피드백 보내기'와 같음) | `text-foreground font-medium` |
| 아이콘 | `text-muted-foreground` | `text-primary` |
| 스위치 | `bg-input`, 손잡이 왼쪽 | `bg-primary`, 손잡이 오른쪽 |

테마별 실제 값 (확인: `index.css`, `theme-retro.css`)

| 토큰 | 다크(라벤더) | 라이트(라벤더) | 레트로(다크 전용) |
|---|---|---|---|
| `--muted-foreground` (꺼짐 글자) | #A7A3C4 | #66627F | #C4C1D6 |
| `--foreground` (켜짐 글자) | #EDEBF8 | #221F33 | #FAF5EC |
| `--primary` (켜짐 아이콘·스위치) | #9B8CFF | #6C5CE7 | 스위치는 레트로 규칙(아래) |
| `--input` (꺼짐 스위치) | #413E5C | #CFCAE6 | 레트로 규칙 |
| `--border` (구분선) | #34314A | #DEDAF0 | 아래 참고 |

글자 대비(직접 계산): 꺼짐 글자 다크 7.3 · 라이트 5.6 · 레트로 8.3, 켜짐 글자는 모두 13 이상 → 기준 4.5 넘음.
켜짐 글자를 `--primary`로 칠하지 않는 이유: 라이트 사이드바 배경에서 4.5 근처라 아슬아슬함. 그래서 **아이콘만 보라색**.

### 레트로 테마

- **스위치는 따로 만들지 말 것.** `theme-retro.css`의 `[data-slot='switch']` 규칙이 자동으로 52×20px 트랙 + 네모 손잡이 + OFF/ON 도트 글자(켜짐 초록 #3FC168)로 바꾼다. 일반 `Switch` 부품을 쓰면 된다.
- 구분선: 레트로에서는 2px `--retro-line-soft`(#4A5068)로 (다른 레트로 구분선과 같은 굵기).
- 켜짐 글자 굵기: 레트로는 굵은 글꼴을 쓰지 않으므로 `font-medium` 무시(기존 레트로 규칙 그대로).
- **주의 — 폭:** 레트로는 글자 12px 도트 + 스위치 52px라 줄 안쪽 폭(약 138px)이 빠듯하다. 계산상 한국어 "업무 모드" ≈ 14+6+60+간격+52 ≈ 132px로 들어가지만, 글자 쪽에 `truncate`를 꼭 걸고 스위치는 `shrink-0`. 줄 높이는 스위치(20px)가 들어가게 최소 28px 이상 → 아래 '피드백 보내기' 줄과 겹치지 않는지 확인.
- 영어·일본어·중국어 레트로에서 글자가 잘리는지 실제 화면으로 한 번 봐 주세요 (미확인).

## 6. 좁은 사이드바(접힘)일 때

- **지금 PC 앱 왼쪽 메뉴에는 접힘 상태가 없다** (`w-44` 고정, 코드 확인). 그래서 이번엔 처리할 것 없음.
- 나중에 아이콘만 남는 접힘 상태가 생기면: 글자·스위치를 숨기고 **32×32 아이콘 버튼**(가방 아이콘)만 남긴다. 꺼짐 = 회색 아이콘, 켜짐 = `bg-primary/15` 바탕 + `text-primary` 아이콘. 마우스 올림 설명은 "업무 모드: 켜짐 / 꺼짐"(아래 문구 `sidebar.workMode.stateOn/Off`).

## 7. 휴대폰 화면 — 이번에 넣지 않음

- **휴대폰 화면(`PhoneShell`)에는 넣지 않는다.** 휴대폰은 지금처럼 설정 화면에서만 바꾼다.
- 참고: 태블릿·펼친 폴드폰은 PC와 같은 틀(`DesktopShell` + `Sidebar`)을 써서, 아무 조건 없이 넣으면 태블릿에도 보인다. **추천안(대표 미확인): 휴대폰 앱 전체(`IS_MOBILE_SHELL`)에서 숨김** — "휴대폰 앱에는 이번에 안 넣는다"로 단순하게.
- 다른 PC 화면을 보는 원격 창(`IS_REMOTE_SCREEN`)에서 보일지는 미정. 업무 모드가 PC마다 따로인 값이면 숨기는 게 맞음(추정) — 정리드가 코드로 확인해 주세요.

## 8. 설정 화면의 기존 항목 — 추천: 그대로 두고 안내 한 줄 추가

추천안(대표 미확인): **설정 화면 '업무 모드' 칸은 지우지 않는다.** 같은 값을 두 곳에서 바꾸게 둔다.

- 이유: ① 설정 화면에는 "무엇을 숨기는지" 설명 문단이 있어 처음 켜는 사람에게 필요 ② 휴대폰은 여전히 여기서만 바꾼다 ③ 설정 검색으로 찾는 사람도 있음.
- 바꿀 것: 설명 문단 끝에 한 줄만 추가 → `settingsPage.workMode.sidebarHint` ("왼쪽 메뉴 맨 아래에서도 바로 켜고 끌 수 있어요."). PC 화면에서만 보이게(휴대폰엔 그 스위치가 없으니).
- 지금 설정 화면은 체크박스(`<input type="checkbox">`)다. 같은 값이 두 곳에서 다른 모양(체크박스 vs 스위치)이면 어색하므로, **가능하면 설정 쪽도 `Switch`로** (선택 사항, 작은 일).

## 9. 처음 쓰는 사람에게 알리는 방법 — 가장 가벼운 안

추천안(대표 미확인): **새 말풍선·안내 창은 만들지 않는다.** 아래 두 가지만.

1. **마우스 올림 설명(title)**: 줄에 마우스를 올리면 `sidebar.workMode.tip` 표시 — "켜면 사무실 지도·자금·상점·레벨을 숨기고 업무 화면만 보여요."
2. **업데이트 소식 한 줄**: 이 기능이 들어가는 버전의 '업데이트 소식'(`WhatsNew`, 버전마다 한 번 자동으로 뜸)에 `whatsNew.workModeSidebar` 한 줄을 넣는다. 이미 있는 1회 안내 통로라 새 UI가 없다.

- 위 둘로 부족하다는 의견이 나오면 그때 다음 단계: 스위치 줄 글자 옆에 작은 점(●, `--status-waiting` 색) 하나를 한 번 눌러 볼 때까지 표시. 이번엔 넣지 않음.

## 11. 동작 (지금 코드 그대로, 새로 만들 것 없음)

- 켜기: 사무실 지도·자금 칩·상점 메뉴·레벨이 사라지고, 사무실 화면을 보고 있었다면 대시보드로 바뀜 (`store.ts shownView`).
- 끄기: 다시 보임. 화면은 그대로 머묾.
- 저장: 기존 `update({ isWorkMode })`와 같은 길로 저장 → 앱을 다시 켜도 유지.

## 12. 확인하지 못한 것

- 원격 창에서 보여야 하는지 (7번).
