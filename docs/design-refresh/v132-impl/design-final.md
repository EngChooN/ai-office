## 시안과 다르게 (정리드 판단)
1. **'오늘 많이 씀' — 만들지 않음 (최 안).** 직원별 예산·오늘 사용량이 화면 상태에 없고, 박 안 A(회사 하루 토큰 한도)는 한도를 정하는 설정 화면이 없어(기본 0, 비서로만 설정 가능) 실제로 거의 안 보이는 표시가 됨. 상황판 '쓴 토큰' 카드가 이미 그 역할.
2. **'다시 시도' — 패널을 열고 지시창에 "멈춘 일을 이어서 다시 해 줘"를 채움(보내기는 대표).** 재시도 기능이 없고, 새로 만들면 main·원격·안드로이드까지 번짐. (두 안 같음)
3. **카드 전체 클릭** — 카드 바깥은 `div`, 머리(얼굴·이름)와 '자세히 ›'가 패널을 엶. 버튼 안에 버튼 금지.
4. **'오늘 완료 ↗' 타일** — 요약 문장에 넣지 않음(최 안). 업무 보드는 왼쪽 메뉴로 간다(직원 화면에 따로 링크를 두지 않음, 구현 확인 2026-11-13).
5. **회의실 방 목록은 PC 화면만**(폰은 `phone:hidden`).

## 채택하지 않은 주요 제안
- 최: `NavTabs`에 `hiddenGroups` prop — 동작은 같지만 순수 함수 쪽이 시험·영향 범위가 더 분명.
- 최: 순수 함수 2파일(`staffNow.ts`·`roleInfo.ts`) — 한 파일이 규칙을 한눈에 보기 쉬움.
- 박: '오늘 많이 씀' 회사 단위 — 위 1번.
- 박: 상황판 펼침 저장은 채택, `LiveMiniView` 정리는 다른 사용처가 있으면 그대로 둠.
