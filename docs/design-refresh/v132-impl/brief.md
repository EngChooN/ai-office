## 작업 범위 요약
1. 대화: '대화' 묶음(chat·meeting)일 때 위쪽 탭 줄 안 그림(다른 묶음 탭은 그대로). 회의실 화면 왼쪽에 단체방과 같은 방 목록(접으면 56px 띠), 회의실 줄 선택 표시. 방 목록·56px 띠의 회의실에 '답 기다리는 회의 결정' 숫자 배지(노란색, 지금 탭 배지 색). 왼쪽 메뉴 '대화'는 마지막 본 곳 그대로. 방 목록 ↑↓ 키 이동이 회의실까지. 폰 화면(PhoneShell) 영향 없음.
2. 직원 화면 A안: 탭 이름 대시보드→직원 목록, 조직도→팀 구성. 숫자 칸 6개 → 한 문장 요약(굵은 부분 누르면 필터). 정렬 급한 순. 카드: 머리(얼굴·이름·직무·팀·상태) / 지금 하는 일(문장, 도구 이름 대신 쉬운 말) / 시킬 수 있는 일 예시 3개(누르면 지시창에 채움) / 버튼 1개 강조(확인 기다림=노랑 '확인하기', 문제=빨강 '다시 시도', 나머지 '일 시키기') + '자세히 ›'(지금 패널). 토큰·$·Lv 카드에서 제거, 예산 넘을 때만 '오늘 많이 씀'. 마지막 칸 '＋ 직원 추가'. 상황판(확인 필요·쓴 토큰·최근 활동)은 목록 아래 접는 칸(기본 접힘).
3. 공통: 직원 추가 3단계(직무 고르기 → 이름·얼굴 → 일할 곳, '자세히 설정'은 3단계에 접음, 마지막 버튼 '일 시작하기'), '직원 고용'→'직원 추가'(앱 바·빈 화면·결재함 등 모두). 패널 머리: 모델 이름 빼고(프로필의 AI 등급만), 폴더는 '일하는 곳: 폴더 이름'(누르면 전체 경로), '터미널에서 이어 하기'는 ⋯ 메뉴, 탭 업무·변경·장비·프로필 → 대화·바뀐 파일·도구·소개, '소개'에 업무 지침 보이기·고치기. 고용 창의 '고용 뒤에는 AI를 바꿀 수 없어요' 문구 사실과 맞게. 쉬운 말 표 17개(시안 glossary)·직무 11개 문구(시안 ROLES)는 4개 언어(ko/en/ja/zh).
