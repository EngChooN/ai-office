1. 대화 화면 위 '단체방 | 회의실' 탭 — 없앨까?

확인한 사실(코드): 위쪽 탭과 방 목록 맨 아래 '회의실'은 같은 회의실 화면으로 갑니다. 56px로 접은 띠의 맨 아래 회의실 아이콘도 같습니다. 탭 줄은 '대화' 메뉴 안에 화면이 2개(단체방·회의실)라서 자동으로 생기는 줄입니다. 휴대폰(세로·분할 화면)은 이미 이 탭 줄을 없애고 회의실을 방 목록 안에 두고 있습니다.
탭이 지금 하는 일 3가지: ① 회의실에서 단체방으로 돌아오는 유일한 버튼(회의실 화면에는 방 목록이 없음) ② '답을 기다리는 회의 결정' 숫자 배지(방 목록의 회의실에는 숫자가 없음) ③ 왼쪽 메뉴 '대화'를 누르면 마지막에 본 탭이 열려서, 회의실에 있다가 '대화'를 눌러도 회의실에 머뭅니다.

지금 (1.3.1)

탭 줄 32px + 방 이름 줄이 겹쳐 '어디에 있는지'를 두 번 말합니다. 회의실이 위(탭)·아래(목록) 두 군데에 있고, 숫자 배지는 위에만 있습니다.

추천 · 방 목록으로 합치기 — 단체방 추천

탭 줄을 없애 대화가 한 줄 더 보입니다. 회의실은 방 목록 맨 아래 한 곳에만 두고, 탭에 있던 숫자 배지를 그 줄로 옮깁니다(방 '안 읽은 수'와 구분되게 노란색).

추천 · 방 목록으로 합치기 — 회의실을 연 모습

회의실도 왼쪽에 같은 방 목록을 그대로 둡니다. '전체 방'을 누르면 바로 단체방으로 돌아갑니다 → 탭이 하던 '빠른 전환'이 한 번 클릭 그대로 남습니다. 방 목록을 56px 띠로 접어도 맨 아래 회의실 아이콘이 같은 역할을 합니다.

세 가지 안 비교

안얻는 것잃는 것 / 위험판단
A. 탭만 제거세로 32px, 회의실 진입점 1곳으로 단순회의실에서 단체방으로 돌아올 버튼이 없어짐(메뉴 '대화'도 회의실을 다시 엶). 결정 대기 숫자가 대화 화면에서 사라짐비추천
B. 그대로 유지작업 0. 데스크톱 사용자는 익숙함같은 버튼 2개, 방 이름 줄과 겹침, 폰과 다른 구조(폰엔 탭 없음)보통
C. 방 목록으로 합치기 추천세로 32px, 진입점 1곳, 폰·PC 같은 구조. 전환은 목록에서 1클릭 그대로회의실 화면이 방 목록 폭(200px)만큼 좁아짐 → 회의 기록 칸은 지금도 넓어 문제 적음(추정)추천
C안에서 같이 바꿔야 하는 것 (구현 시 빠지면 A안이 됨)
  • 대화 묶음(단체방·회의실)일 때 위쪽 탭 줄을 그리지 않음. 다른 묶음(직원·업무 등)의 탭은 그대로.
  • 회의실 화면 왼쪽에 단체방과 같은 방 목록(또는 접힌 56px 띠)을 두고, 회의실 줄을 '선택됨'으로 표시.
  • 방 목록·56px 띠의 회의실에 '답 기다리는 결정' 숫자 배지(노란색, 지금 탭 배지와 같은 색).
  • 왼쪽 메뉴 '대화'는 그대로 '마지막 본 곳'을 엶 — 목록에서 1클릭으로 돌아올 수 있어 문제 없음.
  • 새 색·새 문구 없음. 키보드 이동: 방 목록 안에서 ↑↓로 회의실까지 이어짐.
