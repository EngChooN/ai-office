② 팀 구성 — '누가 있고 무엇을 하는지' 보이는 카드 + 3단계 만들기 추천

지금은 팀을 이름과 색만 넣어 만들고, 팀장·층·참고 문서는 카드 안 드롭다운에서 따로 고칩니다. 랩은 이름·목표·폴더·멤버·랩장을 한 칸에 몰아 받고, 카드에는 'LAB' 글자·폴더 경로·참고 문서·'새 일감'까지 다 펼쳐져 있습니다. 추천안은 '팀'은 그대로, '랩'은 '프로젝트'로 부르고, 만들기를 무엇을 만들지 → 이름·하는 일 → 사람과 리더 3단계로 나눕니다. 카드는 하는 일 한 줄·얼굴·지금 몇 명 일하는지·[일 시키기]만 보여 주고 나머지는 ⋯ 메뉴로 넣습니다.

추천 — 카드 화면

쉬운 말

  • 팀 → 팀 (설명: '늘 함께 일하는 부서예요. 한 사람은 한 팀에만')
  • 랩 → 프로젝트 (설명: '목표 하나를 위해 여러 팀에서 모여요. 한 사람이 여러 곳에')
  • 팀장·랩장 → 리더 하나로 (영어 Lead, 일본어 リーダー, 중국어 负责人)
  • '📁 프로젝트 (다른 창 직원)' → '다른 창에서 일하는 직원'
  • 랩 해산 → 프로젝트 끝내기, 팀 삭제 → 팀 없애기
  • 참고 문서 → 먼저 읽을 문서, 프로젝트 폴더 → 일하는 곳

카드

  • 머리: 색 띠·이름·종류(팀/프로젝트)·지금 일하는 사람 수.
  • 하는 일 한 줄(팀) 또는 목표(프로젝트). 비어 있으면 '하는 일을 적어 두면 직원이 일을 더 잘 나눠요 [적기]'.
  • 얼굴 줄: 리더는 왕관, 상태 점, 프로젝트는 얼굴 아래 출신 팀.
  • 버튼: 일 시키기(리더에게 지시창) · 대화방 · ⋯(이름·색, 사람 바꾸기, 먼저 읽을 문서, 층, 내보내기, 없애기).
  • 팀 이동은 사람 얼굴을 누르면 뜨는 작은 메뉴 '다른 팀으로 옮기기'.
  • 맨 끝 칸은 늘 '＋ 새로 만들기'.
'랩 → 프로젝트'는 단체방 @랩, 업무 매뉴얼, 휴대폰까지 바뀌는 큰 이름 변경입니다. 맨 끝 '정해 주실 것'에 따로 올렸습니다.
추천 — 새로 만들기 3단계

만들기 규칙

  • ① 무엇을 만들까요? 팀 / 프로젝트 두 장 중 하나. 예시가 달린 카드라 차이를 읽고 고름.
  • ② 이름과 하는 일 — 이름 예시 칩(누르면 채움), '하는 일' 한 줄(팀) 또는 '목표'(프로젝트). 색은 자동, 바꾸기만. 프로젝트는 '일하는 곳(폴더)'을 여기서 고르되 기본은 '각자 일하던 곳'.
  • ③ 누가 함께하나요? 얼굴 칩을 눌러 고르고, 고른 사람 중 ☆을 눌러 리더 1명. 리더를 안 정하면 '리더가 없으면 일을 나눠 맡기지 못해요' 안내만(막지는 않음). 팀은 이미 다른 팀에 있는 사람을 고르면 '디자인 팀에서 옮겨요' 표시.
  • [만들기] 뒤 바로 새 카드가 반짝이고 '리더에게 첫 일 시키기' 버튼을 보여 줌.
  • 먼저 읽을 문서·층은 만들기에서 빼고 카드 ⋯ 메뉴에서만.
  • 새로 필요한 데이터: 팀의 '하는 일' 한 줄(지금 팀 데이터에 없음 — 0~80자, 비어도 됨). 프로젝트는 지금 '목표' 칸을 그대로 씀.

③ 직원 패널 '결재' 탭 — 기다리는 결재와 내가 내린 결재를 한곳에 추천

지금은 결재·질문이 있으면 탭 줄 위에 '결재 대기' 칸이 생겨 패널의 최대 절반을 차지하고, 대화가 아래로 밀립니다. 추천안은 탭을 대화 · 결재 ⓷ · 바뀐 파일 · 도구 · 소개로 바꿔 결재를 탭 안으로 옮깁니다. 놓치지 않도록 대화 탭 위에는 한 줄 띠(높이 30px)만 남깁니다. 결재 탭 아래쪽에는 그 직원에게 내가 내린 결재 기록(승인·반려·답변, 누가·언제)을 날짜별로 보여 줍니다.

동작

  • 탭 순서: 대화 · 결재 · 바뀐 파일 · 도구 · 소개. 기다리는 결재가 있으면 '결재' 옆에 노란 숫자(결재+질문 합계).
  • 직원 카드의 노란 '확인하기', 단체방·결재함의 '이 직원 보기'로 패널을 열면 결재 탭이 바로 열림.
  • 대화 탭의 한 줄 띠: '결재 3건이 기다려요 · 파일 고치기 외 2건 [결재 보기]'. 간단하고 안전한 1건이면 띠에서 바로 [승인] (휴대폰 한 줄 띠와 같은 규칙).
  • 카드 모양·순서는 지금 그대로(제목 → 기다리는 이유 → 명령 보기 → 승인·반려·이 일 멈추기). 높이 손잡이·접기는 필요 없어져 없앰.
  • 다 처리하면 '기다리는 결재가 없어요' 한 줄 + 아래 기록만.
  • 기록 걸러보기: 전체 · 승인 · 반려 · 답변 · 자동. 한 줄 = 결과 · 무엇을(쉬운 문장) · 시각 · 누가(PC / 휴대폰 / 자동결재 / 규칙). 누르면 원래 명령 펼침.
  • 처음 20건, '이전 기록 더 보기'로 이어서.

결재 기록 데이터 확인 결과

  • 지금 있는 것: 직원 기록에 결재 줄이 남습니다('승인: …', '반려: …', '답변: …', '🤖 자동결재 승인: …', '규칙으로 자동 승인: …'). 보관 한도 없음.
  • 모자란 것: ① 카드 제목인 쉬운 문장('파일을 고쳐요')이 저장되지 않아 기록엔 원래 명령만 남음 ② 승인/반려·누가 했는지가 문장 속에만 있음 ③ 요청 시각이 없음 ④ 결재만 골라 읽는 방법이 없어 최근 300줄 안에 결재가 몇 건 없을 수 있음.
  • 제안: 결재를 처리할 때마다 한 줄씩 따로 저장하는 '결재 기록' 장부를 새로 둡니다(직원·요청 시각·처리 시각·결과·누가·쉬운 문장·원래 명령·답). 예전 기록은 지금 문장을 읽어 한 번 옮기고, 쉬운 문장이 없으면 원래 명령을 보여 줍니다.
  • 함께 발견: 휴대폰에서 승인·반려한 줄에 '원격' 표시가 화면에서 빠지는 문제가 있습니다(추정 아님, 코드 확인). 개발팀에 함께 넘깁니다.

④ 기록 — 오늘 요약 먼저, 직원별로 묶고, 눌러서 펼치기 추천

지금 '기록 › 보고서'는 모든 직원의 모든 기록이 12px 글자·16px 얼굴로 한 줄씩 시간순으로 섞여 있고, 글은 3줄까지 펼칠 방법이 없습니다. 요약(일일 보고서)은 오른쪽에 마크다운 글로 따로 있습니다. 추천안은 오늘 요약 숫자 4개를 맨 위에 두고, 기록을 직원별 묶음으로 바꿉니다. 각 줄은 한 줄 요약만 보이고, 누르면 전체 글과 결과물이 펼쳐집니다. 기본으로는 끝낸 일·문제·결재만 보이고, '도구 사용'은 지금처럼 숨깁니다.
