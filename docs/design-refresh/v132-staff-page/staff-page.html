2. '직원' 화면 — 지금 무엇이 어려운가

사이드바 '직원'을 누르면 대시보드 탭이 열립니다(메뉴 이름과 화면 이름이 다름). 숫자 칸 6개 → 상황판 카드 3개 → 직원 카드 순서라, 정작 '직원'은 스크롤 아래에 있습니다. 카드에는 직무 이름 한 단어뿐이라 무엇을 시킬 수 있는지 알 수 없습니다. 아래는 코드 기준으로 다시 그린 지금 화면입니다.

짚은 곳

  1. 1메뉴는 '직원', 탭은 '대시보드' — 어디 왔는지 헷갈림. 직원 목록은 맨 아래.
  2. 2숫자 칸 6개 + 카드 3개가 먼저 나옴. '확인 필요'가 칸(직원 수)과 카드(건수)에 같은 이름 다른 뜻으로 두 번.
  3. 3'대기'(일 없음)·'연결 대기'(인터넷)·'퇴근'이 비슷하게 읽힘.
  4. 4'오늘 토큰', 카드 아래 'Lv.3 · 12,480 토큰 · $0.42' — 토큰·달러는 개발 용어. 비용은 '기록 › 비용'에 이미 있음.
  5. 5직무 한 단어('프론트엔드 개발자')만 있고, 시킬 수 있는 일·지시 버튼이 카드에 없음(카드를 눌러 패널을 열어야 함).
  6. 6직원 추가 버튼이 이 화면에 없음 — 맨 위 앱 바 오른쪽 '직원 고용'뿐.
  7. 7마지막 활동이 'Edit · src/…'처럼 도구 이름으로 나올 때가 있음.

직원을 누르면 나오는 패널도

  • 머리에 Opus 같은 모델 이름, ~/flitto/poc/… 폴더 경로, '터미널에서 이어 하기'.
  • 탭 '변경' 안은 커밋·PR·diff — 비개발자에게 가장 낯선 곳.
  • 고용 때 적은 '업무 지침'은 패널 어디에도 안 보임.
  • 고용 창 직무 칩 11개에 설명이 없음. '고용 뒤에는 AI를 바꿀 수 없어요' 문구는 실제 동작(프로필에서 바꿀 수 있음)과 다름.

A안 · 직원 명함 카드 추천

'직원'을 누르면 바로 직원 카드가 보입니다. 카드 한 장에 지금 하는 일(문장) · 이런 일을 시킬 수 있어요(직무별 예시 3개, 누르면 바로 지시창에 채워짐) · 일 시키기 버튼을 넣고, 마지막 칸은 늘 '＋ 직원 추가' 빈자리입니다. 숫자 칸 6개는 한 문장 요약으로, 상황판 카드는 '확인 기다림'만 카드 안 버튼으로 남기고 토큰·활동은 다른 화면으로 보냅니다.

A안 규칙

  • 탭 이름: 대시보드 → 직원 목록, 조직도 → 팀 구성.
  • 맨 위 한 문장: '6명 중 2명 일하는 중 · 2명이 대표님 확인을 기다려요 · 1명 문제 생김'. 굵은 부분을 누르면 그 상태만 걸러짐(지금 숫자 칸과 같은 동작).
  • 정렬은 지금처럼 급한 순: 확인 기다림 → 문제 → 일하는 중 → 쉬는 중 → 퇴근.
  • 카드 3줄 구조(높이 고정): 머리(얼굴·이름·직무·팀·상태) / 지금 하는 일 / 시킬 수 있는 일 / 버튼.
  • 버튼은 상태에 맞게 1개만 강조: 확인 기다림 = 노란 '확인하기', 문제 = 빨간 '다시 시도', 나머지 = '일 시키기'. '자세히 ›'는 지금 패널을 엶.
  • 토큰·달러·Lv는 카드에서 뺌(비용은 '기록 › 비용', 레벨은 사무실 화면과 프로필). 오늘 쓴 양이 예산을 넘을 때만 카드에 '오늘 많이 씀' 꼬리표.
  • '확인 필요'·'쓴 토큰'·'최근 활동' 상황판은 업무 모드 첫 화면에서 계속 필요 → 직원 목록 아래 접는 칸으로 둠(기본 접힘, 2026-11-13 대표 확정).
  • 사무실 미니 화면은 카드 머리 얼굴로 대신(업무 모드와 같은 모습).

B안 · 상태별 목록 + 오른쪽 직원 소개

직원이 많을 때(10명 이상) 한 화면에 더 많이 보이는 안입니다. 왼쪽은 '대표님 확인을 기다려요 / 일하는 중 / 문제 생김 / 쉬는 중' 묶음별 한 줄 목록, 오른쪽은 고른 직원의 소개(무슨 일을 하는 사람인지, 시킬 수 있는 일, 쓸 수 있는 도구를 쉬운 말로, 바로 지시하기)입니다. 직원 추가는 위쪽 버튼과 목록 맨 아래 빈 줄 두 곳.

B안 규칙

  • 목록 한 줄: 얼굴 · 이름/직무 · 지금 하는 일(문장) · 얼마나 됐는지.
  • 묶음 제목이 곧 상태라, 줄마다 상태 글자를 반복하지 않음.
  • 오른쪽 소개 = 지금 패널의 '프로필'을 앞으로 꺼낸 것. '도구'는 장비 탭 내용을 ✓/확인 받고/✕ 세 가지로만.
  • 장점: 한눈에 많이, 소개를 읽으며 바로 지시. 단점: 화면이 좁으면(900px 아래) 소개가 위로 겹쳐 떠야 함, 사무실 느낌(카드·얼굴)이 A보다 약함.

A와 비교

  • A: 직원 3~9명, 처음 쓰는 사람에게 가장 쉬움. 카드만 보고 시킬 일을 고름.
  • B: 직원 10명 이상, 매일 쓰는 사람에게 빠름. 한 번 더 눌러야 시킬 일이 보임.
  • 지금 사용자 다수가 직원 5~8명(대표 화면 기준, 추정) → A 추천. 나중에 A에 '목록으로 보기'(지금도 있음)를 B의 줄 모양으로 바꾸는 것도 가능.

A·B 공통 · 직원 추가 3단계, 패널 머리, 쉬운 말 표

어느 안이든 함께 바꾸는 부분입니다. 직원 추가는 '직무 고르기 → 이름·얼굴 → 일할 곳' 3단계로 나누고, 직무 카드에 무슨 일을 하는 사람인지 한 줄을 붙입니다. 지금 '자세히 설정'(AI·결재 방식·업무 지침)은 3단계 안에 접어 둡니다.

직원 추가 3단계

  1. 어떤 일을 맡길까요? 직무 카드 11개(설명 한 줄). '직접 입력'도 여기.
  2. 이름과 얼굴 — 직무에 맞춰 자동 추천, 바꾸기만.
  3. 어디서 일할까요? 폴더 고르기 또는 '아무 프로젝트나'(기본). '자세히 설정'은 여기 접어 둠.

버튼 이름: '직원 고용' → '직원 추가'(사이드·카드·앱 바 모두). 마지막 버튼 '고용하기' → '일 시작하기'.

패널 머리

  • 모델 이름 → 프로필의 'AI 등급 ●●●●○'로만.
  • 폴더 경로 → '일하는 곳: claude-office'(폴더 이름만, 누르면 전체 경로).
  • '터미널에서 이어 하기' → ⋯ 메뉴 안.
  • 탭: 업무·변경·장비·프로필 → 대화·바뀐 파일·도구·소개. '소개'에 업무 지침을 보여 주고 고칠 수 있게.
