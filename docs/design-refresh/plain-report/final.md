# 쉬운 말 보고 — 구현 기록 (정리드)

규칙 원문: `rules.md`(김기획) · 대표 결정: 기본 쉬운 말, 설정에서 전문가 말투, 비서도 반드시 포함.
설계 비교(최가독·박패턴)는 대표 지시 범위(1~5단계)와 "가장 단순한 안" 원칙에 따라 생략했다.

## 결정
| 쟁점 | 선택 | 이유 |
|---|---|---|
| 설정 값 | `Settings.reportStyle?: 'easy' \| 'expert'`, 없으면 쉬운 말 | `tokenSaverMode`와 같은 선택 칸 방식 — 옛 설정 파일을 고칠 필요 없음 |
| 문안 | `rules.md` 2·3절을 줄여 `staff.reportStyle.easy/expert`(4개 언어) | 토큰 절약. 형식·결재·질문·위임 도구 사용은 그대로라는 한 줄을 끝에 붙임 |
| 직원 | `hired.ts` 세션 시스템 프롬프트에 언어 규칙 바로 뒤 한 번 | 세션 프롬프트를 만드는 곳이 하나뿐이라 중복 없음. 새 세션부터 적용 |
| 비서 | `secretary.ts` 질문마다 만드는 시스템 프롬프트 | 바탕화면 비서도 같은 `secretaryAsk`를 씀. 바로 적용 |
| 회의·데모데이 발언 | 넣지 않음 | 2~4문장 발언이라 이미 짧음, 토큰 절약 |
| 휴대폰 | 원격 설정 허용 목록에 추가 | 다른 일반 설정과 같음 |
| 설정 문구 | rules.md 5절. "진행 중인 일은 그대로" → "새로 시작하는 대화부터 적용" | 실제 적용 시점(새 세션)에 맞춤 |

## 시험
`scripts/reportStyle.test.mts` — 기본값이면 쉬운 말이 한 번만, 전문가로 바꾸면 새 세션에 전문가 문안만, 비서 프롬프트 포함, 휴대폰 허용.
