# 휴대폰·PC 연결 개편 — 인계 메모 (시안 단계, 대표 채택 전)

- 작성: 이디자 · 2026-11-12 · 기준 1.2.0 (`RemoteSection.tsx`, `PeerSection.tsx`, `dict/featuresB.ts`·`peer.ts`, 안드로이드 `strings.xml`)
- 시안: `connect.html` (탭: 지금 화면의 어려운 점 · 쉬운 말 비교표 · 1안 · 2안 · 3안), 캡처 `cn-*.png`
- '지금 화면'은 코드로 다시 그린 그림이고 실제 캡처가 아닙니다. QR은 모양만 흉내 낸 가짜입니다.

## 지금 화면의 어려운 점 (12)
1. 가이드 단계 칩 5개(켜기·포트·공유기·주소·QR)가 실제 거치는 단계와 다름(Tailscale·같은 네트워크는 포트 → QR로 건너뜀)
2. 첫 선택 '연결 방식'이 기술 말. 휴대폰 쪽엔 Tailscale 설명 없음
3. Tailscale ①②③ 상자와 가이드 창 5단계가 따로 있음. ② 휴대폰 설치는 끝났는지 표시 없음
4. 상태 줄이 주소·포트 숫자 위주, 휴대폰이 지금 연결됐는지는 안 보임
5. QR 보기 / QR 다시 만들기(모두 끊김) / 가이드 다시 보기가 한 줄에 같은 크기
6. 연결 코드가 QR 창이 아닌 설정 아래에 있음. 휴대폰 앱에선 '주소로 연결'로 이름이 다름
7. 지문 원문, 최근 접속 기록 `GET /v1/status · 200` 노출
8. 다른 PC 연결에 '휴대폰 연결'의 원격 켜기가 필요 — 화면 구조로 드러나지 않음
9. '직원 보내는 PC / 불러오는 PC' 방향이 헷갈림, 네트워크 확인은 안내만
10. 포트 번호 입력이 모든 방식에서 필수 단계
11. 같은 경고(QR = 모든 권한)를 3~4번 다른 말로 반복
12. 고급 방식 용어(UPnP·포트포워딩·DDNS·내부 IP·TCP·이중 NAT·통신사 공유 주소)

## 쉬운 말 원칙 (비교표 32개는 `connect.html` › 쉬운 말 비교표)
- '원격' → '연결', 설정 제목은 '휴대폰·PC 연결' 하나로
- '연결 방식' → '어디서 쓰실 건가요?' (같은 와이파이 안에서만 / 밖에서도(추천) / 고급: 공유기 직접 설정)
- Tailscale은 처음 나올 때마다 '내 기기끼리 잇는 무료 앱'을 붙임
- 'QR을 못 찍을 때 코드' = '코드로 연결' — PC·휴대폰 같은 이름
- '직원 보내는/불러오는 PC' → '이 PC 직원 빌려주기 / 다른 PC 직원 데려오기'
- 포트·지문·주소·접속 원문은 '고급' 안으로, '휴대폰 모두 끊기(새 QR)'는 따로 빨간 접이식

## 시안 3안
| 안 | 핵심 | 장점 | 단점 |
|---|---|---|---|
| 1안 1·2·3 단계형 | 설정 화면 자체가 세로 3단계(어디서 → 준비물 자동 확인 → 휴대폰/다른 PC 찍기), 끝나면 연결된 기기 목록 | 새 창 없음, 지금 기능 그대로 | 단계 중엔 설정이 길어짐 |
| 2안 QR 중심형 | 첫 화면 QR 한 장 + [연결 켜고 QR 보기], 막히면 '안 되나요?' 질문 목록 | 가장 빠름·짧음 | 기본을 '같은 와이파이'로 시작 → 밖에서 쓰려면 방식 바꾼 뒤 다시 찍기 |
| 3안 마법사형 | [기기 연결하기] → 창 4장(무엇을 → 어디서 → 준비물 → 찍기) | 처음 쓰는 사람이 가장 덜 헤맴, 어디서든 띄우기 쉬움 | 넘기는 화면이 많음, 휴대폰 앱 질문 화면은 안드로이드 작업 필요 |

추천: **1안** (지금 기능만으로 가능, 휴대폰·다른 PC가 한 흐름으로 합쳐짐). 처음 쓰는 사람 편의가 최우선이면 3안.

- 영어·일본어·중국어 문구는 채택 뒤 같은 뜻으로 맞춤
