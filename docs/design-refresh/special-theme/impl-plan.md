# 특별 테마 A안(레트로 도트) 최종 구현 설계 — 정리드

> 2026-11-13 · 근거: `plan-choi.md`(최가독), `plan-park.md`(박패턴), `notes.md`, `special-theme.html` A 규칙.
> 착수 조건: v1.3.2 2차 개선 QA(오큐에이) 통과 후. 경로는 `app/src/` 기준.

## 0. 방향 (두 안 공통 → 그대로 채택)
- 새 테마 id `retro` 하나를 기존 테마와 같은 `<html data-theme data-mode>` 구조로 추가. 별도 스위치·새 설정 항목 없음. 기본 `lavender` 불변.
- 새 규칙은 전부 `renderer/theme-retro.css` 한 파일, `[data-theme='retro']` 아래에만.
- 기존 토큰(`--background`, `--card`, `--primary`, `--radius*`, `--shadow-*`, `--focus-ring`, `--text-*`, `--font-sans`)에 값만 바꿔 넣어 부품 수정을 최소화.
- 코드 기준 기존 테마는 10종(요청서의 13종 아님 — 최가독 확인).

## 2. 자동 시험 (`scripts/themeRetro.test.mts`, 박패턴 안 채택)
1. 스코프: `theme-retro.css` 최상위 규칙이 모두 `[data-theme='retro']`로 시작(`@font-face`·`@keyframes`·`@media` 내부 포함).
2. 토큰 누락: 라벤더 블록의 변수 이름 ⊆ retro 라이트·다크 블록.
3. 테마 목록 동기화: `UI_THEME_IDS` = `index.html`·`remote.html` 부트 정규식(`mobile.html` 경로는 단계 0에서 확인 후 포함).
4. 대비: 본문·보조·버튼·배지·경고·선택 행 ≥ 4.5, 입력칸·버튼 경계 ≥ 3.
5. 글자 크기: `renderer` 전체의 `text-[Npx]` 값이 대응표에 모두 있음.
6. 움직임: 모든 `animation`이 `prefers-reduced-motion` 블록에서 꺼짐.
7. 비상구: 저장값 `retro`가 목록에서 빠지면 `sanitizeUi`가 기본으로 되돌림.
- 채택 안 함: 박패턴의 `index.css` 토큰 해시 시험 — v1.3.2 등 정상 수정마다 깨져 유지비가 큼. 스코프 시험 + 기존 테마 화면 대조로 대신함.

## 3. 단계
**단계 0 (스파이크, 반나절~1일, 머지 안 함)**: 버튼·카드·입력·대화상자를 retro로 그려 확인 — 레이어 우선순위(`!important` 없이 이기는지), Tailwind `--text-*` 변수 반영, `overflow-hidden` 안 테두리 잘림(4px/6px), `select`·`dialog` 모서리, `lucide` 클래스 이름, 모바일 진입 CSS·`mobile.html` 부트, 원격 서버의 글꼴 파일 제공, 글꼴 글자 범위 대조표, 윈도우 배율 흐림. 결과로 이 문서 보정.

**1차 (핵심 화면)**: 테마 등록(uiTheme·i18n 4개 언어·부트 정규식·`windowBg`) + `theme-retro.css`(색·모양·글꼴·크기·움직임) + `button.tsx` `data-variant` + `select`·`dialog` `data-slot` + `DuoIcon` 21개 도트판(`pixel-icon-data.ts`) + lucide CSS 각짐 + 기록 글자 크기 3단계 + `data-lang` + 글꼴 3개·OFL 동봉.
- 화면: 설정(테마 고르기), 상단·사이드, 직원 패널, 결재 카드, 대화, 대화상자, 지도 위 HUD.
- 완료 기준: ① 고르면 즉시 적용·재실행 유지·첫 화면 번쩍임 없음, 다른 테마로 바꾸면 흔적 0 ② 기존 테마(`lavender`·`mono`·`candy` × 라이트·다크) 화면 변경 전후 동일 ③ §2 시험 전부 통과 ④ 핵심 화면 라이트·다크 캡처가 시안 A 규칙과 일치 ⑤ 한·영·일·중 빠진 글자 없음 ⑥ 윈도우 100/125/150%·폰 폭에서 잘림 없음 ⑦ 원격 화면에서 글꼴 로딩(CSP 오류 0) ⑧ typecheck·test 통과, 맥·윈도우 빌드 통과, 설치 파일 크기 전후 기록.

**2차 (나머지)**: 나머지 화면 줄바꿈 보정, lucide 상위 약 10개 도트판, ▶ 선택 표시·이름표 대화창·칸 끊긴 막대·바탕 체크 무늬, 마크다운 표·코드, 바탕화면 비서 창, 부트 정규식 단순화, 필요하면 "도트 글꼴만 끄기".

## 4. 남는 위험
1. 12px 올림·15px 본문으로 좁은 칸 줄바꿈·잘림(가장 큼) → 화면별 캡처 확인.
2. 갈무리의 일·중 글자 부족(미확인) → 단계 0 대조표.
3. 윈도우 125·150%에서 도트 글자 흐림은 막을 수 없음 → 한계로 기록.
4. 글꼴 1.24MB가 설치 파일·휴대폰 첫 접속에 추가됨.

## 5. 구현 기록 (2026-11-13, 정리드)
- **다크 전용(대표 방침 변경):** 라이트 세트를 만들지 않는다. `DARK_ONLY_THEMES`·`themeMode()`(shared/uiTheme.ts)로 레트로를 고르면 저장된 `uiMode`와 상관없이 화면·창·기본 부품(nativeTheme)이 다크, 다른 테마로 바꾸면 원래 설정으로. 첫 페인트 스크립트(index·remote)도 같은 규칙. `windowBg('retro')`는 다크 한 값.
- **글자 범위 대조(fonttools):** ko·en은 기호·이모지만 없음(기기 글꼴로 대체). ja는 갈무리14·11에 모두 있음, 굵은 글꼴만 가나 없음 → ja는 굵은 자리도 `Galmuri11`. zh는 간체 약 1/3 없음 → 글자는 기기 글꼴, 영문·숫자만 도트(`Galmuri11 Latin`, unicode-range).
- **설계와 달라진 점:** ① DuoIcon 21개 도트판 대신 CSS로 선 끝·꺾임을 각지게(`[data-duo]`·`.lucide`) — 그림 21개를 새로 그리는 비용 대비 효과가 작아 보류. ② `rounded-full` 일괄 0, 예외 `data-keep-round`는 아직 쓸 곳 없음. ③ 그림자 4px로 확정. ④ 대표 피드백 반영: 스위치(52×20 홈 트랙·ON/OFF·손잡이 그림자 없음)·체크박스·라디오(네모 칸·도트 체크), 테마 카드(미리보기 그림·'레트로 오피스 게임'·한 줄 설명·'다크 모드로 보여요'·사용 중 표시·기본 테마로 돌아가기), 간격 1할 확대(`--spacing: .275rem`)·줄 간격 1.6~1.7.
- **검증:** `tsc` 0, 테스트 1413(실패 0, 건너뜀 1), `themeRetro.test.mts` 11개. 다크 캡처 `special-theme/impl/dark-*.png`. 결재 카드는 결재 건이 없어 캡처 못 함. 맥·윈도우 빌드·윈도우 배율 125/150%·폰 폭은 아직 확인 못 함.
