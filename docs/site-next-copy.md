# 소개 페이지·리드미 개편안 (1.4.0 이후 배포 기준) — 기능 목록·구성안·한국어 문구

> 작성: 김기획(PM) · 코드는 고치지 않았다 · 기준: CHANGELOG 1.1.0~1.4.0과 `[미정]`, `git log a926b16..HEAD`(30개), 현재 `site/index.html`의 `T.ko`.
> 이 문서는 지난 구성안(0.14~0.15 기준)을 **대체**한다. 영어·일본어·중국어는 한국어 확정 뒤 같은 키로 옮긴다(이 단계에서는 한국어만).
> 쓰기 규칙: 개발 용어 금지, 확인 못 한 기능은 넣지 않고 아래 0절에 모은다.

## 0. 확인 필요 (대표·정리드)

1. **비서 새 기능 4종은 아직 앱 화면에서 눌러 본 확인이 없다.** 커밋 메시지와 QA 기록("코드·시험 확인, 화면 조작은 실제 데이터 창 겹침으로 중단", `bc4c439`)만 근거다. 아래 문구는 "이번 배포에 실린다 + 실제 화면 확인을 통과한다"를 전제로 쓴다. 통과 못 하면 해당 문구·캡처를 뺀다.
2. **기존 사이트의 `n2` "다른 PC 직원과 함께 일하기"는 지금 앱과 맞지 않는다.** 1.4.0에서 "다른 PC에 직원을 빌려주거나 데려오는 기능은 없어졌다". 이 키는 새 문구로 **교체**한다(→ `phone.*`·`device.*`). 또 1.3.0의 "다른 PC를 연결해 그 PC의 사무실·직원을 보고 일 시키기·최대 3대"가 1.4.0 '다른 기기 연결 카드'에서도 그대로인지 확인하지 못했다. 그래서 여러 PC 연결은 "다른 PC도 연결해 오가요"까지만 쓰고 '3대'는 넣지 않았다. 확인 필요.
3. **색 테마 개수**: 사이트는 "6종"이라 쓰는데 1.2.0에서 4종이 늘어 **10종**(+ 1.4.0 '레트로 오피스 게임' 특별 테마)이다. 새 4종 이름(오로라·황혼·캔디·초원)만 CHANGELOG로 확인했고, 실제 설정 화면 칩 개수는 캡처 때 확인한다.
4. **휴대폰 반응 개선("빨라졌어요")**: 처리 중 표시·보내는 중 말풍선은 화면으로 구현됐지만, 속도 자체가 얼마나 빨라졌는지 잰 값은 확인하지 못했다. 문구는 "바로 처리 중으로 바뀐다"는 눈에 보이는 변화만 쓰고 "빨라졌다" 수치는 넣지 않았다.
5. **파일 찾기·긴 대화 요약 비용**: 요약 비용은 추정 단계(`docs/specs/secretary-next.md`)라 사이트에는 비용을 쓰지 않는다. 파일 찾기에서 열 수 있는 형식 범위는 문구에 "허용된 형식만"으로만 쓴다.
6. **버전 번호**: 사이트는 최신 릴리즈를 자동으로 읽어 오고(기본값 `0.16.2`는 실패 시 대비 값), 문구에는 번호를 쓰지 않는다. 기본값 숫자가 낡았으니 배포 번호가 정해지면 정리드가 갱신한다(확인 필요).
7. 소개 문구에 쓴 "Fable 모델"은 CHANGELOG 1.2.0 근거만 있다. 현재 모델 목록에서 그대로 보이는지 확인하지 못했다.
8. 캡처 파일은 새로 찍어야 하는 것이 많다(2-2절). 레트로·비서 카드·아침 요약은 **실제 데이터가 없는 개발 창(`AI_OFFICE_USER_DATA`)** 에서 찍는다(개인 창 노출 방지).

## 3. 한국어 문구 (사이트 키 단위)

표기: `키` — 문구. 바꾸지 않는 키는 "유지"로 적고 문구는 생략한다. `<em>`·`<br>`·`{os}` 같은 자리 표시는 기존 방식 그대로.

### 3-1. 메타·첫 화면

- `meta.title` — AI Office — 말로 시키면 AI 직원들이 일하는 사무실
- `meta.desc` — Claude와 GPT 직원을 뽑아 일을 맡기고, 중요한 일만 결재하고, 끝나면 보고받는 무료 오픈소스 앱. 비서에게 물으면 결재·요약·파일 찾기까지 해 줘요. 어려운 설정은 필요 없어요.
- `badge.oss` — 유지(무료 · 오픈소스 · 맥·윈도우·안드로이드)
- `hero.title` — 말로 시키면 AI 직원들이 일하는<br><em>나만의 사무실</em>, AI Office
- `hero.lead` — Claude 직원과 GPT 직원을 한 사무실에 뽑아 일을 맡기세요. 위험한 일은 먼저 물어보고, 끝나면 보고해 줘요. 비서에게 "밤사이 어땠어?" 하고 물어보면 정리해서 알려 줘요. 명령어 창도, 어려운 설정도 필요 없어요.
- `nav.how` 사용법 · `nav.day`(신규) 하루 · `nav.secretary`(신규) 비서 · `nav.features` 기능 · `nav.screens` 휴대폰 · `nav.look` 스타일 · `nav.grow` 꾸미기 · `nav.download`·`nav.faq` 유지
- `btn.*`, `hero.limits`, `limits.*`, `os.*`, `hero.android.note`, `hero.ios.note` — 유지

## 5. CHANGELOG `[미정]` 보충안

현재 `[미정]`은 개선 8줄로, 규칙(새 기능 5·개선 4·버그 수정 4 이하, 같은 화면 합치기)을 넘는다. 아래처럼 **새 기능으로 올릴 것·합칠 것·버그 수정으로 나눌 것**을 정리한 전체 안이다(한눈에 보기 포함).

```md
## [미정] (설치본 미빌드)
PC 앱 전용: 비서 새 기능은 PC 앱에서 써요. 파일 열기는 휴대폰에서 안 되고(찾기만 돼요), PC 앞에서만 열 수 있어요.

### 한눈에 보기
- **새 기능** 비서 답 안에서 결재를 바로 승인해요
- **새 기능** 돌아오면 비서가 밤사이를 요약해요
- **새 기능** 비서가 파일·폴더를 찾아 열어 줘요
- **새 기능** 긴 대화도 요약해서 이어 가요
- **개선** 휴대폰에서 누르면 바로 '처리 중'이에요

### 새 기능
- 비서가 알려 준 결재를 대답 안의 카드에서 바로 승인·반려해요. 결재함과 같은 내용이고, 이미 처리된 건 '이미 처리됐어요'로 보여요.
- 6시간 넘게 비웠다 돌아와 비서를 처음 열면 끝난 일·기다리는 결재·오류를 한 번 요약해 줘요. 설정 스위치나 '다시 안 보기'로 꺼요.
- 오래된 대화를 값싼 모델로 짧게 요약해 이어 붙이고, 대화 맨 위에 '앞 대화 요약'으로 보여 줘요. 대화와 같이 30일 보관돼요.
- 비서가 직원 결과물·받은 첨부·프로젝트 폴더 안에서 파일·폴더를 찾아 열어 줘요. 열기는 확인 카드 한 번을 거치고 실행 파일은 폴더만 보여 줘요. 휴대폰에서는 찾기만 돼요.
- 비서에게 팀·프로젝트 방에 말을 남기거나 답장하게 시켜요. 확인 카드에 받는 방·보내는 방식·답장할 글이 보이고, 방에 보낸 말은 일하는 직원이 하던 일을 마치면 전해져요.

### 개선
- 바탕화면 비서가 앱과 같아졌어요: 결재 카드가 같은 제목·내용·요청한 사람을 보이고 ⋯ 메뉴로 '앞으로 자동 승인'·'일 멈추기'·'앱에서 열기'를 해요. 머리줄은 '작업 중 N명'과 '대기 n명'으로 나눠 보여요. 레트로 오피스 게임 테마도 비서 창에 적용돼요.
- 비서에게 연달아 물으면 '차례 기다림 · n번째'가 보이고, 하나씩 빼거나 하나로 합쳐 물어요(너무 길면 그대로 둬요). 비서가 지금 메뉴 이름으로 길을 알려 주고, 메뉴바(윈도우는 알림 영역)에서 바탕화면 비서를 켜고 꺼요. 리눅스는 비서 설정이 보이지 않아요.
- 휴대폰(과 다른 PC 원격 창)에서 승인·반려를 누르면 바로 '처리 중'으로 바뀌고, 보낸 글이 '보내는 중'으로 먼저 보여요. 실패하면 '다시 보내기'가 떠요.
- 휴대폰의 입력줄·위쪽 버튼 크기와 간격이 정리됐고, 직원 대화 입력줄이 단체방과 같은 모양이 됐어요. 업무 보드 칸은 카드 높이만큼만 차지해요.

### 버그 수정
- 휴대폰에서 승인·반려가 성공했는데 실패로 보이던 문제와, 실패 말풍선이 늦게 뜨던 문제를 고쳤어요.
- 사무실에서 건물 바깥 거리를 눌렀는데 숨어 있던 직원이 선택되던 문제를 고쳤어요. 오른쪽의 층 버튼은 없앴어요.
- 휴대폰에서 막아 둔 설정을 비서 카드로 바꿀 수 있던 문제를 막았어요.
- 레트로 오피스 게임 테마에서 선택된 탭 앞의 ▶가 거슬리던 것을 없애고 메뉴 숫자 뱃지를 줄였어요. 비서 머리줄 이름이 잘리지 않아요.
```
