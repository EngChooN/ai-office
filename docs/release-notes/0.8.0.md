이번 릴리스는 **세 가지 번호가 따로** 움직입니다. 서로 짝이 맞는 것끼리만 같이 쓰세요.

## 꼭 알아 둘 것 (4가지 + 1)
1. **원격 기능은 기본으로 꺼져 있어요.** 설정 › 휴대폰 연결에서 켤 때만 켜집니다. 끄면 포트가 바로 닫힙니다. 쓰지 않으면 켤 필요가 없습니다.
2. **포트를 열 때는 보안에 주의하세요.** 켜면 이 PC의 포트 하나(기본 47900)가 인터넷 쪽으로 열립니다.
   - 공유기가 자동 설정을 받지 않으면 공유기 관리 화면에서 직접 열어야 합니다.
   - 열린 포트는 누구나 두드려 볼 수 있습니다. 앱은 토큰이 있어야만 답하고, 틀린 시도는 횟수를 제한해 잠그며, 잠기면 PC에 알립니다. 그래도 **쓰지 않을 때는 끄세요.**
   - QR에는 접속 열쇠(토큰)가 들어 있습니다. QR을 사진으로 남기거나 남에게 보이지 마세요. QR은 5분 뒤 화면에서 가려집니다.
3. **인증서가 고정돼 있어요.** 휴대폰은 QR에 담긴 이 PC의 인증서 지문과 다른 서버에는 연결하지 않습니다(무시하고 계속 버튼 없음). **PC의 원격 키가 바뀌면**(키를 지웠거나 저장된 키를 읽지 못해 새로 만든 경우 등) **QR을 다시 만들어 휴대폰을 다시 연결해야 합니다.**
4. **알림이 수십 분 늦을 수 있어요.** 이번 버전의 휴대폰은 15분쯤마다 PC에 새 결정이 있는지 물어봅니다. 절전 상태(Doze)나 배터리 최적화에 따라 더 늦어질 수 있습니다. 앱을 열면 바로 최신 상태를 불러옵니다. 즉시 알림(푸시, FCM)은 다음 단계입니다.
5. **휴대폰에서 하는 지시·결재는 PC에서 직접 하는 것과 같은 힘이 있어요.** 휴대폰에서 결재를 승인하면 직원이 그 명령을 실제로 실행합니다. 휴대폰을 잃어버리면 PC에서 바로 **"QR 다시 만들기"** 를 누르세요. 이전 열쇠가 즉시 막히고 연결된 휴대폰이 모두 끊깁니다.

## 데스크톱 0.8.0
**새 기능 — 휴대폰 연결 (PC 쪽)**
- 설정 › 휴대폰 연결: 켜기 전 주의 확인 → 포트 → 공유기 자동 설정(UPnP) → 주소(선택) → QR 순서의 안내.
- 휴대폰으로는 상태 보기·결재·질문 답하기·기획 확인·지시만 할 수 있습니다. 파일 보기, 고용·퇴사, 설정 변경은 할 수 없습니다.
- 휴대폰에서 한 일은 기록에 "📱 원격"으로 남습니다. 최근 접속 기록 20건도 볼 수 있습니다.
- 결재 내용이 너무 길어 일부만 보이면 휴대폰에서는 **반려만** 가능하고 승인은 PC에서 합니다. 직원이 지금 하는 일은 "Bash 실행 중"처럼 도구 이름만 보냅니다(명령·파일 위치는 보내지 않음).
- 보안 점검을 3번 거쳐 지적 사항을 모두 반영했습니다(자세한 변경은 `docs/changelog-dev.md`).

**개선**
- 일하던 직원을 Esc·중단으로 멈추고 말을 걸면, 이야기가 끝난 뒤 하던 업무를 알아서 이어서 합니다.
- 직원이 후속 업무 카드를 올릴 때 담당을 정할 수 있습니다.

**설치 파일**
- 맥(Apple Silicon): `Claude Office.dmg`
- 윈도우(시험판, 설치 없이 풀어서 `claude-office.exe` 실행): `Claude Office-win32-x64-0.8.0.zip`
- 서명·공증이 없어 처음 열 때 경고가 나옵니다(맥: "그래도 열기", 윈도우: "추가 정보 › 실행").

## 안드로이드 1.0.0
- 대상: Android 8.0 이상. 설치: APK를 폰으로 옮겨 "출처를 알 수 없는 앱 설치"를 허용한 뒤 설치합니다.
- 할 수 있는 일: QR 연결 · 직원 상태 목록 · 대기 결정(결재·질문·기획 확인) 승인·반려·답변 · 직원에게 지시 · 연결 문제 안내 화면(원격 꺼짐, PC 응답 없음, 오프라인, 토큰 폐기, 잠김 카운트다운, 인증서 불일치) · 백그라운드 새 결정 알림.
- 보안: 평문 통신 차단, 토큰은 폰의 보안 저장소(Keystore)에만, 사용자 설치 인증서는 신뢰하지 않음, 릴리스는 디버깅 꺼짐.
- 서명 지문(SHA-256): `0d0c4c7953462e5850b9d0c4a5281dbab25db806a062cfc5e602f52e10818f76` — 설치 전 받은 APK의 지문과 같은지 확인하세요(`android/README.md`).
- 이번 버전에 없는 것: 푸시 알림(FCM), 첨부, 업무 보드, 단체방 보기, iOS.

## 프로토콜 v1
- HTTPS(자체 서명, TLS 1.2 이상)와 `Authorization: Bearer <토큰>`. 경로 4개: 상태 조회, 대기 결정 목록, 결정 응답, 지시 전송.
- 연결 정보는 QR 하나에 들어 있습니다(주소·포트·토큰·인증서 지문, 푸시용 예약 필드).
- 모르는 필드는 양쪽 모두 무시하므로, 필드가 늘어도 v1은 유지됩니다. 호환이 깨질 때만 v2.

## 아직 확인하지 못한 것
- 테스트와 에뮬레이터·실제 PC 연결로 확인했습니다(QA 3차 pass). 아래는 **실기기에서만** 볼 수 있어 아직 확인하지 못했습니다. 체크리스트: `docs/specs/android-real-device-checklist.md`
  - LTE(외부망)로 접속, 공인 IP가 바뀐 뒤의 동작
  - 공유기 뒤에서 IP별 잠금이 실제로 구분되는지, 잠금 때 PC 알림 표시
  - 절전(Doze) 중 알림이 실제로 얼마나 늦는지(실측값은 확인 뒤 이 문서에 적습니다)
  - 폰 가로 화면·키보드가 입력창을 가리는지
  - 결재·기획 종류의 결정 응답(질문 응답은 확인함)
- 알림 제목에 직원 이름이 보이는 설정이 켜져 있습니다(`NOTICE_SHOWS_STAFF_NAME`). 잠금 화면 노출을 줄이려면 끌 수 있으며 대표 결정이 필요합니다.
- 맥·윈도우 설치본을 실제로 PC에서 켜 보는 확인은 하지 않았습니다(빌드와 파일 검증만).
