# 릴리스 노트 — 데스크톱 0.8.1 (2026-10-23)

0.8.0의 휴대폰 연결 기능에서 **같은 와이파이에서 QR을 찍어도 연결되지 않던 문제**를 고친 패치입니다. 새 기능은 없습니다.

| 대상 | 버전 | 비고 |
|---|---|---|
| 데스크톱 (맥·윈도우, 같은 버전) | **0.8.1** | 0.8.0에서 올리는 업데이트 |
| 안드로이드 앱 | 업데이트 필요 | 임안드가 만드는 중. 버전은 앱 쪽에서 정함 |
| 원격 프로토콜 | **v1** (그대로) | QR에 선택 필드 `lan`만 추가(호환 유지) |

## 휴대폰 앱도 같이 업데이트해야 해요
- 이번 수정은 **PC와 휴대폰 앱이 함께** 바뀌어야 효과가 있습니다. PC만 0.8.1로 올리면 QR에 같은 와이파이 주소(`lan`)가 담기지만, 안드로이드 앱 1.0.0은 모르는 필드를 무시하므로 **여전히 이전처럼 외부 주소로만 연결을 시도합니다.**
- 새 앱으로 올리기 전에도 0.8.1 PC와 앱 1.0.0은 **서로 깨지지 않습니다**(프로토콜 v1 유지). 연결 방식만 예전과 같습니다.
- 새 앱이 나오면 앱을 올린 뒤 **QR을 한 번 다시 찍어 연결**하세요.

## 무엇이 고쳐졌나
- QR에 공유기 **외부 주소**만 들어 있었습니다. 같은 와이파이의 휴대폰이 그 주소로 접속하려 하면, 공유기가 안쪽에서 바깥 주소로 되돌아오는 연결(헤어핀 NAT)을 못 받는 경우(이중 공유기 포함) 연결이 되지 않았습니다.
- 이제 QR에 **같은 와이파이용 주소(`lan`)** 를 함께 담습니다. 새 앱은 같은 와이파이 주소로 먼저 짧게(약 2초) 붙어 보고, 안 되면 외부 주소로 연결합니다.
- 연결 안내 화면 QR 아래에 "같은 와이파이"와 "밖에서" 주소가 함께 보입니다.
- 외부 주소와 같은 와이파이 주소가 같으면 `lan`은 넣지 않습니다.

## 그대로인 것 (0.8.0 노트의 꼭 알아 둘 것)
- 원격 기능은 **기본으로 꺼져** 있습니다. 켤 때만 포트가 열리고, 끄면 바로 닫힙니다.
- 포트를 열 때는 보안에 주의하세요. QR에는 접속 열쇠(토큰)가 들어 있으니 사진으로 남기지 마세요.
- 인증서 고정: PC의 원격 키가 바뀌면 QR을 다시 만들어 다시 연결해야 합니다.
- 알림은 15분쯤마다 확인하는 방식이라 수십 분 늦을 수 있습니다.
- 휴대폰의 결재·지시는 PC에서 직접 하는 것과 같은 힘이 있습니다. 잃어버리면 "QR 다시 만들기".
- 자세한 내용: `docs/release-notes/0.8.0.md`, `docs/specs/remote-protocol-v1.md`(8절 QR 형식).
