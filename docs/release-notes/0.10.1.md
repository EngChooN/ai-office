# 릴리스 노트 — 대화 새로 넘기기·급여 명세서 개편 (2026-10-24)

이번 릴리스부터 **휴대폰 앱 번호가 PC와 같아집니다**(폰 0.10.1 ↔ PC 0.10.1). 프로토콜은 따로 표기합니다. 서로 짝이 맞는 것끼리만 같이 쓰세요.

| 대상 | 버전 | 파일 |
|---|---|---|
| 데스크톱 (맥·윈도우, 같은 버전) | **0.10.1** | 맥 dmg·zip, 윈도우 zip |
| 안드로이드 앱 | **0.10.1** (`versionCode` 9) — 이제 PC와 같은 번호 | 서명된 APK (이전 앱과 같은 키, 업데이트로 설치) |
| 원격 프로토콜 | **v2** (v1도 그대로, 이번에 바뀐 것 없음) | `docs/specs/remote-protocol-v2.md` |

**버전을 0.10.1(패치)로 정한 이유:** 대표님 결정입니다. 이 묶음은 처음 0.11.0으로 준비했다가 0.10.1로 바꿨고, **0.11.0이라는 번호는 배포하지 않았습니다.** 앱이 정하던 토큰 한도와 월 예산을 없앤 변경이 들어 있으니 아래 "바뀐 것"을 꼭 읽으세요.

**호환 표**
| 데스크톱 | 안드로이드 | 보이는 것 |
|---|---|---|
| 0.10.1 | 0.10.1 | 최신 PC 화면 그대로(급여 명세서 개편·직원 패널 포함) |
| 0.10.1 | 1.1.x(예전 번호) | 연결은 되지만 폰 화면이 예전 모양일 수 있습니다(급여 명세서 등) |
| 0.10.0 | 0.10.1 | 연결은 되지만 급여 명세서 등 새 화면이 PC와 맞지 않을 수 있습니다(PC를 올리면 해결) |

## 설치 순서
1. **PC 0.10.1을 먼저** 설치합니다(맥은 앱을 종료한 뒤 교체, 윈도우는 zip을 풀어 실행).
2. **그다음 폰 0.10.1**을 업데이트로 설치합니다(기존 1.1.x 앱 위에 그대로).
3. 휴대폰 연결을 켜 둔 상태라면 폰을 새로 연결할 필요는 없습니다. 연결이 안 되면 설정 › 휴대폰 연결에서 QR을 다시 만들어 다시 찍으세요.

## 바뀐 것
**대화가 길어지면 새 대화로 넘겨서 토큰과 속도를 아껴요**
- 지금까지는 직원이 같은 대화를 계속 이어 가서, 도구를 한 번 쓸 때마다 그동안의 대화 전체(많게는 수십만 토큰)를 다시 보내고 있었습니다.
- 이제 대화가 길어지면(약 15만 토큰을 넘으면) **다음 지시부터 새 대화로 시작**하고, 직전 보고만 넘겨 이어 갑니다. 이전 대화는 지워지지 않습니다.
- 직원이 일하는 도중에 말을 거는 끼어들기는 대화를 바꾸지 않습니다. 앱을 켠 뒤 첫 지시는 이전 대화 파일의 끝부분을 읽어 판단합니다.

**이 변경의 영향 (두 가지)**
1. **직원이 예전 대화의 세세한 내용은 기억하지 못할 수 있어요.** 새 대화에는 직전 보고(최대 4000자)와 새 지시만 넘어갑니다. 예전에 나눈 자세한 설명이나 결정이 필요하면 지시에 다시 적어 주세요. 업무 카드·기획서·참고 문서에 남아 있는 내용은 그대로 읽을 수 있습니다.
2. **"터미널에서 이어 하기"는 새 대화로 열려요.** 대화가 한 번 넘겨진 직원은 터미널에서도 넘겨진 뒤의 새 대화가 이어집니다. 이전 대화는 지워지지 않았지만, 이 버튼으로는 열리지 않습니다.

**급여 명세서를 실제 사용량 중심으로 바꿨어요**
- 위에는 Claude 플랜 사용률(5시간·7일)이, 아래에는 직원마다 오늘·이번 주·달별로 쓴 토큰과 비중이 나옵니다. 표 칸 간격도 넓혔습니다.
- **앱이 따로 정하던 토큰 한도(일·주·월)와 월 예산($), 직원별 월 예산은 없앴어요.** 실제 한도는 Claude 플랜이 정하기 때문입니다.
  - **예산을 넘으면 새 지시를 거절하던 동작도 함께 없어졌습니다.** 이제 앱은 토큰을 이유로 지시를 막지 않습니다.
  - 대신 **플랜 사용률이 80%·100%에 닿으면 알림**을 보냅니다. 알림을 놓치지 마세요.
  - 장비 탭의 월 예산 입력칸이 사라졌습니다. 이전에 저장한 값은 쓰이지 않습니다.
- 상단 바의 "이번 달 $"가 **플랜 사용률**로 바뀌었습니다.
- 상점에서 쓰는 회사 자금(₩)은 그대로입니다.

**대시보드 직원 카드가 상태를 한눈에 보여 줘요**
- 카드 테두리와 바탕이 상태색을 띱니다(작업 중·확인 필요 등). 카드의 미니 화면은 칸이 넓어져도 직원을 키우지 않고 칸 비율대로 넓게 그립니다.

**직원 패널이 넓어졌어요**
- 직원이 움직이는 모습을 패널 위쪽 이름 옆의 작은 칸으로 옮겨서, 업무·변경·장비·프로필 내용이 위아래로 더 많이 보입니다. 업무 모드에서는 정지 그림으로 보입니다.

**휴대폰 앱 0.10.1**
- 최신 PC 화면(위 변경)을 그대로 담았습니다.
- **휴대폰 앱 아이콘이 PC와 같아졌어요**(픽셀아트 사무실 직원).
- **번호가 1.1.3에서 0.10.1으로 바뀌었지만, 업데이트로 그대로 설치됩니다.** 내부 번호(`versionCode`)는 7에서 9로 올라 기존 앱 위에 덮어 설치되고, 서명 키도 같습니다. 정식 출시 전이라 폰 앱도 PC와 같은 0.x 번호를 쓰기로 했습니다.

## 보안 주의 (이전과 같음, 다시 확인하세요)
- **휴대폰은 PC 전체를 조작할 수 있습니다**(직원 고용·퇴사, 설정, 결재 승인, 지시, 자동결재 켜고 끄기까지). QR을 찍은 휴대폰이 곧 PC 조작 권한입니다.
- **QR을 남에게 보이지 마세요.** 사진으로 남기지 마세요. 휴대폰에 화면 잠금을 걸어 두세요. 잃어버리면 바로 설정 › 휴대폰 연결 › "QR 다시 만들기".
- 휴대폰 연결을 켜 둔 채 앱을 끄면 다음에 켤 때 포트가 자동으로 다시 열립니다. 쓰지 않을 때는 꺼 두세요.
- 자동결재는 모든 변형을 막지는 못합니다. 되돌리기 어려운 프로젝트에서는 켜지 말고, 켜더라도 짧게 시작하세요(자세한 범위는 `docs/release-notes/0.10.0.md`).

## 확인한 것과 아직 확인하지 못한 것
**확인한 것**
- 리드가 개발 창으로 화면을 확인했고, PC `tsc`·테스트 229개가 통과했습니다.
- 빌드: dmg 체크섬 유효(안의 앱 버전 0.10.1), 윈도우 zip 실행 파일 확인, 화면(`dist-mobile`)을 다시 빌드한 뒤 APK를 같은 키로 서명해 검증(v2 서명, 서명자 1명, `versionCode` 8·`versionName` 0.10.1, 아이콘 교체 후 재빌드, APK 22,425,045바이트), 앱 단위 테스트 59개 통과, **APK 안 화면 파일(`assets/web/`, 3개)이 `dist-mobile`과 파일 해시로 같음**을 확인했습니다.

**아직 확인하지 못한 것**
- **대표님 지시로 QA를 생략했습니다.** 오큐에이의 확인과 한리뷰의 리뷰를 거치지 않았습니다. 특히 대화 새로 넘기기(긴 대화에서 새 대화로 넘어간 뒤 직원 동작)와 알림(플랜 사용률 80%·100%)은 실제 사용에서 확인이 필요합니다.
- 맥·윈도우 설치본을 PC에서 켜 보는 확인(빌드와 파일 검증까지만 함)
- 실기기: 폰·폴드·태블릿에서 급여 명세서와 직원 패널 화면
