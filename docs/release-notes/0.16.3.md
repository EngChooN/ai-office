# AI Office 0.16.3 (2026-10-31)

## 한국어

### 새 기능
- 대화방에서 지시를 보내면 답이 올 때까지 직원별 상태 줄(대기·작업 중·확인 필요·오류, 대기 N건)이 지시한 방과 직원 패널의 업무 탭에 보여요.
- 대화방에서 @ 뒤에 나오는 후보를 키보드로 고를 수 있어요. ↑↓로 옮기고 Enter나 Tab으로 고르고 Esc로 닫아요.

### 개선
- @ 후보를 고르면 입력창에 커서가 그대로 남아, 바로 이어서 칠 수 있어요.
- 상태 줄이 좁은 화면에서도 넘치지 않고, 긴 이름과 상태는 줄여서 보여요.

### 버그 수정
- 직원이 일하다 오류가 나면 대화방에 알리고, 남은 지시는 정리해요. 쉬는 중에 연결이 끊긴 것은 알리지 않아요.

- 알려 드려요: 윈도우 zip 파일은 계속 올리지 않아요. 옛 zip 앱을 쓰던 분은 Release 페이지에서 Setup.exe를 직접 받아 설치한 뒤 옛 폴더를 지우면 돼요. 설정과 기록은 그대로 이어져요.
- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English

### New features
- When you send an instruction in a chat room, a per-staff status line (waiting / working / needs your check / error, N waiting) now shows in that room and in the Tasks tab of the staff panel until the reply arrives.
- You can pick @ suggestions in the chat room with the keyboard: ↑↓ to move, Enter or Tab to select, Esc to close.

### Improvements
- After you pick an @ suggestion, the cursor stays in the input box so you can keep typing right away.
- The status line no longer overflows on narrow screens, and long names and statuses are shortened.

### Bug fixes
- If a staff member hits an error while working, the chat room is told and the remaining instructions are cleared. A connection that drops while the staff member is idle is not reported.

- Please note: the Windows zip file is still not published. If you used the old zip app, download Setup.exe from the Release page, install it, and then delete the old folder. Your settings and history carry over.
- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語

### 新機能
- チャットルームで指示を送ると、返事が届くまで社員ごとの状態行（待機・作業中・要確認・エラー、待ち N 件）が、指示したルームと社員パネルの業務タブに表示されます。
- チャットルームの @ 候補をキーボードで選べます。↑↓で移動、Enter または Tab で選択、Esc で閉じます。

### 改善
- @ 候補を選んだ後も入力欄にカーソルが残るので、そのまま続けて入力できます。
- 状態行が狭い画面でもあふれず、長い名前や状態は短く表示されます。

### バグ修正
- 社員が作業中にエラーになると、チャットルームに知らせ、残りの指示を整理します。待機中に接続が切れた場合は知らせません。

- お知らせ：Windows の zip ファイルは引き続き公開しません。古い zip 版アプリを使っていた方は、Release ページから Setup.exe を直接ダウンロードしてインストールし、古いフォルダーを削除してください。設定と履歴はそのまま引き継がれます。
- お知らせ：Windows のインストーラーには署名がないため、初めて開くときに警告画面（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。

## 中文

### 新功能
- 在聊天室发出指令后，在收到回复之前，每位员工的状态行（等待、工作中、需确认、错误，等待 N 条）会显示在发出指令的聊天室和员工面板的任务标签页中。
- 聊天室里的 @ 候选可以用键盘选择：↑↓ 移动，Enter 或 Tab 选中，Esc 关闭。

### 改进
- 选中 @ 候选后，光标仍留在输入框中，可以直接接着输入。
- 状态行在窄屏幕上不会溢出，过长的名字和状态会被缩短显示。

### 问题修复
- 员工工作中出错时，会在聊天室告知，并清理剩余的指令。员工空闲时连接中断不会提示。

- 请注意：仍然不发布 Windows zip 文件。使用旧 zip 版应用的用户，请到 Release 页面直接下载 Setup.exe 安装，然后删除旧文件夹。设置和记录会保留。
- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
