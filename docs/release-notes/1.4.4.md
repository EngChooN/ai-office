# AI Office 1.4.4 (2026-11-18)

## 한국어
알아 둘 점: 윈도우 화면 캡처·컴퓨터 조작·앱 밖 직원 알림 지원은 윈도우 실기기 확인 전이에요. 문제가 있으면 이슈로 알려 주세요.

### 한눈에 보기
- **새 기능** 윈도우에서도 화면 캡처가 돼요
- **새 기능** 윈도우에서도 컴퓨터 조작이 돼요
- **새 기능** 윈도우에서 앱 밖 직원 알림이 와요

### 새 기능
- 윈도우에서도 직원이 화면을 캡처해 보고에 붙일 수 있어요. 이제 맥 전용이 아니에요.
- 윈도우에서도 직원이 마우스 클릭·키 입력·스크린샷으로 컴퓨터를 조작할 수 있어요. 스크린샷만 결재 없이 찍고, 클릭·입력·이동은 결재를 받아요.
- 윈도우에서도 앱 밖(터미널 등)에서 일하는 직원의 진행 알림과 질문을 사무실에서 받을 수 있어요.

## English
Good to know: Windows screen capture, computer control and notifications for staff working outside the app have not been verified on a real Windows PC yet. If something goes wrong, please let us know as an issue.

### At a glance
- **New** Screen capture now works on Windows
- **New** Computer control now works on Windows
- **New** Windows gets outside-staff notifications

### New features
- Staff can now capture the screen and attach it to their report on Windows too. It is no longer Mac only.
- Staff can now control the computer on Windows too, with mouse clicks, key presses and screenshots. Screenshots need no approval; clicking, typing and moving do.
- On Windows you can now receive progress notifications and questions from staff working outside the app (for example in a terminal).

## 日本語
ご注意：Windows の画面キャプチャ・コンピューター操作・アプリ外スタッフの通知は、Windows 実機での確認がまだです。問題があれば issue でお知らせください。

### ひと目で
- **新機能** Windows でも画面キャプチャができます
- **新機能** Windows でもコンピューター操作ができます
- **新機能** Windows でアプリ外スタッフの通知が届きます

### 新機能
- Windows でも、スタッフが画面をキャプチャして報告に添付できます。Mac 専用ではなくなりました。
- Windows でも、スタッフがマウスのクリック・キー入力・スクリーンショットでコンピューターを操作できます。スクリーンショットは決裁不要、クリック・入力・移動は決裁が必要です。
- Windows でも、アプリの外（ターミナルなど）で働くスタッフの進行通知と質問をオフィスで受け取れます。

## 中文

### 一览

### 新功能
- 在 Windows 上，员工也可以截取屏幕并附在报告中，不再仅限 Mac。
- 在 Windows 上，员工也可以通过鼠标点击、键盘输入和截图操作电脑。截图无需审批，点击、输入、移动需要审批。
- 在 Windows 上，也能在办公室收到在应用外（如终端）工作的员工的进度通知和提问。
