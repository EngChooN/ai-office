# AI Office 0.14.2 (2026-10-28)

## 한국어

### 새 기능
- 비서에게 GPT 직원을 뽑아 달라고 할 수 있어요. 고용 카드에서 Claude나 GPT 중 엔진을 고르고, 모델이 엔진과 맞는지 바로 확인해요.
- GPT 직원의 '터미널에서 이어 하기'가 컴퓨터에 설치된 Codex 도구로 열려요. Codex가 없으면 설치 안내가 떠요.

### 개선
- GPT 직원도 Claude 직원과 같은 도구 제한을 받아요. 웹 검색은 막히고, 위험한 명령은 실행되지 않아요. 셸 명령은 실행 전에 결재함에 물어봐요.
- 외부 세션 영입, 휴대폰 고용, 내보내기·가져오기에서 직원의 엔진(Claude/GPT)이 그대로 유지돼요.
- 요금제 한도에 걸렸을 때 멈춤과 알림을 엔진별로 따로 처리해요.
- Codex 외부 세션에서도 '오늘 한 일'을 볼 수 있어요. 장비 목록은 새로고침할 수 있어요.
- Codex만 쓰는 경우 문구·온보딩·사용량 카드가 엔진 상관없이 같은 방식으로 나와요. Codex만 쓰면 빈 Claude 칸은 숨겨져요.

### 버그 수정
- 사용량의 남은 시간이 '1시간 60분'처럼 잘못 나오던 문제를 고쳤어요.
- 엔진과 모델이 어긋난 직원은 켤 때 자동으로 바로잡아요.

## English

### New features
- You can ask the secretary to hire GPT staff. On the hiring card, choose Claude or GPT as the AI engine, and the app checks right away that the model matches the engine.
- "Continue in terminal" for GPT staff now opens with the Codex tool installed on your computer. If Codex is not installed, the app shows install instructions.

### Improvements
- GPT staff follow the same tool limits as Claude staff. Web search is blocked, dangerous commands do not run, and shell commands ask for approval in the approval inbox before they run.
- Bringing in outside sessions, hiring from the phone, and export/import keep each staff member's engine (Claude or GPT).
- When a plan limit is reached, the pause and the notice are handled separately for each engine.
- Codex outside sessions now show "What I did today." The equipment list can be refreshed.
- If you use only Codex, the wording, onboarding and usage card are shown the same way regardless of engine. Empty Claude sections are hidden when you use only Codex.

### Bug fixes
- Fixed the remaining time in usage showing wrongly as "1 hour 60 minutes."
- Staff whose engine and model did not match are now corrected automatically when they are turned on.

## 日本語

### 新機能
- 秘書にGPT社員の採用を頼めるようになりました。採用カードでClaudeかGPTのどちらのAIにするかを選ぶと、モデルがそのAIに合っているかすぐ確認されます。
- GPT社員の「ターミナルで続ける」が、パソコンにインストールされたCodexツールで開くようになりました。Codexがない場合はインストールの案内が表示されます。

### 改善
- GPT社員もClaude社員と同じツールの制限を受けます。Web検索はできず、危険なコマンドは実行されません。シェルのコマンドは実行前に承認箱で確認を求めます。
- 外部セッションの招へい、スマートフォンからの採用、書き出し・読み込みで、社員のAI（ClaudeまたはGPT）がそのまま保たれます。
- 料金プランの上限に達したときの停止と通知を、AIごとに別々に処理します。
- Codexの外部セッションでも「今日やったこと」を見られます。機材の一覧を更新できるようになりました。
- Codexだけを使っている場合、文言・初期設定・利用量カードがAIに関係なく同じ形で表示されます。Codexだけを使う場合、空のClaudeの欄は非表示になります。

### バグ修正
- 利用量の残り時間が「1時間60分」と誤って表示される問題を直しました。
- AIとモデルが合っていない社員は、オンにするときに自動で直すようになりました。

## 中文

### 新功能
- 可以请秘书招聘 GPT 员工。在招聘卡片上选择 Claude 或 GPT 作为引擎，应用会立即检查模型是否与引擎匹配。
- GPT 员工的“在终端中继续”现在会用电脑上已安装的 Codex 工具打开。如果没有安装 Codex，会显示安装说明。

### 改进
- GPT 员工与 Claude 员工受到相同的工具限制。网页搜索被禁止，危险命令不会执行，Shell 命令在执行前会在审批箱中请求确认。
- 从外部会话邀请、从手机招聘、导出和导入时，员工的引擎（Claude 或 GPT）都会保持不变。
- 达到套餐上限时，暂停和提醒按引擎分别处理。
- Codex 外部会话也能查看“今天做了什么”。设备列表可以刷新。
- 只使用 Codex 时，文案、新手引导和用量卡片不分引擎，统一显示。只使用 Codex 时，空白的 Claude 栏会被隐藏。

### 问题修复
- 修复了用量中的剩余时间错误显示为“1小时60分钟”的问题。
- 引擎与模型不匹配的员工，开启时会自动纠正。
