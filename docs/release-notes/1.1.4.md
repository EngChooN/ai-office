# AI Office 1.1.4 (2026-11-09)

## 한국어
### 개선
- 직원 업무 패널에서 날짜가 바뀌어도 이전 대화가 사라지지 않아요. 날짜와 상관없이 최근 기록부터 보여 주고, 위로 끝까지 올리면 이전 기록을 더 불러와요. 날짜가 바뀌는 곳에는 '11월 6일 (금)'처럼 날짜 구분선이 들어가고, 더 없으면 '처음 기록이에요'라고 알려 줘요. 위쪽 사용량은 지금처럼 오늘 것만 보여요.
- 기록이 아주 많아도 업무 패널 스크롤이 부드럽도록 화면 밖 기록은 그리지 않게 했어요. 다른 PC 직원과 앱 밖에서 실행 중인 직원도 같은 방식으로 이전 기록을 볼 수 있어요.
- 앱을 다시 켠 뒤 결재함에 되살아난 결재를 승인하면, 그 일을 다시 할 때만 같은 결재를 한 번 건너뛰어요. 이제 그 일이 끝나면 건너뛰기도 바로 사라져서, 같은 직원이 다른 일에서 같은 작업을 하면 다시 결재를 받아요.
- 기기별 차이: 모두 PC 앱의 변화예요. 휴대폰 앱은 코드 변경 없이 같은 번호로 맞췄고, 화면은 PC가 보내 주는 새 화면을 써요.

### 버그 수정
- 사이드바 '후원하기' 버튼과 소개 사이트의 후원 링크가 AI Office 후원 페이지가 아닌 다른 페이지로 열리던 문제를 고쳤어요.
- 오래돼서 다시 띄우지 않은 결재 기록이 영어·일본어·중국어 화면에서도 한국어로 나오던 문제를 고쳤어요.
- 대화방 입력칸 위의 대기 메시지가 한 장뿐인데도 상자 안에 스크롤이 생기던 문제를 고쳤어요.
- 긴 메시지에 답장하면 내가 보낸 말풍선이 화면 왼쪽으로 넘쳐 잘리고 내가 쓴 글이 안 보이던 문제를 고쳤어요. 인용 줄은 말풍선 폭에 맞춰 줄여 보여요.

## English
### Improvements
- Earlier conversations no longer disappear from a staff member's work panel when the date changes. The panel shows the most recent records regardless of date, and scrolling all the way up loads earlier ones. A date divider like 'Fri, November 6' marks each new day, and 'This is the first record' appears when there is nothing older. The usage line at the top still shows today only.
- The work panel stays smooth even with a very long history, because records outside the screen are not drawn. Staff on another PC and staff running outside the app show earlier records the same way.
- When you approve an approval that was restored after restarting the app, the same approval is skipped once while that work is redone. That skip now ends as soon as the work finishes, so the same action in other work by that staff member asks for approval again.
- Device differences: all changes are in the PC app. The phone app keeps the same version number with no code changes and uses the new screens sent by the PC.

### Bug fixes
- Fixed the sidebar 'Support us' button and the website's support link opening a different page instead of the AI Office support page.
- Fixed log entries for old approvals that were not restored showing in Korean on English, Japanese, and Chinese screens.
- Fixed a scroll bar appearing in the queued message box above the chat input even when there was only one message.
- Fixed your chat bubble overflowing off the left edge (hiding what you wrote) when replying to a long message. The quoted line is now shortened to fit the bubble.

## 日本語
### 改善
- 日付が変わってもスタッフの業務パネルから以前の会話が消えなくなりました。日付に関係なく最近の記録から表示し、いちばん上までスクロールするとさらに以前の記録を読み込みます。日付が変わる所には「11月6日(金)」のような日付の区切り線が入り、それより前がないときは「最初の記録です」と表示します。上部の使用量はこれまでどおり今日の分だけです。
- 記録がとても多くても業務パネルのスクロールが滑らかになるよう、画面外の記録は描かないようにしました。別のPCのスタッフやアプリの外で動いているスタッフも、同じように以前の記録を見られます。
- アプリを再起動して決裁箱に復元された決裁を承認すると、その作業をやり直すときだけ同じ決裁を一度スキップします。今後はその作業が終わるとスキップもすぐ消え、同じスタッフが別の作業で同じ操作をすると再び決裁を求めます。
- 端末ごとの違い：すべて PC アプリの変更です。スマホアプリはコードを変えずに同じ番号に合わせ、画面は PC から送られる新しい画面を使います。

### バグ修正
- サイドバーの「支援する」ボタンと紹介サイトの支援リンクが、AI Office の支援ページではなく別のページを開いていた問題を直しました。
- 古くなって復元しなかった決裁の記録が、英語・日本語・中国語の画面でも韓国語で表示されていた問題を直しました。
- 会話ルームの入力欄の上にある待機メッセージが1件だけでも、枠内にスクロールバーが出ていた問題を直しました。
- 長いメッセージに返信すると、自分の吹き出しが画面の左にはみ出して切れ、書いた文が見えなくなる問題を直しました。引用行は吹き出しの幅に合わせて省略表示されます。

## 中文
### 改进
- 日期变化后，员工工作面板里之前的对话不会再消失。面板不论日期都会从最近的记录开始显示，滚动到最上面会继续加载更早的记录。日期变化处会显示「11月6日周五」这样的日期分隔线，没有更早的记录时会提示「这是第一条记录」。顶部的用量仍然只显示今天的。
- 即使记录很多，工作面板也能流畅滚动，因为屏幕外的记录不会被绘制。其他电脑上的员工和在应用外运行的员工，也能用同样的方式查看更早的记录。
- 重启应用后在审批箱中恢复的审批被批准时，只会在重做该工作时跳过一次相同审批。现在该工作一结束，跳过就会立即失效，同一员工在其他工作中执行相同操作时会再次请求审批。
- 设备差异：所有变化都在电脑应用中。手机应用没有代码变化，只同步了版本号，界面使用电脑发送的新界面。

### 问题修复
- 修复了侧边栏“赞助支持”按钮和介绍网站的赞助链接打开的不是 AI Office 赞助页面的问题。
- 修复了因过旧而未恢复的审批记录在英文、日文、中文界面中仍显示为韩文的问题。
- 修复了聊天室输入框上方的待发消息即使只有一条也会出现滚动条的问题。
- 修复了回复长消息时，自己发送的气泡超出屏幕左侧被截断、看不到所写内容的问题。引用行会按气泡宽度缩略显示。
