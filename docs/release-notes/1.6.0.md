# AI Office 1.6.0 (2026-11-23)

## 한국어
### 한눈에 보기
- **새 기능** 휴대폰에서 결과물 미리보기·내려받기
- **새 기능** 코드 블록에 복사 버튼, 붙여넣은 코드 자동 정리
- **개선** 직원 업무 기록에서 내 지시 줄을 구분해 표시
- **개선** Claude 로그인 안 됨을 쉬운 안내로
- **수정** 방에서 코드만 보낸 지시가 깨지던 문제

휴대폰 결과물 미리보기는 실제 휴대폰과 윈도우 PC에서의 확인을 아직 하지 못했어요.

### 새 기능
- 휴대폰에서도 다른 PC의 결과물을 앱 안에서 미리 보고 내려받을 수 있어요. 전에는 "PC에서 열어 주세요"라고만 나왔어요.
- 대화 속 코드 블록 오른쪽 위의 버튼으로 코드를 바로 복사할 수 있어요.
- 입력칸에 여러 줄 코드를 붙여넣으면 코드 블록으로 자동 감싸 줘요. 실행 취소(⌘Z·Ctrl+Z) 한 번이면 원래대로 돌아와요.

### 개선
- 직원 업무 기록에서 내가 내린 지시 줄을 보고와 다른 배경색으로 구분해 보여 줘요.
- Claude에 로그인이 안 돼 답하지 못할 때 영어 오류 대신 해결 방법을 한국어·영어·일본어·중국어로 안내해요.

### 버그 수정
- 단체방에서 코드만 보낸 지시가 업무 기록에서 깨져 보이던 문제를 고쳤어요.

## English
### At a glance
- **New** Preview and download results on your phone
- **New** Copy button on code blocks; pasted code auto-formatted
- **Better** Your instructions stand out in the staff work log
- **Better** Clear guidance when Claude isn't signed in
- **Fixed** Instructions with only code broke in group chats

Phone result preview has not yet been checked on a real phone or a Windows PC.

### New features
- On your phone you can now preview and download results from another PC inside the app. Before, it only said "Open it on the PC".
- Code blocks in chats have a button at the top right to copy the code in one tap.
- Pasting several lines of code into the input box wraps it in a code block automatically. One undo (⌘Z / Ctrl+Z) restores the original text.

### Improvements
- In the staff work log, the instructions you gave are shown with a different background from reports.
- When Claude can't answer because you aren't signed in, you now get steps to fix it in Korean, English, Japanese and Chinese instead of an English error.

### Bug fixes
- Fixed instructions containing only code looking broken in the work log after being sent from a group chat.

## 日本語
### ひと目で
- **新機能** スマホで成果物のプレビューとダウンロード
- **新機能** コードブロックにコピーボタン、貼り付けコードを自動整形
- **改善** スタッフの業務記録で自分の指示行を区別表示
- **改善** Claudeにログインしていない時の案内を分かりやすく
- **修正** グループでコードだけ送った指示が崩れる問題

スマホでの成果物プレビューは、実機のスマホとWindows PCでの確認がまだできていません。

### 新機能
- スマホでも、ほかのPCの成果物をアプリ内でプレビューしてダウンロードできます。以前は「PCで開いてください」と表示されるだけでした。
- チャット内のコードブロック右上のボタンで、コードをすぐにコピーできます。
- 入力欄に複数行のコードを貼り付けると、自動でコードブロックで囲みます。元に戻す(⌘Z・Ctrl+Z)を1回押すと元の文章に戻ります。

### 改善
- スタッフの業務記録で、自分が出した指示の行をレポートと違う背景色で区別して表示します。
- Claudeにログインしていないため答えられない時、英語のエラーの代わりに解決方法を日本語・英語・韓国語・中国語で案内します。

### バグ修正
- グループチャットでコードだけを送った指示が、業務記録で崩れて表示される問題を修正しました。

## 中文
### 一览
- **新功能** 手机上可预览和下载成果物
- **新功能** 代码块新增复制按钮,粘贴的代码自动整理
- **改进** 员工工作记录中区分显示我的指示行
- **改进** Claude 未登录时给出易懂的提示
- **修复** 在群聊中只发送代码的指示显示错乱

手机上的成果物预览尚未在真实手机和 Windows 电脑上确认。

### 新功能
- 在手机上也可以在应用内预览并下载其他电脑的成果物。以前只显示“请在电脑上打开”。
- 对话中代码块右上角的按钮可以一键复制代码。
- 在输入框粘贴多行代码时会自动用代码块包裹。按一次撤销(⌘Z·Ctrl+Z)即可恢复原文。

### 改进
- 在员工工作记录中,我下达的指示行用与报告不同的背景色区分显示。
- 因 Claude 未登录而无法回答时,不再显示英文错误,而是用韩语、英语、日语、中文给出解决方法。

### 问题修复
- 修复了在群聊中只发送代码的指示在工作记录中显示错乱的问题。
