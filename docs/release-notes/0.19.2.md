# AI Office 0.19.2 (2026-11-02)

## 한국어

### 개선
- 직원 대화창 아래에 '대화 기억'을 고를 수 있어요(짧게·보통·길게·최대). 길게나 최대를 고르면 새 대화로 덜 넘어가서 앞 이야기를 이어 말할 수 있어요. 대신 비용이 늘어요. 마우스를 올리면 각각 무슨 뜻인지 설명이 나와요.

- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English

### Improvements
- You can now pick 'Memory' under each staff chat (Short, Normal, Long, Max). Long or Max moves to a new conversation less often, so you can keep talking about earlier things, at a higher cost. Hover to see what each option means.

- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語

### 改善
- 社員の会話欄の下で「会話の記憶」を選べます(短め・普通・長め・最大)。長めや最大にすると新しい会話に移りにくくなり、前の話を続けられます。そのぶん費用は増えます。マウスを乗せると、それぞれの意味が表示されます。

- お知らせ：Windows のインストーラーには署名がないため、初めて開くときに警告画面（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。

## 中文

### 改进
- 员工对话框下方可以选择“对话记忆”(短、普通、长、最大)。选长或最大时较少转到新对话，可以接着之前的话题聊，但费用会增加。把鼠标移上去会显示每个选项的含义。

- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
