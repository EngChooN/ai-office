# AI Office 1.0.0 (2026-11-03)

## 한국어

### 새 기능
- 피드백 보내기를 누를 때 최근에 생긴 오류가 있으면 오류 기록을 함께 보낼지 물어요. 보낼 내용을 미리 볼 수 있고, 체크를 끄면 빼고 보내요. 홈 폴더 위치·이름·이메일·비밀번호 같은 값은 가려서 넣고, 기록이 길면 일부만 넣은 뒤 전체 기록을 복사해 둬요. 휴대폰에서는 보내지 않아요.
- 결재함의 결재·질문이 저장돼요. 앱을 껐다 켜도 7일 안의 것은 '이어 가기' 카드로 다시 나타나고, 승인·반려·답을 보내면 그 직원에게 새 지시로 이어져요. 승인한 결재는 같은 도구·내용에 한 번만 자동 허용돼요.
- GPT(Codex) 직원마다 '셸 네트워크 허용'을 켤 수 있어요(기본 꺼짐). 켜도 승인 방식과 파일을 고치는 범위는 그대로이고, 휴대폰에서는 바꿀 수 없어요.

### 개선
- 화면 문구를 쉬운 말로 다듬고 같은 뜻의 말을 하나로 맞췄어요. 'AI 엔진(Claude·GPT)', '팀장·랩장', 'AI 사용 비용'과 '회사 자금(게임 속 돈)', '매뉴얼 단계 진행'으로 부르고, 변경 탭·자동결재 안내의 프로그램 이름과 명령어는 '자세히' 안으로 접었어요.
- AI Office가 1.0.0 정식 버전이 됐어요. 설명 문서와 소개 페이지에서 베타·시험판 표기를 없앴고, 첫 화면 사무실 그림을 현재 화면으로 바꿨어요.

### 버그 수정
- GPT(Codex) 직원을 이어 하려는데 이 컴퓨터에 Codex가 없을 때, 안내 문구에 적힌 [설치 안내] 버튼이 보이지 않던 문제를 고쳤어요. 버튼을 누르면 설치 안내 페이지가 브라우저로 열려요.

- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요. 휴대폰 앱은 오류 기록 첨부를 보내지 않고, GPT 셸 네트워크 허용은 PC에서만 바꿀 수 있어요.

## English

### New features
- When you send feedback and errors happened recently, the app asks whether to include the error records. You can preview them and uncheck the box to leave them out. Home folder locations, names, emails, passwords and similar values are hidden, and if the records are long only part is included and the full records are copied for you to paste. Not sent from phones.
- Approvals and questions in the inbox are now saved. After you quit and reopen the app, those from the last 7 days come back as "Continue" cards, and approving, rejecting or answering sends them to that staff member as a new instruction. An approved item is auto-allowed once for the same tool and content.
- You can turn on "allow shell network" per GPT (Codex) staff member (off by default). The approval mode and the range of files they can edit stay the same, and it cannot be changed from a phone.

### Improvements
- On-screen wording is plainer, and words with the same meaning now match: "AI engine (Claude/GPT)", "team leader / lab head", "AI usage costs" vs. "company funds (in-game money)", and "manual steps". Program names and commands in the Changes tab and auto-approve notes are folded under "Details".
- AI Office is now the official 1.0.0 release. Beta and trial labels were removed from the README and intro page, and the office picture on the front page now shows the current screen.

### Bug fixes
- Fixed the [Install guide] button mentioned in the message not appearing when you try to continue a GPT (Codex) staff member on a computer without Codex. The button now opens the install guide in your browser.

- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway." The phone app does not send error records, and the GPT shell network setting can only be changed on the PC.

## 日本語

### 新機能
- フィードバックを送るとき、最近エラーが起きていればエラー記録も一緒に送るか確認します。送る内容を前もって見られ、チェックを外せば除いて送ります。ホームフォルダの場所・名前・メールアドレス・パスワードなどの値は隠して入れ、記録が長いときは一部だけ入れて全体の記録をコピーしておきます。スマホからは送りません。
- 決裁箱の決裁・質問が保存されます。アプリを終了して開き直しても、7日以内のものは「続ける」カードとして再び表示され、承認・差し戻し・返答を送るとそのスタッフへの新しい指示として続きます。承認した決裁は同じツール・内容に一度だけ自動で許可されます。
- GPT（Codex）スタッフごとに「シェルのネットワーク許可」をオンにできます（初期はオフ）。オンにしても承認方式とファイルを直せる範囲は変わらず、スマホからは変更できません。

### 改善
- 画面の言葉をやさしくし、同じ意味の言葉を一つにそろえました。「AIエンジン（Claude・GPT）」「チームリーダー・ラボ長」「AI利用コスト」と「会社資金（ゲーム内のお金）」「マニュアル段階進行」と呼び、変更タブ・自動決裁の案内にあるプログラム名やコマンドは「詳しく」の中にたたみました。
- AI Office が 1.0.0 の正式版になりました。READMEと紹介ページからベータ・試験版の表記を外し、最初の画面のオフィスの絵を現在の画面に差し替えました。

### バグ修正
- このコンピューターに Codex がない状態で GPT（Codex）スタッフを続けようとしたとき、案内文にある [インストール案内] ボタンが表示されなかった問題を直しました。ボタンを押すとインストール案内ページがブラウザで開きます。

- お知らせ: Windows のインストーラーには署名がないため、初めて開くときに警告ウィンドウ（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。スマホアプリはエラー記録を送らず、GPT のシェルネットワーク許可は PC でのみ変更できます。

## 中文

### 新功能
- 发送反馈时，如果最近出现过错误，会询问是否一起发送错误记录。可以先预览要发送的内容，取消勾选就不发送。主文件夹位置、名字、邮箱、密码等内容会被隐藏，记录太长时只放入一部分，并把完整记录复制好供你粘贴。手机上不会发送。
- 审批箱里的审批和提问现在会被保存。关闭并重新打开应用后，7天内的内容会以“继续”卡片重新出现，批准、驳回或回答会作为新指示发给该员工。已批准的审批会对相同工具和内容自动允许一次。
- 可以为每位 GPT（Codex）员工开启“允许 Shell 网络”（默认关闭）。开启后审批方式和可修改文件的范围不变，手机上无法更改。

### 改进
- 让界面用语更易懂，并统一了同义的说法：“AI 引擎（Claude·GPT）”“组长·实验室负责人”“AI 使用费用”与“公司资金（游戏内货币）”“手册步骤”。变更标签页和自动审批说明中的程序名和命令收进了“详细”里。
- AI Office 成为 1.0.0 正式版。README 和介绍页面中去掉了测试版、试用版标记，首页的办公室图片也换成了当前画面。

### 问题修复
- 修复了在没有安装 Codex 的电脑上继续 GPT（Codex）员工时，提示中提到的[安装指南]按钮不显示的问题。点击按钮会在浏览器中打开安装指南页面。

- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。手机应用不会发送错误记录，GPT 的 Shell 网络设置只能在电脑上更改。
