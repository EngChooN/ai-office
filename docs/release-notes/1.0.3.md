# AI Office 1.0.3 (2026-11-06)

## 한국어

### 새 기능
- 팀장·랩 리드가 일하는 중인 팀원에게 끼어들어 새 지시를 할 수 있어요. 하던 일을 잠깐 멈추고 새 지시를 먼저 한 뒤 이어서 하게 하거나, 하던 일을 그만두게 하고(받은 업무 카드는 할 일로) 새 지시만 하게 고를 수 있어요. 누가 누구의 일을 멈췄는지는 두 사람 기록에 남고, 결과는 지금처럼 팀장에게 보고돼요. 다른 PC 직원에게는 끼어들지 않고 하던 일이 끝난 뒤에 전해요.

### 개선
- 다른 PC 연결과 휴대폰 연결에 있던 5분 제한시간을 없앴어요. 연결 코드와 QR은 연결에 성공하거나, 대표님이 닫거나, 앱을 끄거나, 코드를 3번 틀릴 때까지 열려 있어요. 회사 컴과 집 컴처럼 멀리 떨어진 PC도 천천히 연결할 수 있어요.

- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English

### New features
- Team leaders and lab leads can now step in while a teammate is working and give a new instruction. They can pause the current work, deliver the new instruction first and then carry on, or have the teammate drop the current work (their task cards go back to To do) and do only the new instruction. Who stopped whose work is recorded for both people, and the result is reported back to the leader as before. Teammates on another PC are not interrupted; the instruction is delivered after their current work.

### Improvements
- The 5-minute time limit on connecting another PC or a phone is gone. The connection code and QR code stay open until a device connects, you close them, you quit the app, or the code is entered wrong 3 times. You can now take your time connecting PCs that are far apart, like a work PC and a home PC.

- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語

### 新機能
- チームリーダー・ラボリードが、作業中のメンバーに割り込んで新しい指示を出せるようになりました。今の作業をいったん止めて新しい指示を先にしてから続けさせるか、今の作業をやめさせて（受けた業務カードは未着手へ）新しい指示だけをさせるかを選べます。誰が誰の作業を止めたかは二人の記録に残り、結果はこれまでどおりリーダーに報告されます。別のPCのスタッフには割り込まず、今の作業が終わってから届きます。

### 改善
- 別のPCとの接続とスマホ接続にあった5分の制限時間をなくしました。接続コードとQRは、接続に成功するか、代表が閉じるか、アプリを終了するか、コードを3回間違えるまで開いたままです。会社のPCと自宅のPCのように離れたPCも、ゆっくり接続できます。

- お知らせ: Windows のインストーラーには署名がないため、初めて開くときに警告ウィンドウ（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。

## 中文

### 新功能
- 组长和实验室负责人现在可以在成员工作时插话下达新指示。可以选择让成员先暂停手头工作、优先处理新指示后再继续，或者让成员放弃手头工作（已接的任务卡退回待办），只做新指示。谁停下了谁的工作会记录在双方的记录中，结果仍像以前一样汇报给负责人。不会打断另一台电脑上的员工，指示会在其当前工作结束后送达。

### 改进
- 取消了连接其他电脑和连接手机时的 5 分钟时限。连接码和二维码会一直有效，直到连接成功、代表关闭、退出应用或验证码输错 3 次为止。即使是公司电脑和家里电脑这样相隔较远的电脑，也可以从容地完成连接。

- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
