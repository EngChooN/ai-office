# AI Office 1.1.2 (2026-11-08)

## 한국어
### 개선
- 예약 업무 목록에 '편집' 버튼이 생겼어요. 시간·요일·지시를 고치고 '변경 저장'을 누르면 같은 예약이 바뀌고, 마지막 실행 기록은 그대로 남아요. 목록에는 '다음 실행' 시각도 보여요.
- 결재를 기다리는 이유가 한 줄로 보여요. 예: '처음 보는 명령이라 기다려요', '삭제·푸시·외부 전송 같은 위험한 일이라 기다려요', '방금 고친 파일을 실행하려 해서 기다려요'.
- 결재 화면과 직원 프로필에 자동결재가 켜져 있는지, 이 직원의 결재 방식이 무엇인지 한 줄로 보여요. 꺼져 있으면 '켜기' 버튼으로 설정 화면에 갈 수 있어요.
- 사용량 카드에 '마지막 갱신 N분 전'이 보여요.
- 새로 고용하는 직원의 기본 결재 방식이 '수정은 자율'이 됐어요. 파일 수정은 묻지 않고, 삭제·푸시 같은 위험한 일은 계속 물어요. 휴대폰에서 고용하면 지금처럼 '모두 묻기'예요.
- 자동결재·자율 진행이 불필요하게 자주 묻던 것을 줄였어요. 직원이 방금 고친 파일을 실제로 실행할 때만 기다려요. 이름이 비슷한 파일을 다루거나, 설정 파일을 고친 뒤 시험·확인 명령을 돌리는 정도로는 더 이상 막히지 않아요.
- 반대로 우회는 더 단단히 막았어요. 파일을 고친 뒤 그 파일을 직접·간접으로 실행하거나, 명령으로 파일을 쓰고 바로 돌리거나, 다른 폴더로 옮겨 실행하는 경우는 그대로 기다려요. 고친 파일 기록은 작업 폴더별로 남기고, 바로가기 폴더로 접근해도 같은 폴더로 봐요.
- 자율 진행 중 거부된 일은 다른 방법으로 우회하거나 다시 시도하지 않고 '대표 확인 필요' 목록에 남기도록 안내해요.
- 윈도우 경로와 실행 방식도 같은 규칙으로 판정해요.
- GPT(Codex) 구성 요소가 앱에 없으면 '앱을 최신 버전으로 업데이트해 주세요'라고 알려 줘요. 연결 실행에 실패했거나 확인하지 못했을 때는 카드 안에 '다시 확인' 버튼이 나와요.
- 기기별 차이: 맥만 Codex 구성 요소가 빠져 있었어요. 윈도우는 해당 없어요. 휴대폰 앱은 코드 변경 없이 같은 번호로 맞췄고, 화면은 PC가 보내 주는 새 화면을 써요.
- 알려 드려요: **맥 1.1.0·1.1.1을 쓰고 있다면 1.1.2로 업데이트해 주세요.** 그 두 버전의 맥 설치본에는 GPT(Codex)가 빠져 있어서 GPT 직원이 연결되지 않았어요.
- 알려 드려요: 사용량은 실시간이 아니에요. 직원이 일할 때와 새로고침 버튼을 눌렀을 때만 갱신되고, 카드에 마지막 갱신 시각이 보여요.
- 알려 드려요: 자동결재는 안전을 위해 여전히 보수적이라, 처음 보는 명령이나 직접 만든 스크립트 실행은 계속 물어봐요.

### 버그 수정
- 맥 1.1.0·1.1.1 설치본에서 GPT(Codex) 직원이 연결되지 않던 문제를 고쳤어요. 이제 맥 설치 파일을 만들 때 Codex가 없으면 만들기를 멈춰서 같은 일이 다시 생기지 않아요.
- 예약 업무를 편집하거나 단축키(⌘K·⌘F·꾸미기 키)를 쓸 때 'toLowerCase' 오류가 나던 문제를 고쳤어요. 윈도우 자동완성처럼 키 이름이 없는 입력이 들어와도 오류가 나지 않아요. 예전 PC에서 받은 명령 자동완성 목록도 오류 없이 걸러요.
- 직원이 자동 허용된 명령으로 파일을 쓴 뒤 바로 실행해 결재를 피하던 틈을 막았어요. 바로가기 폴더(예: /tmp)로 고친 파일이 시험 통과 처리되던 문제도 고쳤어요.
- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English
### Improvements
- The schedule list now has an 'Edit' button. Change the time, days and instruction, then press 'Save changes' to update the same schedule; its last-run record is kept. The list also shows the 'Next run' time.
- The reason an approval is waiting is now shown in one line, for example 'Waiting because this command is unfamiliar', 'Waiting because this is risky (delete, push, or sending data out)' or 'Waiting because it wants to run a file it just edited'.
- The approval screen and staff profile now show whether auto-approve is on and what this staff member's approval mode is. When it is off, a 'Turn on' button takes you to Settings.
- The usage card shows 'Updated N minutes ago'.
- Newly hired staff now default to the 'Edits are automatic' approval mode: file edits are not asked, while risky things like delete or push are still asked. Staff hired from the phone stay on 'Ask for everything'.
- Auto-approve and autonomous mode now ask less often than necessary. They wait only when a staff member actually runs a file they just edited. Touching a similarly named file, or running test and check commands after editing a settings file, no longer blocks.
- At the same time, workarounds are blocked more firmly. Editing a file and then running it directly or indirectly, writing a file with a command and running it right away, or moving to another folder to run it still waits. Edited-file records are kept per work folder, and a shortcut folder counts as the same folder.
- When autonomous mode rejects something, staff are told not to work around it or retry another way, and to leave it in the 'Needs owner check' list.
- Windows paths and ways of running commands are now judged by the same rules.
- If the GPT (Codex) component is missing from the app, you are told to 'update the app to the latest version'. When connecting fails or cannot be checked, the card shows a 'Check again' button.
- Differences by device: only the Mac app was missing the Codex component; Windows is not affected. The phone app keeps the same number with no code change and uses the new screens sent by the PC.
- Please note: **If you use Mac 1.1.0 or 1.1.1, please update to 1.1.2.** Those two Mac builds were missing GPT (Codex), so GPT staff could not connect.
- Please note: usage is not live. It updates only while staff are working and when you press the refresh button, and the card shows when it was last updated.
- Please note: for safety, auto-approve is still cautious, so unfamiliar commands and running scripts staff wrote themselves are still asked.

### Bug fixes
- Fixed GPT (Codex) staff not connecting in Mac 1.1.0 and 1.1.1. Building a Mac installer now stops if Codex is missing, so this cannot happen again.
- Fixed a 'toLowerCase' error when editing a schedule or using shortcuts (⌘K, ⌘F, decorate keys). Input without a key name, such as Windows autofill, no longer causes an error. Command suggestion lists from older PCs are also filtered without errors.
- Closed a gap where staff could write a file with an auto-allowed command and run it right away to avoid approval. Also fixed edited files being passed as tested when reached through a shortcut folder such as /tmp.
- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語
### 改善
- 予約業務の一覧に「編集」ボタンができました。時間・曜日・指示を直して「変更を保存」を押すと同じ予約が変わり、最後の実行記録は残ります。一覧には「次回実行」の時刻も表示されます。
- 承認を待っている理由が1行で表示されます。例:「初めて見るコマンドなので待っています」「削除・プッシュ・外部送信など危険な操作なので待っています」「直前に修正したファイルを実行しようとしているので待っています」。
- 承認画面とスタッフのプロフィールに、自動決裁がオンかどうか、このスタッフの承認方法が何かが1行で表示されます。オフのときは「オンにする」ボタンで設定画面へ移動できます。
- 使用量カードに「最終更新 N分前」が表示されます。
- 新しく採用するスタッフの標準の承認方法が「編集は自動」になりました。ファイル編集は確認せず、削除・プッシュなど危険な操作は引き続き確認します。スマートフォンで採用した場合は従来どおり「すべて確認」です。
- 自動決裁・自律モードが必要以上に確認していた点を減らしました。スタッフが直前に修正したファイルを実際に実行するときだけ待ちます。名前が似たファイルを扱ったり、設定ファイルを直した後にテスト・確認コマンドを実行したりしても、止まらなくなりました。
- 一方で回避策はより強く防ぎます。ファイルを直してから直接・間接に実行する、コマンドでファイルを書いてすぐ実行する、別のフォルダーに移って実行する場合は、これまでどおり待ちます。修正ファイルの記録は作業フォルダーごとに残し、ショートカットのフォルダーから入っても同じフォルダーとして扱います。
- 自律モードで拒否された作業は、別の方法で回避したり再試行したりせず、「代表の確認が必要」リストに残すよう案内します。
- Windows のパスと実行方法も同じルールで判定します。
- アプリに GPT（Codex）の構成要素がない場合は「アプリを最新バージョンにアップデートしてください」と案内します。接続の実行に失敗したときや確認できなかったときは、カードに「再確認」ボタンが出ます。
- 端末ごとの違い: Codex の構成要素が欠けていたのは Mac のみで、Windows は影響ありません。スマートフォンアプリはコード変更なしで同じ番号に合わせ、画面は PC から送られる新しい画面を使います。
- お知らせ: **Mac 1.1.0・1.1.1 をお使いの場合は 1.1.2 にアップデートしてください。** この2つの Mac 版には GPT（Codex）が含まれておらず、GPT スタッフが接続できませんでした。
- お知らせ: 使用量はリアルタイムではありません。スタッフが作業しているときと更新ボタンを押したときだけ更新され、カードに最終更新時刻が表示されます。
- お知らせ: 自動決裁は安全のため引き続き慎重で、初めて見るコマンドやスタッフが自分で作ったスクリプトの実行は確認します。

### バグ修正
- Mac 1.1.0・1.1.1 で GPT（Codex）スタッフが接続できなかった問題を直しました。Mac のインストーラーを作るときに Codex がないと作成を止めるので、同じことは起きません。
- 予約業務の編集やショートカット（⌘K・⌘F・飾り付けキー）で「toLowerCase」エラーが出る問題を直しました。Windows のオートフィルのようにキー名のない入力でもエラーになりません。古い PC から受け取ったコマンド候補の一覧もエラーなく絞り込みます。
- スタッフが自動許可されたコマンドでファイルを書いてすぐ実行し、承認を避けられた抜け穴をふさぎました。/tmp などのショートカットフォルダー経由で、修正したファイルがテスト通過扱いになる問題も直しました。
- お知らせ: Windows のインストーラーには署名がないため、初めて開くときに警告ウィンドウ（SmartScreen）が表示されます。「詳細情報 › 実行」をクリックしてください。

## 中文
### 改进
- 定时任务列表新增“编辑”按钮。修改时间、星期和指示后点“保存更改”，就会更新同一个定时任务，上次执行记录会保留。列表中还会显示“下次执行”时间。
- 等待审批的原因会用一行字显示。例如“这是陌生的命令，正在等待”“这是删除、推送、对外发送等危险操作，正在等待”“要运行刚修改的文件，正在等待”。
- 审批界面和员工资料中会用一行显示自动审批是否开启，以及该员工的审批方式。关闭时，可点“开启”前往设置。
- 用量卡片显示“最后更新 N 分钟前”。
- 新雇用员工的默认审批方式改为“修改自动”：修改文件不再询问，删除、推送等危险操作仍会询问。在手机上雇用的员工仍是“全部询问”。
- 减少了自动审批和自主模式不必要的询问。只有员工真正运行刚修改的文件时才会等待。处理名称相近的文件，或修改设置文件后运行测试、检查命令，不会再被拦住。
- 同时加强了对绕过方式的拦截。修改文件后直接或间接运行它、用命令写入文件后立即运行、换到其他文件夹运行，仍会等待。已修改文件的记录按工作文件夹保存，通过快捷方式文件夹进入也视为同一个文件夹。
- 自主模式拒绝某项操作时，会提示员工不要绕过或换方法重试，而是把它留在“需代表确认”列表中。
- Windows 的路径和运行方式也按同样规则判断。
- 应用中缺少 GPT（Codex）组件时，会提示“请将应用更新到最新版本”。连接运行失败或无法确认时，卡片中会出现“重新检查”按钮。
- 各设备差异：只有 Mac 应用缺少 Codex 组件，Windows 不受影响。手机应用没有代码改动，仅号码与电脑版保持一致，界面使用电脑发送的新界面。
- 请注意：**如果您使用 Mac 1.1.0 或 1.1.1，请更新到 1.1.2。** 这两个 Mac 版本缺少 GPT（Codex），GPT 员工无法连接。
- 请注意：用量不是实时的。只在员工工作时和点击刷新按钮时更新，卡片会显示最后更新时间。
- 请注意：出于安全考虑，自动审批仍然比较谨慎，陌生命令和员工自己编写的脚本仍会询问。

### 问题修复
- 修复了 Mac 1.1.0、1.1.1 中 GPT（Codex）员工无法连接的问题。现在制作 Mac 安装文件时如果缺少 Codex 就会中止，不会再出现同样的问题。
- 修复了编辑定时任务或使用快捷键（⌘K、⌘F、装饰键）时出现“toLowerCase”错误的问题。Windows 自动填充这类没有按键名称的输入也不会再报错。从旧电脑收到的命令建议列表也能正常过滤。
- 堵住了员工用自动允许的命令写入文件后立即运行、从而避开审批的漏洞。还修复了通过 /tmp 等快捷方式文件夹访问时，修改过的文件被当作已测试通过的问题。
- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
