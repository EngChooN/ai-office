# AI Office 0.17.0 (2026-10-31)

## 한국어

### 새 기능
- 바탕화면 비서 캐릭터(맥): 앱을 설치하면 바탕화면에 비서 캐릭터가 떠 있어요. 끌어서 원하는 곳에 두고, 화면 가장자리 가까이 놓으면 가장자리에 붙어요. 설정 > 연결에서 끄거나 켤 수 있어요.
- 캐릭터를 누르면 작은 창이 열려요. 앱을 열지 않고도 결재를 승인·반려하고, 직원 질문에 답하거나 넘기고, 비서에게 말할 수 있어요. 창에 다 담기 어려운 긴 질문은 '앱에서 열기'로 이어져요.
- 결재가 오면 캐릭터 머리 위에 말풍선(!)이 뜨고 캐릭터가 폴짝 뛰어요. 평소에는 숨쉬고 두리번거려요.

### 개선
- 바탕화면 비서의 표정이 상황에 따라 바뀌어요. 결재가 오면 놀라고, 대답을 만드는 동안은 생각하고, 승인·답하기를 마치면 기뻐하고, 오류가 나면 걱정해요. 직원이 일하는 동안은 집중하고, 10분 넘게 조용하면 졸아요.
- 캐릭터 크기(80~160)와 투명도(40~100%)를 설정에서 바꿀 수 있고, 바꾸면 바로 반영돼요.
- 숨겨 둔 캐릭터는 메뉴 막대나 설정에서 다시 불러올 수 있어요.
- 화면의 움직임 줄이기를 켜 두면 캐릭터가 움직이지 않아요.

- 알려 드려요: 바탕화면 비서는 맥에서만 나와요. 윈도우와 휴대폰 앱에는 이번 버전에서 바뀐 기능이 없어요.
- 알려 드려요: 윈도우 zip 파일은 계속 올리지 않아요. 옛 zip 앱을 쓰던 분은 Release 페이지에서 Setup.exe를 직접 받아 설치한 뒤 옛 폴더를 지우면 돼요. 설정과 기록은 그대로 이어져요.
- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English

### New features
- Desktop secretary character (Mac): after install, a secretary character sits on your desktop. Drag it anywhere; drop it near a screen edge and it snaps to the edge. Turn it on or off in Settings > Connections.
- Click the character to open a small window. Without opening the app, you can approve or reject requests, answer or skip staff questions, and talk to the secretary. Questions too long for the window continue via 'Open in app'.
- When an approval arrives, a speech bubble (!) appears above the character and it hops. Otherwise it breathes and looks around.

### Improvements
- The desktop secretary's face changes with the situation: surprised when an approval arrives, thinking while it prepares an answer, happy after you approve or answer, worried on errors, focused while staff are working, and sleepy after 10 quiet minutes.
- Change the character's size (80–160) and opacity (40–100%) in Settings; changes apply right away.
- A hidden character can be brought back from the menu bar or Settings.
- If Reduce Motion is on, the character stays still.

- Please note: the desktop secretary appears on Mac only. The Windows and phone apps have no changes in this version.
- Please note: the Windows zip file is still not published. If you used the old zip app, download Setup.exe from the Release page, install it, and then delete the old folder. Your settings and history carry over.
- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語

### 新機能
- デスクトップ秘書キャラクター（Mac）：インストールするとデスクトップに秘書キャラクターが表示されます。ドラッグして好きな場所に置け、画面の端の近くに置くと端に吸着します。設定 > 連携でオン・オフできます。
- キャラクターをクリックすると小さなウィンドウが開きます。アプリを開かずに承認・却下、スタッフの質問への回答・スキップ、秘書との会話ができます。ウィンドウに収まらない長い質問は「アプリで開く」から続けられます。
- 承認待ちが届くとキャラクターの頭上に吹き出し（!）が出て、ぴょんと跳ねます。普段は呼吸したり、きょろきょろしたりします。

### 改善
- デスクトップ秘書の表情が状況に合わせて変わります。承認待ちが届くと驚き、回答を作る間は考え込み、承認・回答を終えると喜び、エラーが出ると心配します。スタッフが作業中は集中し、10分以上静かだと眠そうになります。
- キャラクターのサイズ（80〜160）と透明度（40〜100%）を設定で変更でき、すぐに反映されます。
- 隠したキャラクターはメニューバーや設定から呼び戻せます。
- 「視差効果を減らす」がオンのときはキャラクターが動きません。

- お知らせ：デスクトップ秘書は Mac でのみ表示されます。Windows とスマホアプリには今回の変更はありません。
- お知らせ：Windows の zip ファイルは引き続き公開しません。古い zip 版アプリを使っていた方は、Release ページから Setup.exe を直接ダウンロードしてインストールし、古いフォルダーを削除してください。設定と履歴はそのまま引き継がれます。
- お知らせ：Windows のインストーラーには署名がないため、初めて開くときに警告画面（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。

## 中文

### 新功能
- 桌面秘书角色（Mac）：安装后桌面上会出现秘书角色。可拖到任意位置，放在屏幕边缘附近会自动贴边。可在 设置 > 连接 中开启或关闭。
- 点击角色会打开小窗口。无需打开应用即可批准或驳回审批、回答或跳过员工提问、与秘书对话。窗口放不下的长问题可通过“在应用中打开”继续。
- 有审批到达时，角色头上会出现气泡（!）并跳一下。平时会呼吸、东张西望。

### 改进
- 桌面秘书的表情会随情况变化：有审批到达时惊讶，准备回答时思考，完成批准或回答后开心，出错时担心，员工工作时专注，安静超过10分钟会犯困。
- 可在设置中调整角色大小（80–160）和透明度（40–100%），立即生效。
- 隐藏的角色可从菜单栏或设置中重新调出。
- 开启“减弱动态效果”时角色保持静止。

- 请注意：桌面秘书仅在 Mac 上显示。Windows 和手机应用本版本没有变化。
- 请注意：仍然不发布 Windows zip 文件。使用旧 zip 版应用的用户，请到 Release 页面直接下载 Setup.exe 安装，然后删除旧文件夹。设置和记录会保留。
- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
