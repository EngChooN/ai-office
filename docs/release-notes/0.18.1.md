# AI Office 0.18.1 (2026-10-31)

## 한국어

### 개선
- 앱이 더 빨리 열려요. 처음에 불러오는 양을 절반으로 줄이고, 다른 화면은 열 때 불러와요. 화면을 불러오지 못하면 그 자리에 '다시 시도' 안내가 나와요.
- GPT(Codex) 사용률을 읽지 못하면 이유(프로그램을 못 찾음·응답 없음·정보 없음 등)를 알려 줘요. 새로고침은 Codex 사용률까지 다 읽은 뒤 끝나요.
- 자동 승인 판단이 더 꼼꼼해졌어요. 확실히 안전한 명령만 자동으로 넘기고, 처음 보는 명령·패키지 설치·갱신은 대표에게 확인을 받아요.
- 기록에서 비밀번호·키 같은 비밀 값을 더 잘 가려요.

### 버그 수정
- 업무 카드 하나의 결과물 정보가 깨지면 업무 카드 목록 전체가 안 보이던 문제를 고쳤어요.
- 매뉴얼을 저장할 때 같은 이름의 다른 매뉴얼을 덮어쓰거나 원본이 지워질 수 있던 문제를 고쳤어요. 윈도우에서 만든 매뉴얼도 제대로 읽어요.

- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English

### Improvements
- The app opens faster. It loads half as much at startup and loads other screens when you open them. If a screen can't load, a 'Try again' notice appears in its place.
- If GPT (Codex) usage can't be read, the app tells you why (program not found, no response, no data, etc.). Refresh now finishes only after Codex usage is read.
- Auto-approval is stricter. Only clearly safe commands pass automatically; unfamiliar commands and package installs or updates ask you first.
- Secrets such as passwords and keys are hidden more reliably in logs.

### Bug fixes
- Fixed the whole task card list disappearing when one card's result data was broken.
- Fixed saving a manual possibly overwriting another manual with the same name or deleting the original. Manuals made on Windows are now read correctly.

- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語

### 改善
- アプリの起動が速くなりました。最初に読み込む量を半分に減らし、ほかの画面は開いたときに読み込みます。画面を読み込めないときは、その場所に「再試行」の案内が出ます。
- GPT（Codex）の使用率を読み取れないとき、理由（プログラムが見つからない・応答がない・情報がないなど）を表示します。更新は Codex の使用率まで読み終えてから完了します。
- 自動承認の判定がより厳しくなりました。確実に安全なコマンドだけを自動で通し、見慣れないコマンドやパッケージのインストール・更新は代表に確認します。
- 記録の中のパスワードやキーなどの秘密の値をより確実に隠します。

### バグ修正
- 業務カード1枚の成果物情報が壊れていると、業務カード一覧全体が表示されなかった問題を修正しました。
- マニュアル保存時に同じ名前の別マニュアルを上書きしたり、元のファイルが消えたりすることがあった問題を修正しました。Windows で作ったマニュアルも正しく読み込みます。

- お知らせ：Windows のインストーラーには署名がないため、初めて開くときに警告画面（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。

## 中文

### 改进
- 应用打开更快了。启动时加载的内容减少一半，其他页面在打开时才加载。页面加载失败时，会在原位置显示“重试”提示。
- 无法读取 GPT（Codex）使用率时，会说明原因（找不到程序、没有回应、没有数据等）。刷新会等到 Codex 使用率读取完毕后才结束。
- 自动批准的判断更严格了。只有确定安全的命令会自动通过，陌生命令以及安装、更新软件包会先征求你的确认。
- 记录中的密码、密钥等机密值会被更可靠地隐藏。

### 问题修复
- 修复了某张任务卡的成果信息损坏时，整个任务卡列表无法显示的问题。
- 修复了保存手册时可能覆盖同名的其他手册或删除原文件的问题。在 Windows 上制作的手册也能正确读取。

- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
