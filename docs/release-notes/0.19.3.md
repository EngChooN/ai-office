# AI Office 0.19.3 (2026-11-02)

## 한국어

### 개선
- 화면에 나오는 말을 쉬운 우리말로 맞췄어요. "상대 PC"는 "다른 PC"로, 연결 거절은 "반려"로, 업무 흐름은 "매뉴얼 단계 진행"으로, 요금제 알림의 5시간·7일 창은 "최근 5시간·최근 7일"로 바꿨어요. 메뉴바에서는 "포트 번호" 표시를 없앴어요.
- 자율 진행 기록에 "Bash" 같은 도구 이름 대신 "프로그램 실행·파일 수정·파일 읽기·웹 조회"로 나와요. 직원 채팅 안내에서도 "delegate"·"백그라운드" 같은 말을 뺐어요.
- 연결 상태 안내(Claude·GPT(Codex) 로그인 필요, 설치 안 됨 등)와 업데이트 실패 안내를 비개발자도 알 수 있게 다시 썼어요.
- 장비 프리셋·연결 도구 추가·외부 직원 알림 설명을 쉬운 말로 다시 썼어요. 긴 설명은 '자세히'로 접히고, 변경 탭의 괄호 속 용어는 풀어서 보여 줘요. 화면마다 다르던 용어도 하나로 맞췄어요.
- 첫 실행 안내를 정리했어요. 소개 카드는 3장(고용·지시·결재)이고 필요한 계정(Claude 유료 구독 또는 ChatGPT)을 미리 알려 줘요. 준비 점검은 설치 확인을 빼고 로그인 → 폴더 → 첫 업무 3단계로 줄었고, 폴더 단계에는 예시와 "직원이 이 폴더의 파일을 고칠 수 있어요", "안 골라도 돼요" 안내가 붙었어요.
- Claude 로그인이 브라우저로 바로 열려요. 터미널 창에서 계정 종류를 고를 필요가 없어요. 로그인 주소가 나뉘어 나와도 끝까지 받은 뒤 열고, 브라우저를 못 열거나 10초 안에 주소를 못 받으면 터미널 로그인으로 넘어가요. 로그인을 취소하면 터미널을 열지 않고 그대로 멈춰요.
- 상태를 확인하는 동안(다시 확인할 때도)에는 '다음'과 '나중에'가 눌리지 않고 '확인 중…'이 보여요.
- 첫 업무가 실패하면 이유에 맞는 버튼이 나와요. 로그인 문제면 로그인 단계로, 네트워크 문제면 다시 시도(로그인 버튼 없음), 알 수 없는 오류는 원문 보기와 다시 시도, 시간이 오래 걸리면 '이어 보기'로 그 직원 패널을 열어요. 완료 화면에는 결재함·보고 위치 안내와 결재함 바로 가기가 있고 추천 버튼 하나만 강조돼요.
- 둘러보기를 핵심 5단계로 줄이고 마지막에 '더 보기'를 뒀어요. 건너뛰거나 그만 보면 '설정 › 안내에서 다시 볼 수 있어요' 알림이 떠요. 첫 업무를 해 본 분은 연습 고르기를 건너뛰어요.
- 직원 고용 창은 이름·직무만 보이고 나머지는 '자세히 설정'으로 접혀요. 성능 등급 설명도 붙었어요.
- 빈 화면 안내: 직원이 없는 사무실 띠에 '직원 고용'·'안내 다시 보기' 버튼, 빈 직원 패널에 예시 지시 칩, 빈 결재함에 설명과 고용 버튼이 생겼어요. GPT 안내 띠는 직원이 0명이면 고용할 때까지 띄우지 않아요.
- 첫 실행 안내의 로그인 단계가 Claude와 ChatGPT(Codex) 계정을 함께 확인해요. 두 계정 카드가 항상 나란히 보이고, 둘 중 하나만 준비돼도 넘어갈 수 있어요. 둘 다 준비되면 둘 다 ✓로 보여요.
- GPT(Codex) 직원의 '베타' 표시를 없앴어요. 이제 Claude와 똑같이 정식으로 지원해요.
- 휴대폰 앱에서도 자율 진행을 켤 수 있어요. 지시창과 업무 카드에 '자율 진행' 칸이 보여요. 위험한 작업은 자율 진행이어도 건너뛰고, 휴대폰에서 켜면 PC에 알림이 가요.
- 휴대폰 앱에서 자동결재를 '지금부터 1·4·8·12시간'으로 켤 수 있어요. 정한 시간이 지나면 저절로 꺼지고, 켜면 PC에 알림이 가요. 매일 시간대와 완전 자율은 지금처럼 PC에서만 정해요.
- 휴대폰에서 바꿀 수 없는 칸에는 'PC에서 바꿀 수 있어요'가 보여요. 직원 작업 폴더, 채용할 때 작업 폴더·결재 방식, 외부 직원 정식 채용 때 결재 방식, 장비의 도구 허용·금지, 직원 화면 캡처 허용, 내 계정 매뉴얼 고치기·지우기, 랩 작업 폴더가 해당돼요. 휴대폰 자동결재는 최대 12시간까지만 켜져요. 결재함의 '앞으로 자동 승인'은 프로그램 실행 요청이면 휴대폰에서 보이지 않아요(누르면 이번 한 번만 승인되던 문제).
- 휴대폰에서 자율 진행이나 자동결재를 켤 때 PC 앱이 예전 버전이면, 오류 대신 'PC의 AI Office를 업데이트해 주세요' 안내가 나와요.

- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English

### Improvements
- On-screen wording is now plainer and consistent. "Peer PC" became "other PC", rejecting a connection is "send back", workflows are "manual steps run", and plan-usage alerts say "last 5 hours / last 7 days". The menu bar no longer shows a port number.
- The autonomous-run log now shows "run program / edit file / read file / web lookup" instead of tool names like "Bash", and staff chat hints no longer mention "delegate" or "background".
- Account/connection status messages (Claude or GPT (Codex) sign-in needed, not installed, etc.) and update-failure messages were rewritten for non-developers.
- Descriptions for equipment presets, adding connected tools, and external-staff notifications were rewritten in plain language. Long explanations fold under "Details", bracketed terms on the Changes tab are spelled out, and terms that differed between screens are now consistent.
- The first-run guide is tidier. There are 3 intro cards (hire, instruct, approve), and it tells you up front which account you need (a paid Claude plan or ChatGPT). Setup checks drop the install check and now have 3 steps: sign in → folder → first task. The folder step shows an example plus "Staff can edit files in this folder" and "You can skip this".
- Claude sign-in opens straight in your browser, so you no longer pick an account type in a terminal window. If the sign-in link arrives in pieces, the app waits for the full link before opening it. If the browser can't open or no link arrives within 10 seconds, it falls back to terminal sign-in. Cancelling sign-in just stops without opening a terminal.
- While status is being checked (including re-checks), "Next" and "Later" are disabled and "Checking…" is shown.
- If the first task fails, you get buttons that match the reason: a sign-in problem takes you to the sign-in step, a network problem offers a retry (without a sign-in button), an unknown error offers "view original" and a retry, and if the task takes a long time, "Keep watching" opens that staff member's panel. The finish screen explains where the approval inbox and reports are, adds a shortcut to the inbox, and highlights only one recommended button.
- The tour is cut to 5 key steps with "See more" at the end. If you skip or stop it, a notice says you can replay it in Settings › Guide. If you have already done a first task, the practice-task picker is skipped.
- The hire dialog shows only name and role, and folds the rest under "More settings". Performance tiers now have descriptions.
- Empty-state hints: an office with no staff shows "Hire staff" and "Replay guide" buttons in the banner, an empty staff panel shows example instruction chips, and an empty approval inbox explains itself and offers a hire button. The GPT banner stays hidden until you hire someone if you have no staff.
- The sign-in step of the first-run guide now checks your Claude and ChatGPT (Codex) accounts together. Both account cards are always shown side by side, and either one being ready is enough to continue. When both are ready, both show a ✓.
- The "Beta" label on GPT (Codex) staff is gone. GPT is now fully supported, just like Claude.
- You can now turn on autonomous mode from the phone app. The "Autonomous" checkbox appears in the instruction box and on task cards. Risky actions are still skipped in autonomous mode, and the PC gets a notice when it is turned on from the phone.
- From the phone app you can turn on auto-approval for 1, 4, 8, or 12 hours from now. It turns itself off when the time is up, and the PC gets a notice when it is turned on. A daily time range and full autonomy are still set only on the PC.
- Settings the phone can't change now say "You can change this on the PC." This covers a staff member's work folder, the folder and approval style when hiring, the approval style when formally hiring external staff, tool allow/block in equipment, allowing staff screen capture, editing or deleting My-account manuals, and a lab's work folder. Auto-approval from the phone can be turned on for at most 12 hours. In the approval inbox, "Always allow" no longer appears on the phone for program-run requests (tapping it used to approve only that one request).
- If the PC app is an older version when you turn on autonomous mode or auto-approval from the phone, you now see a prompt to update AI Office on the PC instead of an error.

- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語

### 改善

- 自律進行の記録に「Bash」などのツール名ではなく「プログラム実行・ファイル編集・ファイル読み取り・Web参照」と表示されます。社員チャットの案内から「delegate」「バックグラウンド」も除きました。
- アカウント接続状態（Claude・GPT(Codex)のログイン必要、未インストールなど）とアップデート失敗の案内を、開発者でなくても分かるように書き直しました。

- 初回起動の案内を整理しました。紹介カードは3枚（採用・指示・決裁）で、必要なアカウント（Claudeの有料プランまたはChatGPT）を先にお知らせします。準備チェックはインストール確認をなくし、ログイン → フォルダ → 最初の業務の3段階になりました。フォルダの段階には例と「社員がこのフォルダのファイルを編集できます」「選ばなくても大丈夫です」の案内が付きます。
- Claudeのログインがブラウザで直接開きます。ターミナル画面でアカウントの種類を選ぶ必要はありません。ログインURLが分割して届いても最後まで受け取ってから開き、ブラウザを開けないときや10秒以内にURLを受け取れないときはターミナルでのログインに切り替えます。ログインを取り消した場合はターミナルを開かずにそのまま止まります。

- ツアーを主要な5段階に絞り、最後に「もっと見る」を置きました。スキップやツアーの終了をすると「設定 › 案内からもう一度見られます」と通知します。最初の業務を済ませた方は練習課題の選択を飛ばします。
- 社員採用の画面は名前と職務だけを表示し、残りは「詳細設定」に折りたたみます。性能ランクの説明も付きました。
- 空の画面の案内：社員がいないオフィスの帯に「社員を採用」「案内をもう一度見る」ボタン、空の社員パネルに指示例のチップ、空の決裁箱に説明と採用ボタンが付きました。GPTの案内帯は、社員が0人のときは採用するまで表示しません。
- 初回起動の案内のログイン段階で、ClaudeとChatGPT(Codex)のアカウントをあわせて確認します。2つのアカウントカードが常に並んで表示され、どちらか1つが準備できていれば次に進めます。両方準備できていれば両方に✓が付きます。
- GPT(Codex)社員の「ベータ」表示をなくしました。これからはClaudeと同じく正式に対応します。
- スマホアプリからも自律進行をオンにできます。指示欄と業務カードに「自律進行」の欄が表示されます。危険な作業は自律進行でもスキップし、スマホでオンにすると PC に通知が届きます。
- スマホアプリから自動承認を「今から1・4・8・12時間」でオンにできます。時間が過ぎると自動でオフになり、オンにすると PC に通知が届きます。毎日の時間帯と完全自律はこれまでどおり PC でのみ設定します。
- スマホで変更できない項目には「PC で変更できます。」と表示されます。社員の作業フォルダ、採用時の作業フォルダ・承認方式、外部社員を正式採用するときの承認方式、装備のツール許可・禁止、社員の画面キャプチャ許可、マイアカウントのマニュアルの編集・削除、ラボの作業フォルダが対象です。スマホからの自動決裁は最大 12 時間までです。決裁箱の「今後は自動承認」は、プログラム実行の依頼ならスマホでは表示されません（押しても今回だけ承認される問題）。
- スマホで自律進行や自動決裁をオンにするとき、PC アプリが古いバージョンなら、エラーの代わりに「PC の AI Office をアップデートしてください」と案内されます。

- お知らせ：Windows のインストーラーには署名がないため、初めて開くときに警告画面（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。

## 中文

### 改进
- 统一并简化了界面用语。“对方 PC”改为“其他 PC”，拒绝连接改为“退回”，工作流程改为“手册步骤进行”，套餐用量通知改为“最近 5 小时 / 最近 7 天”。菜单栏不再显示端口号。
- 自主进行记录中不再显示“Bash”等工具名，而是“运行程序・修改文件・读取文件・网页查询”。员工聊天提示也去掉了“delegate”“后台”等词。
- 重写了账号连接状态（需要登录 Claude 或 GPT(Codex)、未安装等）和更新失败的提示，让非开发人员也能看懂。
- 用浅显的话重写了装备预设、添加连接工具、外部员工通知的说明。较长的说明收在“详细”中，变更标签页中括号里的术语也改为直白的说法，各界面不一致的用语也统一了。
- 整理了首次运行引导。介绍卡片为 3 张（雇用・指示・审批），并提前告知需要的账号（Claude 付费订阅或 ChatGPT）。准备检查去掉了安装确认，缩减为登录 → 文件夹 → 第一项任务共 3 步。文件夹这一步附有示例，以及“员工可以修改此文件夹中的文件”“不选也可以”的说明。
- Claude 登录会直接在浏览器中打开，不再需要在终端窗口里选择账号类型。登录链接分段传来时，会等完整收到后再打开；浏览器打不开或 10 秒内没收到链接时，改用终端登录。取消登录时不会打开终端，直接停止。
- 正在确认状态时（包括重新确认），“下一步”和“稍后”无法点击，并显示“确认中…”。
- 第一项任务失败时，会显示与原因相符的按钮：登录问题会带你回到登录步骤，网络问题提供重试（不显示登录按钮），未知错误提供查看原文和重试，耗时较长时可用“继续查看”打开该员工的面板。完成页面会说明审批箱和报告的位置，提供审批箱快捷入口，并只突出一个推荐按钮。
- 导览精简为 5 个关键步骤，最后提供“查看更多”。跳过或停止导览时，会提示“可在 设置 › 引导 中再次查看”。已经做过第一项任务的用户会跳过练习任务选择。
- 雇用员工窗口只显示姓名和职务，其余内容收在“详细设置”中。性能等级也加了说明。
- 空状态引导：没有员工的办公室横幅中有“雇用员工”“再看一遍引导”按钮，空的员工面板中有示例指令标签，空的审批箱中有说明和雇用按钮。员工为 0 人时，GPT 提示横幅在雇用员工之前不会显示。
- 首次运行引导的登录步骤会同时检查 Claude 和 ChatGPT(Codex) 账号。两张账号卡片始终并排显示，只要其中一个就绪即可继续。两个都就绪时都会显示 ✓。
- 去掉了 GPT(Codex) 员工的“测试版”标记。现在与 Claude 一样正式支持。
- 手机应用也可以开启自主推进了。指令框和任务卡上会显示“自主推进”选项。即使在自主推进中，危险操作也会跳过；在手机上开启时，电脑会收到通知。
- 手机应用可以“从现在起 1·4·8·12 小时”开启自动审批。到时间会自动关闭，开启时电脑会收到通知。每天的时间段和完全自主仍然只能在电脑上设置。
- 手机上无法更改的项目会显示“可在电脑上更改。”包括员工工作文件夹、招聘时的工作文件夹和审批方式、正式招聘外部员工时的审批方式、装备的工具允许/禁止、允许员工截屏，修改或删除“我的账户”手册，以及实验室的工作文件夹。手机上开启自动审批最多 12 小时。审批箱中的“以后自动批准”在程序运行请求上不再在手机显示（以前点了也只批准这一次）。
- 在手机上开启自主推进或自动审批时，如果电脑端应用是旧版本，会提示“请更新电脑上的 AI Office”，而不是报错。

- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
