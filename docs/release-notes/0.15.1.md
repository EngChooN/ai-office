## 한국어

### 버그 수정
- 안드로이드 앱에서 사진을 붙이려고 사진 선택 창을 열면 앱이 갑자기 꺼지던 문제를 고쳤어요. 선택 창이 앱을 가리는 순간 실시간 연결이 닫히면서 생기던 오류였어요.
- 직원 대화창의 입력란을 선택하면 포커스 테두리가 두 겹으로 겹쳐 보이던 문제를 고쳤어요. 이제 바깥 테두리 한 겹만 강조돼요.

### 개선
- 기기별 차이: 안드로이드 수정은 휴대폰 앱에만 해당해요. PC 앱은 입력란 테두리 수정만 적용돼요.
- 알려 드려요: 윈도우 zip 파일은 계속 올리지 않아요. 옛 zip 앱을 쓰던 분은 Release 페이지에서 Setup.exe를 직접 받아 설치한 뒤 옛 폴더를 지우면 돼요. 설정과 기록은 그대로 이어져요.
- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English

### Bug fixes
- Fixed the Android app suddenly closing when you opened the photo picker to attach a picture. The error happened when the live connection closed the moment the picker covered the app.
- Fixed the focus outline of the input box in the staff chat looking doubled when selected. Now only the outer border is highlighted.

### Improvements
- Differences by device: the Android fix applies only to the phone app. The PC app only gets the input outline fix.
- Please note: the Windows zip file is still not published. If you used the old zip app, download Setup.exe from the Release page, install it, and then delete the old folder. Your settings and history carry over.
- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語

### バグ修正
- Android アプリで写真を添付しようと写真選択画面を開くと、アプリが突然終了する問題を修正しました。選択画面がアプリを覆った瞬間にリアルタイム接続が閉じて起きるエラーでした。
- 社員のチャット画面で入力欄を選択すると、フォーカスの枠が二重に見える問題を修正しました。外側の枠だけが強調されます。

### 改善
- 端末ごとの違い: Android の修正はスマートフォンアプリのみが対象です。PC アプリには入力欄の枠の修正だけが適用されます。
- お知らせ：Windows の zip ファイルは引き続き公開しません。古い zip 版アプリを使っていた方は、Release ページから Setup.exe を直接ダウンロードしてインストールし、古いフォルダーを削除してください。設定と履歴はそのまま引き継がれます。
- お知らせ：Windows のインストーラーには署名がないため、初めて開くときに警告画面（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。

## 中文

### 问题修复
- 修复了在安卓应用中打开照片选择窗口来附加照片时应用会突然关闭的问题。原因是选择窗口遮住应用的瞬间实时连接被关闭而产生错误。
- 修复了在员工对话窗口中选中输入框时，焦点边框显示为双层的问题。现在只高亮外侧一层边框。

### 改进
- 各设备的差异：安卓的修复只适用于手机应用。电脑应用只会应用输入框边框的修复。
- 请注意：仍然不发布 Windows zip 文件。使用旧 zip 版应用的用户，请到 Release 页面直接下载 Setup.exe 安装，然后删除旧文件夹。设置和记录会保留。
- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
