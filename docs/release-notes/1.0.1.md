# AI Office 1.0.1 (2026-11-04)

## 한국어

### 새 기능
- 일하는 중인 직원에게 패널(휴대폰 포함)에서 보낸 지시가 입력칸 위 '대기 메시지'로 쌓였다가, 하던 일이 끝나면 순서대로 전해져요(업무 보드의 다음 업무보다 먼저). 마우스를 올리면(터치 화면은 늘 보여요) '지금 보내기'(하던 일을 멈추고 바로 전하기)와 '취소'가 나와요. 결재·질문을 기다리는 중에 보낸 말과 /명령은 지금처럼 바로 전해져요. 앱을 끄면 대기 메시지는 사라져요.

### 버그 수정
- 피드백에 붙는 오류 기록에서 개인 경로와 폴더 이름을 더 꼼꼼히 가려요. 끝에 있는 폴더 이름, 점이 든 폴더 이름, 길이를 자르는 자리에 걸친 비밀값의 앞부분도 가리고, 파일 이름 뒤에 이어진 글은 남겨 오류 위치를 알 수 있어요.

- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English

### New features
- Instructions you send to a staff member from the panel (including the phone) while they are working now line up as "Waiting messages" above the input box, and are delivered in order when the current work finishes (before the next task on the task board). Hover over one (always visible on touch screens) to see "Send now" (stops the current work and delivers it right away) and "Cancel." Messages sent while waiting for an approval or question, and /commands, are still delivered immediately. Quitting the app clears waiting messages.

### Bug fixes
- The error records attached to feedback now hide personal paths and folder names more thoroughly. A trailing folder name, folder names containing dots, and the start of a secret value cut off at the length limit are hidden too, while text after a file name on the same line is kept so the error location is still visible.

- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語

### 新機能
- 作業中のスタッフにパネル（スマホを含む）から送った指示が、入力欄の上に「待機メッセージ」として並び、作業が終わると順番に届きます（タスクボードの次のタスクより先）。マウスを重ねると（タッチ画面では常に表示）「今すぐ送る」（作業を止めてすぐ伝える）と「取り消し」が出ます。決裁・質問の待機中に送った言葉と /コマンドはこれまで通りすぐ届きます。アプリを終了すると待機メッセージは消えます。

### バグ修正
- フィードバックに付くエラー記録で、個人のパスやフォルダ名をより丁寧に隠すようにしました。末尾のフォルダ名、ドットを含むフォルダ名、長さの上限で切れた秘密の値の前半も隠し、ファイル名の後の同じ行の文は残してエラーの場所が分かるようにしました。

- お知らせ: Windows のインストーラーには署名がないため、初めて開くときに警告ウィンドウ（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。

## 中文

### 新功能
- 在员工工作时从面板（包括手机）发送的指示，会在输入框上方显示为“待发消息”，等当前工作结束后按顺序发送（先于任务看板的下一项任务）。鼠标悬停时（触屏设备始终显示）会出现“立即发送”（停下当前工作并立刻传达）和“取消”。等待审批或提问期间发送的话以及 /命令仍会立即送达。关闭应用后待发消息会消失。

### 问题修复
- 反馈附带的错误记录会更仔细地隐藏个人路径和文件夹名称。末尾的文件夹名、含点的文件夹名、以及在长度上限处被截断的密钥开头部分也会被隐藏，同时保留文件名后同一行的文字，方便定位错误。

- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
