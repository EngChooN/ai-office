# 릴리스 노트 — PC 화면 전체를 휴대폰에서 (2026-10-23)

이번 릴리스는 **세 가지 번호가 따로** 움직입니다. 서로 짝이 맞는 것끼리만 같이 쓰세요.

| 대상 | 버전 | 파일 |
|---|---|---|
| 데스크톱 (맥·윈도우, 같은 버전) | **0.9.0** | 맥 dmg·zip, 윈도우 zip |
| 안드로이드 앱 | **1.1.0** | 서명된 APK (1.0.x와 같은 키, 업데이트로 설치) |
| 원격 프로토콜 | **v2 추가** (v1은 그대로 유지) | `docs/specs/remote-protocol-v2.md` |

**호환 표**
| 데스크톱 | 안드로이드 | 쓰는 프로토콜 | 보이는 것 |
|---|---|---|---|
| 0.8.x | 1.0.x | v1 | 지금과 같다 |
| 0.9.0 이상 | 1.0.x | v1 | 지금과 같다. **1.0.x 앱은 업데이트하지 않아도 계속 연결된다** |
| 0.8.x | 1.1.x | v1 | 예전 화면 + "PC를 올리면 전체 기능을 쓸 수 있어요" 안내 |
| 0.9.0 이상 | 1.1.x | v2 | PC 화면 전체 |

호환 여부는 **프로토콜 버전**으로 판단합니다(PC가 지원하는 버전을 알려 주고 앱이 맞춥니다). 앱과 PC 중 하나만 올려도 서로 깨지지 않습니다.

## 꼭 알아 둘 것 (보안)
1. **이제 휴대폰이 PC 전체를 조작할 수 있어요.** 휴대폰 연결을 켜 두면 별도 스위치 없이 **바로 전체 기능이 열립니다.** 휴대폰은 직원 고용·퇴사, 설정 변경, 결재 승인, 지시, 업무·회의 관리, 커밋·푸시까지 **PC에서 직접 하는 것과 같은 일**을 할 수 있습니다. 이전(0.8.x)에는 상태 보기·결재·질문·기획 확인·지시만 가능했습니다.
   - **0.9.0으로 올리면, 이미 휴대폰 연결을 켜 둔 PC도 따로 조작하지 않아도 전체 기능이 열립니다.** 앱 1.1.0으로 올린 휴대폰이 연결돼 있다면 곧바로 전체 조작이 가능합니다. 쓰지 않는 휴대폰은 PC에서 "QR 다시 만들기"로 끊어 두세요.
2. **QR과 휴대폰을 PC 비밀번호처럼 다루세요.**
   - QR에는 접속 열쇠(토큰)가 들어 있습니다. QR을 찍은 휴대폰은 PC의 Claude Office를 모두 조작할 수 있으니(고용·설정·결재 포함) **QR을 남에게 보이지 마세요.** 사진으로 남기지도 마세요. 5분 뒤 화면에서 가려집니다.
   - 휴대폰을 잃어버렸거나 QR이 노출됐다면 **바로 설정 › 휴대폰 연결 › "QR 다시 만들기"** 를 누르세요. 이전 열쇠가 즉시 막히고 연결된 휴대폰이 모두 끊깁니다.
   - 휴대폰에 화면 잠금을 꼭 걸어 두세요. 앱을 열 수 있는 사람은 PC 전체를 조작할 수 있습니다.
3. **휴대폰 화면에 PC의 폴더 경로가 그대로 보여요.** 휴대폰이 연결되면 직원 작업 폴더 같은 PC의 폴더 경로도 휴대폰 화면에 그대로 나타납니다(PC 화면과 같습니다). 경로에 사용자 이름이나 프로젝트 이름이 들어 있을 수 있으니, 휴대폰 화면을 남에게 보여 줄 때 주의하세요.
4. **휴대폰 연결을 켜 둔 채 앱을 끄면, 다음에 앱을 켤 때 포트가 자동으로 다시 열리고 공유기 자동 설정도 다시 시도해요.** 쓰지 않을 때는 설정 › 휴대폰 연결에서 **꺼 두세요.** 끄면 포트가 바로 닫힙니다.
5. **포트를 열 때는 보안에 주의하세요.** 켜면 이 PC의 포트 하나(기본 47900)가 인터넷 쪽으로 열립니다. 앱은 토큰이 있어야만 답하고, 틀린 시도는 횟수를 제한해 잠그며 PC에 알립니다. 그래도 **쓰지 않을 때는 끄는 것이 가장 안전합니다.**
6. **인증서 고정은 그대로예요.** 휴대폰은 QR에 담긴 이 PC의 인증서 지문과 다른 서버에는 연결하지 않습니다. PC의 원격 키가 바뀌면 QR을 다시 만들어 휴대폰을 다시 연결해야 합니다.
7. **알림은 15분쯤마다 확인하는 방식이라 수십 분 늦을 수 있어요.** 앱을 열어 둔 동안은 PC의 변경이 몇 초 안에 화면에 반영됩니다. 앱이 꺼져 있을 때의 즉시 알림(푸시)은 다음 단계입니다.
8. **연결이 끊기는 설정을 휴대폰에서 바꿀 때는 확인을 한 번 받아요.** 휴대폰에서 "QR 다시 만들기"나 "원격 끄기"를 누르면 그 휴대폰도 바로 끊깁니다.

## 데스크톱 0.9.0
**새 기능 — 휴대폰에서 PC 화면 전체**
- 휴대폰·태블릿 앱에서 PC와 같은 화면(사무실 지도, 직원 패널, 고용, 업무 보드, 결재함, 단체방, 회의, 매뉴얼, 예약, 보고서, 급여 명세서, 상점, 설정 등)을 그대로 쓸 수 있습니다. 태블릿(폭 840dp 이상)은 PC 배치 그대로, 폰은 같은 화면을 모바일 배치로 놓습니다.
- PC에서 바뀐 내용은 몇 초 안에 휴대폰에 반영됩니다(실시간 연결).
- PC에서만 되는 일은 휴대폰에서 "PC에서 해 주세요"라고 안내합니다: 폴더·파일 고르기 창(경로를 직접 입력하거나 최근 폴더에서 고름), 파일을 PC에서 열기(휴대폰에 저장), 터미널 열기, 로그인 창, QR 보기.
- 휴대폰에서 한 일은 기록에 "📱 원격"으로 남습니다.

**개선**
- 설치한 Claude Office와 개발용 Claude Office가 같은 데이터를 동시에 열어 서로 덮어쓰던 일을 막았습니다. 이미 하나가 켜져 있으면 두 번째 앱은 "이미 켜져 있어요"라고 알리고 꺼집니다.

**개선**
- 0.9.0으로 올린 뒤 휴대폰을 연결해 쓰던 PC에서는 처음 한 번 "이제 연결된 휴대폰이 PC를 전부 조작할 수 있어요" 안내가 뜹니다. 내 휴대폰이 아니면 그 자리에서 QR을 다시 만들 수 있습니다.
- 휴대폰 연결 포트를 바꾸면 그 포트가 저장되어 앱을 다시 켜도 그대로 쓰입니다. 바꾸기 전에 "연결된 휴대폰이 끊기고 새 QR을 찍어야 한다"는 확인 창이 뜹니다.
- 휴대폰이 여러 화면을 한꺼번에 불러올 때 연결이 끊기던 일을 줄였습니다. 연결 열쇠가 없는 요청은 내용을 받기 전에 바로 거절합니다.

## 안드로이드 1.1.0
- 1.0.x에서 **업데이트로 설치**됩니다(같은 서명 키). 설치 전 APK의 서명 지문(SHA-256)이 `android/README.md`와 같은지 확인하세요.
- PC 화면 전체를 앱 안에 넣었습니다. 앱은 PC와의 모든 통신을 인증서 고정 연결로만 하고, 화면 부분(WebView)은 직접 인터넷에 나가지 않습니다.
- PC가 0.9.0 이전이면 1.0.x와 같은 화면으로 동작하고 "PC를 올리면 전체 기능을 쓸 수 있어요" 안내를 보여 줍니다.
- 같은 와이파이에서는 QR의 같은 와이파이 주소로 먼저 연결합니다(1.0.1부터).
- 이번 버전에 없는 것: 푸시 알림(FCM), iOS.

## 프로토콜 v2
- PC 화면이 쓰는 기능 전체(81개)를 `POST /v2/call` 하나로 부르고, PC의 변화는 `GET /v2/events`(SSE)로 받으며, 첨부는 `POST /v2/attachments`·`GET /v2/files/{id}`로 주고받습니다.
- 인증·잠금·오류 규칙은 v1과 같고, v1 4종은 그대로 유지됩니다. v1 서버·앱은 바뀌는 것이 없습니다(선택 필드 몇 개만 추가).
- 자세한 규칙: `docs/specs/remote-protocol-v2.md`.

## 개발자용 노트
- **데이터 폴더는 한 앱만 씁니다.** `main/dataLock.ts`가 데이터 폴더에 `office.lock`을 겁니다. 설치본이 켜져 있는데 개발 앱(`pnpm start`)을 띄우면 개발 앱이 "이미 켜져 있어요"를 보이고 꺼집니다.
- **설치본을 켠 채 개발 앱·QA를 따로 띄우려면** 다른 데이터 폴더를 주세요.
  ```bash
  CLAUDE_OFFICE_USER_DATA=/path/to/other-folder pnpm start
  ```
  이 값이 있으면 그 폴더가 데이터 폴더(`office.db` 등)가 됩니다. 설치본 데이터는 건드리지 않습니다. 앞으로 개발 앱·QA는 이 방식을 쓰세요(같은 폴더를 쓰면 설치본의 설정 "원격 켬"까지 이어받아 개발 앱이 포트를 열 수 있습니다).
- 모바일 빌드: `cd app && npm run build:mobile` → `app/dist-mobile/`. 안드로이드 빌드가 `assets/web/`로 복사합니다. 빌드·서명 방법은 `android/README.md`.
- 설계·화면·브리지 문서: `docs/specs/remote-protocol-v2.md`, `android-bridge.md`, `android-pc-layout.md`, `android-qa.md`.

**확인한 것**
- 보안 리뷰: 한리뷰가 PC 서버 v2와 폰 화면 쪽 모두 승인했습니다.
- QA: 오큐에이 판정은 "경미한 수정 필요"였고, 나온 버그 2건(재연결 배너, 폰 가로 화면)은 고쳤습니다. 고친 뒤의 확인은 개발 쪽 테스트(PC 166개, 앱 59개 통과)까지이며 오큐에이가 다시 확인하지는 않았습니다.

- 맥·윈도우 설치본은 빌드와 파일 검증까지만 했고, PC에서 켜 보지는 않았습니다.
