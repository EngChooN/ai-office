# AI Office 0.16.2 (2026-10-30)

## 한국어

### 개선
- 안드로이드 폰 화면을 다듬었어요. 헤더의 아이콘 버튼과 보내기 버튼이 동그랗게 보이고, 세로 폰의 데모데이는 대사창이 무대 아래에, 반응 버튼이 화면 아래에 놓여요.
- 질문에 답하기·결재 버튼이 좁은 칸에서 줄바꿈돼요. 가로로 돌린 폰이나 작은 PC 창에서도 가로 스크롤이 생기지 않아요.
- 폰의 직원 패널에서는 결재 칸 높이 손잡이를 없애고 내용만큼만 보여 줘요.
- 단체방의 입력칸과 말풍선에서 @이름이 강조돼 보여요.

### 버그 수정
- 단체방에서 직원이 일하는 중에 @이름으로 보낸 지시의 답이 사라지던 문제를 고쳤어요. 이제 앞 일이 끝난 뒤에도 그 지시의 답이 지시를 보낸 방(팀·랩 방 포함)에 올라와요.

- 알려 드려요: 윈도우 zip 파일은 계속 올리지 않아요. 옛 zip 앱을 쓰던 분은 Release 페이지에서 Setup.exe를 직접 받아 설치한 뒤 옛 폴더를 지우면 돼요. 설정과 기록은 그대로 이어져요.
- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English

### Improvements
- Polished the Android phone screens. Header icon buttons and the send button are now round, and in portrait the Demo Day dialogue box sits below the stage with the reaction buttons at the bottom of the screen.
- Answer and approval buttons now wrap in narrow spaces, so no horizontal scrollbar appears on a phone turned sideways or in a small PC window.
- The phone's staff panel no longer has a height handle for the approvals section and shows only as much as the content needs.
- @names are now highlighted in the group chat input box and speech bubbles.

### Bug fixes
- Fixed replies being lost when you sent an @name instruction in the group chat while that staff member was working. The reply now arrives in the room the instruction was sent from (including team and lab rooms), even after the earlier task finishes.

- Please note: the Windows zip file is still not published. If you used the old zip app, download Setup.exe from the Release page, install it, and then delete the old folder. Your settings and history carry over.
- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語

### 改善
- Android スマホの画面を整えました。ヘッダーのアイコンボタンと送信ボタンが丸く表示され、縦向きのスマホではデモデーのセリフ枠がステージの下に、リアクションボタンが画面の下に配置されます。
- 質問への返答・承認ボタンが狭い場所で折り返されます。横向きのスマホや小さな PC ウィンドウでも横スクロールが出ません。
- スマホの社員パネルでは、承認欄の高さハンドルをなくし、内容に合わせた高さで表示します。
- グループチャットの入力欄と吹き出しで、@名前が強調表示されます。

### バグ修正
- グループチャットで、社員が作業中に @名前 で送った指示への返事が消えてしまう問題を直しました。前の作業が終わった後でも、その指示への返事が送った部屋（チーム・ラボのルームを含む）に届きます。

- お知らせ：Windows の zip ファイルは引き続き公開しません。古い zip 版アプリを使っていた方は、Release ページから Setup.exe を直接ダウンロードしてインストールし、古いフォルダーを削除してください。設定と履歴はそのまま引き継がれます。
- お知らせ：Windows のインストーラーには署名がないため、初めて開くときに警告画面（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。

## 中文

### 改进
- 优化了安卓手机画面。顶部图标按钮和发送按钮变为圆形；竖屏时，演示日的对话框位于舞台下方，反应按钮位于屏幕下方。
- 回答问题和审批按钮在窄空间里会自动换行。手机横屏或电脑窗口较小时，也不会出现横向滚动条。
- 手机上的员工面板去掉了审批栏的高度拖柄，按内容大小显示。
- 群聊的输入框和气泡里，@名字会高亮显示。

### 问题修复
- 修复了在员工工作时于群聊中用 @名字 发出的指示，回复会丢失的问题。现在即使前一项工作结束后，该指示的回复也会回到发出指示的房间（包括团队房间和实验室房间）。

- 请注意：仍然不发布 Windows zip 文件。使用旧 zip 版应用的用户，请到 Release 页面直接下载 Setup.exe 安装，然后删除旧文件夹。设置和记录会保留。
- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
