# AI Office 1.0.2 (2026-11-05)

## 한국어

### 새 기능
- 직원 채팅에서 쓸 수 있는 / 명령이 늘었어요. 깊이 조사하기·디버그·코드 검토·단순화·일괄 작업·예약 같은 작업 명령 19개와 스킬·플러그인 다시 읽기 같은 설정 명령 5개가 열렸고, `/model sonnet`처럼 모델 이름(default·opus·sonnet·haiku)을 적으면 그 직원의 모델이 바로 바뀌어요(다음 지시부터 적용). 앱에 없는 설정(생각 깊이·빠른 모드·조언자)은 안내만 보여 줘요. GPT(Codex) 직원도 `/compact`(대화 줄이기)·`/review`(코드 검토)·`/goal <조건>`(목표 정하기, `/goal pause`·`/goal resume`으로 멈춤·재개, `/goal clear`로 해제)을 쓸 수 있어요. 목표를 끝내지 못하고 20번 이어 하면 스스로 멈추고 알려 줘요.
- 일하는 중에 인터넷이 끊겨 직원 일이 멈추면, 받은 일과 업무 카드를 그대로 들고 '연결 대기' 상태로 기다렸다가 인터넷이 돌아오면 하던 일을 저절로 이어서 해요(같은 일은 3번까지, 6시간 안). 그동안 대표님이 직접 새로 지시하거나 멈추면 기다리기를 그만두고 지금처럼 정리해요.

- 알려 드려요: 윈도우 설치 파일에 서명이 없어서 처음 열 때 경고 창(SmartScreen)이 떠요. '추가 정보 › 실행'을 누르면 돼요.

## English

### New features
- More / commands are available in staff chat. 19 task commands (deep research, debug, code review, simplify, batch work, schedule and more) and 5 setting commands such as reloading skills and plugins are now open, and typing a model name like `/model sonnet` (default, opus, sonnet, haiku) switches that employee's model right away (applies from the next instruction). Settings the app doesn't have (thinking depth, fast mode, advisor) only show a notice. GPT (Codex) employees can now use `/compact` (shorten the conversation), `/review` (code review) and `/goal <condition>` (set a goal; `/goal pause`·`/goal resume` pause or continue it, `/goal clear` removes it). If a goal keeps going 20 times without finishing, it pauses itself and lets you know.
- If the internet drops while an employee is working, the employee keeps the task and its card, shows 'Reconnecting', and automatically continues once the internet is back (up to 3 times per task, within 6 hours). If you send a new instruction or stop them in the meantime, they stop waiting and wrap up as before.

- Please note: the Windows installer is not signed, so a warning window (SmartScreen) appears the first time you open it. Click "More info › Run anyway."

## 日本語

### 新機能
- 社員チャットで使える / コマンドが増えました。深い調査・デバッグ・コードレビュー・簡略化・一括作業・予約などの作業コマンド19個と、スキルやプラグインの再読み込みなどの設定コマンド5個が使えるようになり、`/model sonnet` のようにモデル名 (default・opus・sonnet・haiku) を書くと、その社員のモデルがすぐ切り替わります (次の指示から適用)。アプリにない設定 (考える深さ・高速モード・アドバイザー) は案内だけ表示します。GPT (Codex) 社員も `/compact` (会話の要約)・`/review` (コードレビュー)・`/goal <条件>` (目標の設定、`/goal pause`・`/goal resume` で一時停止・再開、`/goal clear` で解除) を使えます。目標が終わらないまま20回続くと、自動で一時停止してお知らせします。

- お知らせ: Windows のインストーラーには署名がないため、初めて開くときに警告ウィンドウ（SmartScreen）が表示されます。「詳細情報 › 実行」を押してください。

## 中文

### 新功能
- 员工聊天中可用的 / 命令变多了。深入调研、调试、代码审查、简化、批量处理、预约等 19 个任务命令，以及重新读取技能和插件等 5 个设置命令现已开放；输入 `/model sonnet` 这样的模型名 (default、opus、sonnet、haiku) 即可立即切换该员工的模型 (从下一条指示起生效)。应用中没有的设置 (思考深度、快速模式、顾问) 只显示提示。GPT (Codex) 员工也可以使用 `/compact` (压缩对话)、`/review` (代码审查) 和 `/goal <条件>` (设定目标，`/goal pause`·`/goal resume` 暂停或继续，`/goal clear` 取消)。目标连续推进 20 次仍未完成时会自动暂停并提示。
- 员工工作时如果网络断开导致工作中断，会保留收到的工作和任务卡片并显示“等待连接”，网络恢复后自动继续之前的工作 (同一工作最多 3 次，6 小时内)。期间如果代表直接下达新指示或让其停止，就不再等待，并像以前一样处理。

- 请注意：Windows 安装程序没有签名，首次打开时会弹出警告窗口（SmartScreen）。点击“更多信息 › 仍要运行”即可。
