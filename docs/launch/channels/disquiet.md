검색으로 확인한 내용 (공식 가이드 원문 아님, 오래된 글 기준이라 화면과 다를 수 있음):

- 태그는 주제별 분류(예: 이커머스, 마케팅 툴, 디자인 툴)로 검색됩니다. 실제 태그 목록은 등록 화면에서 골라야 합니다.
- 최근 공지 기준으로 **본인이 만든 제품만** 등록할 수 있습니다. AI Office는 대표님 제품으로 등록합니다.
- 제품 링크만 넣은 글은 메인 피드에 덜 나온다고 합니다. **제품을 먼저 등록하고, 그 제품에 메이커로그를 연결**하는 순서를 권합니다.

### 설명 초안 (한국어, 짧게 씁니다)

AI Office는 Claude Code와 ChatGPT(Codex)를 '직원'으로 고용해, 사무실 화면에서 말로 일을 맡기는 무료 데스크톱 앱입니다.

- 파일 수정과 명령 실행은 **결재함에서 승인해야만** 실행됩니다. 바꾼 내용은 한 번에 되돌릴 수 있습니다.
- 큰 일은 팀장에게 맡기면, 팀장이 계획을 세우고 일을 나눠 확인을 받은 뒤 보고합니다.
- 직원이 일할수록 회사 레벨이 올라 사무실이 커집니다. (정확히는 최대 20단계)
- 맥(Apple Silicon)과 윈도우에서 쓸 수 있고, 안드로이드 폰으로 결재할 수도 있습니다(기본은 꺼짐).
- API 키는 필요 없습니다. 이 컴퓨터에 Claude Code 또는 ChatGPT 로그인이 되어 있으면 됩니다. 사용량은 그 계정에 청구됩니다.
- 데이터는 내 PC에 저장되고, 앱은 사용 기록을 모으지 않습니다. 외부 통신은 업데이트 확인과 내려받기뿐입니다.

**알려 드릴 한계**
- 코드 서명과 공증이 아직 없어서, 맥에서 처음 열 때 "확인되지 않은 개발자" 경고가 뜹니다. **시스템 설정 › 개인정보 보호 및 보안 › "그래도 열기"**로 열 수 있습니다.
- 윈도우에서는 외부 직원 알림·질문 처리와 화면 캡처가 아직 안 됩니다.
- 여러 직원을 동시에 돌리면 구독 사용 한도를 빨리 씁니다.

## 2. 메이커로그 글 (한국어)

**제목**: 터미널 창 여러 개를 오가다가 '사무실'을 만들었습니다

**본문**

Claude Code를 여러 개 띄워 일을 시키다 보니, 어느 창이 일하고 있는지, 어느 창이 제 허락을 기다리는지 자꾸 놓쳤습니다. 무엇을 바꿨는지 찾으려고 창을 하나씩 뒤지는 일도 많았습니다.

그래서 AI를 사무실의 직원처럼 자리에 앉혀 두고, 말로 일을 맡긴 뒤 결재만 하는 화면을 만들었습니다. 이름은 AI Office입니다.

이번 1.1.4 기준으로 바뀐 것 중 쓸 만한 것을 골라 적습니다.
- 업무 패널에서 날짜가 바뀌어도 이전 대화가 사라지지 않습니다. 위로 올리면 이전 기록을 더 불러옵니다.
- 앱을 다시 켠 뒤 결재함에 되살아난 결재를 승인하면, 그 일을 다시 할 때만 같은 결재를 한 번 건너뜁니다. 그 일이 끝나면 건너뛰기도 사라집니다.
- 직원이 일하는 중에 보낸 말은 '대기 메시지'로 쌓였다가 순서대로 전해집니다. 급하면 '지금 보내기'로 끼어들 수 있습니다.

아직 안 되는 것도 적어 둡니다. 코드 서명이 없어 맥에서 경고가 뜨고, 맥은 Apple Silicon만, 윈도우는 외부 직원 알림과 화면 캡처가 빠져 있습니다. 이 부분은 고칠 계획이 있을 때 다시 적겠습니다.

무료이고 MIT 라이선스입니다. 써 보시고 설치나 결재 흐름에서 막힌 곳이 있으면 댓글로 알려 주세요. 확인하는 대로 답하겠습니다.
