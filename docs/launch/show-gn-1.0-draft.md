AI Office - Claude·GPT를 '직원'으로 고용해 사무실처럼 일 시키는 무료 데스크톱 앱

## 본문

안녕하세요. AI Office 1.0을 공개합니다. 실제 화면은 [움직이는 화면(GIF)](https://raw.githubusercontent.com/EngChooN/ai-office/main/docs/launch/gif/office-1.0.gif)과 [소개 페이지](https://engchoon.github.io/ai-office/)에서 보실 수 있습니다.

AI Office는 Claude Code나 Codex(GPT) 세션을 **직원**으로 고용해서, 사무실 화면에서 일을 맡기는 무료 오픈소스 데스크톱 앱입니다. 코드를 직접 다루지 않아도 되도록 만들었습니다. 일은 말로 맡기고, 파일 수정이나 명령 실행처럼 중요한 작업은 **결재함에서 승인해야만** 실행됩니다. 끝나면 보고서로 결과를 받습니다.

만든 이유는 단순합니다. Claude Code를 여러 개 띄워 일을 시키다 보니, 터미널 창 사이를 오가며 누가 무엇을 하고 있는지, 무엇을 허락해 달라고 기다리는지 챙기는 일이 더 힘들었습니다. 그래서 AI를 직원처럼 자리에 앉혀 두고, 저는 말로 일을 맡기고 결재만 하는 '사무실'을 만들었습니다. 개발자가 아닌 동료도 같은 방식으로 쓸 수 있게 하는 것이 목표입니다.

### 무엇을 할 수 있나요
- **Claude와 GPT 직원을 함께 고용**: 직원마다 Claude 또는 GPT를 골라 씁니다. 하나만 있어도 시작할 수 있습니다.
- **단체 대화와 @멘션**: 역할을 정하고 대화방에서 직원을 부르면, 담당이 정해지지 않은 일은 맞는 직원이 가져갑니다.
- **결재함**: 파일 변경과 명령은 먼저 결재함에 올라옵니다. 승인 대기 중인 결재는 앱을 껐다 켜도 이어서 처리됩니다. 직원이 바꾼 내용은 버튼 한 번으로 되돌릴 수 있습니다.
- **일하는 중에도 지시 쌓아 두기**: 직원이 일하는 동안 보낸 말은 '대기 메시지'로 쌓였다가 하던 일이 끝나면 순서대로 전해집니다. 급하면 '지금 보내기'로 바로 끼어들 수 있습니다.
- **팀장에게 큰 일 맡기기**: 큰 업무를 팀장에게 주면 계획을 세우고, 나누고, 확인을 받은 뒤 보고합니다. 업무 보드에서 진행 상황을 볼 수 있습니다.
- **사무실 맵**: 누가 일하고 있고 누가 기다리는지 한눈에 보입니다. 팀 구역, 회의실, 휴게실이 있고 사무실을 꾸밀 수 있습니다.
- **그 밖에**: 회의, 예약 업무, 보고서, 직원 급여명세 화면이 있습니다.
- **안드로이드 앱**: PC 앱과 연결하면 폰에서 결재, 지시, 대화를 할 수 있습니다. 기본은 꺼져 있습니다(아래 제한 사항 참고).

### 설치
- **macOS (Apple Silicon)**: `.dmg`를 받아 열고 앱을 Applications 폴더로 옮깁니다. 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면 **시스템 설정 › 개인정보 보호 및 보안 › "그래도 열기"**를 누릅니다.
- **Windows**: `AI-Office-win-x64-Setup.exe`를 실행합니다. 관리자 권한 없이 사용자 폴더에 설치됩니다. SmartScreen 경고가 뜨면 **"추가 정보 › 실행"**을 누릅니다.
- **Android**: `.apk`를 받아 설치합니다. PC 앱이 켜져 있어야 연결됩니다.

**필요한 것**: 이 컴퓨터에 **Claude Code 또는 ChatGPT(Codex)** 로그인이 되어 있어야 합니다. API 키는 따로 필요 없습니다. 직원이 쓰는 사용량은 로그인한 계정에 그대로 청구됩니다.

### 알려진 제한 사항
- 코드 서명과 공증이 없어서 설치할 때 OS 보안 경고가 뜹니다.
- 맥은 Apple Silicon만 지원합니다.
- Windows에서는 외부 직원 알림과 질문 처리(훅), 화면 캡처가 아직 맥에서만 됩니다. 결과 검토(커밋·PR 확인)는 Git for Windows와 GitHub CLI가 필요하며, 실제로 충분히 검증하지 못했습니다.
- 폰 원격 연결은 **기본으로 꺼져 있습니다**. 켜면 PC의 포트(기본 47900)가 인터넷 쪽으로 열리므로 쓰지 않을 때는 끄는 것을 권합니다. 폰 알림은 약 15분 간격으로 확인해서 수십 분 늦을 수 있습니다.
- 직원 작업은 계정의 사용 한도에 영향을 받습니다.
