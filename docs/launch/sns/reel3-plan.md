## 장면 구성
| 시간 | 화면 | 자막 |
|---|---|---|
| 0~6.5초 | 휴게 공간에서 수다 말풍선("점심 뭐 먹지?"·"간식 챙겼어요"), 화면이 옆으로 천천히 흐름 | 우리 직원들 쉬는 시간 ☕ → 자기들끼리 수다 중 ㅎㅎ (점심 뭐 먹지? 💬 간식 챙겼어요 🍪) |
| 6.5~14초 | 일을 맡기자 직원들이 자기 자리로 걸어가 앉음(💡·✅ 감정 표시) | 일 좀 맡겨 볼까? 📮 → 자기 자리 찾아가서 총총 🏃 → 바로 일 시작 💻✨ |
| 14~18.5초 | 비서 캐릭터(앱 속 바탕화면 비서 그림), 표정이 바뀜 | 비서도 있어요 💁‍♀️ / 말풍선: 대표님~ 결재 2건 있어요! → 음… 확인해 볼게요 🤔 → 다 끝났어요! ✨ |
| 18.5~21.5초 | 끝 화면 | AI Office · 내 컴퓨터 속 작은 AI 회사 🏢 · 무료 · 프로필 링크 ⬇️ · Claude 또는 ChatGPT 계정이 필요해요 |

- 사무실 장면은 실제 앱 화면을 녹화했습니다(꾸민 그림 아님). 진짜 데이터는 건드리지 않도록 복사본 사무실로 따로 띄웠고, 터미널 세션 캐릭터는 빼고 팀을 1층에 모아 북적이게 했습니다.
- 비서 장면만 앱의 비서 캐릭터 그림(표정 3종)에 움직임과 말풍선을 붙여 만들었습니다.
- 2026-11-04 재녹화: 첫 판은 창이 가려진 채 화면을 연속 캡처해 초당 15장·최대 0.65초 멈춤이 섞였습니다. 앱은 창이 완전히 가려지면 사무실 그림을 멈추는 절전 기능이 있어서, 녹화할 때만 이 절전을 끄고 사무실 그림판(캔버스)을 앱 안에서 직접 30fps로 녹화해 다시 만들었습니다(프레임 간격 최대 0.07초). 비서·끝 화면도 30fps로 다시 만들었습니다.
