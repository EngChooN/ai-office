# @ai_office_hq 첫 게시물 기획안 (인스타 + 쓰레드)

> 게시는 대표님이 직접 합니다. 이 문서는 기획·촬영 목록·문구만 담습니다.
> 사실 기준: 회사 레벨 20단계(`app/src/shared/officeLevel.ts`), 무료, 맥·윈도우·안드로이드, Claude 또는 ChatGPT 계정 필요.

## ① 형식 추천: 릴스 (약 10초, 세로 9:16)
- **이유**: 인스타 탐색 피드는 릴스를 가장 많이 띄웁니다. 첫 게시물이 계정을 알리는 역할이라 도달이 중요합니다.
- 캐러셀은 두 번째 게시물로 씁니다. "단계별 쓰는 법"을 6장으로 정리하면 저장이 잘 됩니다.

## ② 장면 구성 (10초, 자막은 화면 가운데 큰 글씨 3~6단어)

| 시간 | 화면 | 큰 글자 문구 (훅 포함) |
|---|---|---|
| 0~1.5초 | 빈 사무실 전경, 천천히 줌인 | **"AI 직원, 내 사무실에서 뽑았어요"** |
| 1.5~3초 | 직원 고용 화면, 역할 선택 | **"Claude·ChatGPT 직원 고용"** |
| 3~5초 | 대화창에 "블로그 글 3개 정리해 줘" 입력 후 전송 | **"말로 일을 맡기면 끝"** |
| 5~7.5초 | 결재함에 승인 카드가 뜨고 [승인] 누르기 | **"위험한 일은 내가 승인해야 실행"** |
| 7.5~9초 | 레벨업 알림, 층이 하나 늘어나는 장면 | **"일할수록 사무실이 커져요"** |
| 9~10초 | 로고와 프로필 아이콘 + 무료 표시 | **"무료 · 맥·윈도우·안드로이드 / 프로필 링크"** |

- **첫 1.5초 훅 점검**: 자막이 첫 프레임부터 보여야 합니다. 빈 사무실 장면은 움직임을 줘서 멈추지 않게 합니다.
- 장면 전환은 빠르게(0.5초 안팎), 배경음은 가볍게. 음성 설명은 넣지 않아도 자막만으로 이해되게 만듭니다.

## ③ 촬영·캡처 목록
1. **빈 사무실 전경** (줌인용, 가구가 적은 상태 권장)
2. **직원 고용 화면** (Claude와 GPT 선택지가 같이 보이는 장면)
3. **대화창에 지시를 입력하는 장면** (실제 업무 문구, 짧게)
4. **결재함 승인 카드** (승인 버튼이 보이는 장면)
5. **레벨업 알림 또는 층이 추가된 사무실** (레벨이 올라간 화면이 있으면 사용)
6. **상점에서 가구를 고르는 장면** (꾸미기 강조용, 선택 사항)
7. **앱 아이콘과 소개 페이지 주소** (엔딩 프레임용)

**촬영 주의**
- 화면 속 이름, 폴더 경로, 이메일, 프로젝트 이름이 보이지 않게 가리거나 미리 정리합니다.
- 기존 `office-1.0.gif`는 가로 비율일 수 있습니다. 세로 9:16이 아니면 같은 장면을 세로로 다시 찍습니다.
- 프로필 아이콘은 `docs/launch/sns/ai_office_hq-profile.png`를 씁니다.
