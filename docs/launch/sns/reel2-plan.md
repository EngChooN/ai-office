# @ai_office_hq 두 번째 릴스 기획안 (시끄러운 하이텐션 버전)

> 기획만 합니다. 이미지 제작과 게시는 하지 않습니다. 게시는 대표님이 직접 합니다.
> 트렌드 메모(훅·빠른 컷·POV 자막·음원 주기)는 요청자가 찾은 내용을 그대로 씁니다. 이번에 따로 검증하지 않았습니다.

## 1) 피드백 해석

| 지인 의견 | 원하는 것 |
|---|---|
| "어그로 끄는 시끄러운 것도 올리자" | 첫 번째 릴스(차분한 7장)와 톤이 다른 **짧고 세고 웃기는** 버전을 추가 |
| "저 대표됐어요!!!!" 템포 빠르게 | **1인칭 대표 캐릭터**를 세우고 첫 2초에 감정을 터뜨리기 |
| "얘네들이 제 직원이에요~~ ㅋㅋ" | 직원을 캐릭터처럼 보여 주기(이름과 얼굴 카드) |
| "비개발자를 위해 ○○도 만들고 ○○도 만들고" | **비개발자도 이런 걸 만들 수 있다**는 가능성을 나열 |

공통으로 빠진 것: 타깃이 "개발을 모르는 사람"이라는 점을 첫 장면에서 말해야 합니다.

## 2) 컨셉 2안

### 안 A. "저 오늘부터 대표됐어요" (하이텐션, 12초) ← 추천
**메시지**: 내가 대표가 되어 직원을 뽑는다는 설정을 웃기게 보여 준다.

| 초 | 화면 | 큰 자막 | 효과음·텐션 |
|---|---|---|---|
| 0~1.5 | 사무실 줌인, 빠른 컷 | **"저 오늘부터 대표됐어요!!!!"** | 쿵 효과음, 빠른 비트 시작 |
| 1.5~3 | 직원 뽑기 버튼을 빠르게 두 번 누름 | **"직원 뽑는 중 ㅋㅋ"** | 딸깍 효과음 |
| 3~5 | 직원 3명이 나란히 서 있는 장면 | **"얘네들이 제 직원이에요~~"** | 웃음 효과음(짧게) |
| 5~8 | 대화창에 "랜딩 페이지 하나 만들어 줘" 입력, 직원이 움직이는 장면 2~3컷 | **"말 한마디면 일 시작"** | 타이핑 소리 |
| 8~10 | 결재 카드 뜸, [승인] 누름 | **"사장님 허락 없인 안 움직여요ㅋ"** | 띵 효과음 |
| 10~12 | 완료 보고, 레벨업 알림, 엔딩 로고 | **"무료 · 프로필 링크 ⬇️"** | 마지막 강한 한 방 |

- **훅 문구 후보 3개**
  1. "저 오늘부터 대표됐어요!!!!"
  2. "얘네 다 제 직원이에요 ㅋㅋ"
  3. "개발 몰라도 직원 뽑고 일 시킬 수 있음"
- **캡션**
  ```
  저 오늘부터 대표됐어요 ㅋㅋ 🏢
  직원 뽑고, 말로 일 시키고, 승인만 누르는 중이에요.
  개발 몰라도 됩니다. 무료예요.
  ※ Claude 또는 ChatGPT 계정이 필요해요.
  프로필 링크에서 받을 수 있어요 ⬇️
  ```
- **해시태그 (5개)**: #AI직원 #AI사무실 #클로드코드 #무료앱 #AIOffice
- **음원 분위기**: 빠르고 밝은 팝, 약 120~130BPM. 짧은 드럼 브레이크를 넣어 자막이 바뀌는 순간에 맞춥니다. 음원은 게시 직전 인스타 라이브러리에서 최근 7~10일 안에 뜨는 것을 고릅니다.

### 안 B. "비개발자인데 이것도 만들었어요" (나열형, 14초)
**메시지**: 비개발자도 쓸 수 있는 결과물의 종류를 보여 준다. 저장하고 싶은 콘텐츠가 됩니다.

| 초 | 화면 | 큰 자막 | 효과음·텐션 |
|---|---|---|---|
| 0~2 | 사무실 전경 | **"비개발자도 이것 다 만들 수 있어요"** | 빠른 비트 |
| 2~4.5 | 랜딩 페이지 결과 화면 | **"랜딩 페이지"** | 슉 효과음 |
| 4.5~7 | 발표 자료(슬라이드) 결과 | **"발표 자료"** | 슉 효과음 |
| 7~9.5 | 엑셀/CSV 정리 결과 | **"엑셀 정리"** | 슉 효과음 |
| 9.5~12 | 간단한 웹 게임 실행 화면 | **"간단한 웹 게임"** | 슉 효과음 |
| 12~14 | 로고, 무료 표시 | **"무료 · 프로필 링크 ⬇️"** | 마지막 한 방 |

- **훅 문구 후보 3개**
  1. "비개발자인데 게임도 만들었어요" → **체험담처럼 쓰지 않습니다.** 아래처럼 가능형으로 씁니다.
  2. "개발 몰라도 이것까지 가능합니다"
  3. "AI 직원한테 시키면 되는 것들"
- **캡션**
  ```
  개발을 몰라도 AI 직원한테 시키면 되는 것들 📋
  · 소개 페이지(랜딩 페이지)
  · 발표 자료
  · 엑셀 정리
  · 간단한 웹 게임
  직원이 만든 결과는 내가 승인한 뒤에만 실행돼요.
  ※ Claude 또는 ChatGPT 계정이 필요해요. 사용량은 그 계정에 청구돼요.
  프로필 링크에서 받을 수 있어요 ⬇️
  ```
- **해시태그 (5개)**: #비개발자 #AI도구 #ChatGPT #무료앱 #AIOffice
- **음원 분위기**: 리듬이 일정한 가벼운 비트, 약 100~110BPM. 항목이 바뀔 때마다 같은 효과음이 나와 리듬을 만듭니다.

**'다 만들 수 있어요' 예시에 대한 주의**
- 위 4개는 AI 직원이 파일로 만들 수 있는 결과물입니다. 그러나 **실제로 앱에서 만들어 본 결과**를 찍어야 합니다. 찍기 전에는 게시하지 않습니다.
- 간단한 웹 게임은 결과가 단순해야 합니다. 실제로 돌아가는지 먼저 확인합니다.
- "누구나 몇 분 만에" 같은 시간 약속은 쓰지 않습니다.
