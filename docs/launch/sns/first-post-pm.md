# 인스타 첫 게시물 — PM 의견 (김기획)

기준: CONTEXT·SPEC·README 1.0.1. 한마케 기획안과 독립. 실제 설치·실행은 안 함(문서 대조만).

## ① 꼭 보여 줄 장면 (1~3개, 모두 실제 기능)
1. **내 사무실에 AI 직원이 앉아 일하는 화면** — 직원이 책상에서 움직이고 말풍선이 뜨는 사무실 맵. "터미널 없이 사람 뽑듯 쓴다"가 한눈에 보이는 유일한 장면. (SPEC 맵·직원 행동)
2. **직원을 고용하고 일을 시키는 3~5초** — 고용 → `@이름`으로 지시 → 결재함에 승인 카드 도착. "나는 대표, 결재만 한다"를 보여 줌.
3. **레벨업으로 사무실이 넓어지고 상점에서 꾸미는 장면** — 회사 레벨·층 확장·상점(101종)은 SPEC 19·20·22에 있음. 재미 포인트.
- 첫 게시물은 1번을 표지로, 2→3번 순서 릴스/캐러셀 권장. 화면은 업무 모드 말고 맵이 보이는 모드로.
- 쓰지 말 것: 회의실·급여·매뉴얼 등 기능 나열(첫 게시물엔 과함).

## ② 설치 후 막힐 지점 → 캡션/고정 댓글에 미리 적기
| 막힘 | 안내 문구 |
|---|---|
| 계정 | Claude 또는 ChatGPT 계정이 **이미 로그인**돼 있어야 함. 앱 자체는 무료지만 AI 사용량은 **본인 구독·계정 한도**에서 차감 |
| 맥 보안 경고 | 서명·공증 안 된 앱 → "개발자 확인 불가" 경고 → 설정›개인정보 보호 및 보안›"그래도 열기" |
| 윈도우 경고 | SmartScreen "PC 보호" → "추가 정보›실행". **윈도우는 아직 실사용 검증이 얕다**고 솔직히 한 줄 |
| 기기 | 맥은 **Apple Silicon만**(인텔 맥 불가). 안드로이드는 apk 직접 설치 + PC 앱 연결용(단독 사용 아님) |
| 휴대폰 연결 | 기본 꺼짐. Tailscale 설치 등 단계가 있어 일반인에겐 어려움 → 첫 게시물에선 "추가 설정 필요"만 |
- **확인 필요(개발/대표):** 맥 dmg·윈도우 설치·apk 실기기 확인이 안 끝남. 게시 전 한 번씩 설치 검증 필수. 데이터 저장 위치·텔레메트리, 구독 로그인의 약관 적합성도 미확인.

## ③ 이후 게시물 순서
1. **2번째: "5분 따라하기"** — 설치→로그인→첫 직원 고용→첫 지시. 막힘 안내(②)를 그림으로. 신뢰·전환용.
2. **3번째: "사무실이 자란다"** — 레벨업·상점 꾸미기 전후 비교. 공유·저장 유도(재미).
3. **4번째: "결재함/휴대폰으로 퇴근길 승인"** — 신뢰·안전(직원이 위험한 작업은 내 승인 후 실행). 휴대폰 연결은 설정 부담을 솔직히 안내.

## ④ 피해야 할 표현
- "설치만 하면 알아서 다 해줍니다/완전 자동" — 결재·지시가 필요, 과장.
- "완전 무료" — 앱은 무료·오픈소스이나 AI 사용료는 본인 계정에서 나감. "앱은 무료, 계정 필요"로.
- "안전·보안 인증" — 미서명·미공증. 경고가 뜬다고 먼저 말할 것.
- "개발 지식 전혀 불필요 / 누구나 1분" — 경고 해제·계정 로그인 단계가 있음.
- "윈도우·안드로이드 완벽 지원" — 윈도우 미검증, 안드로이드는 보조 앱.
- 클로드코드·코덱스 "대체/공식" 암시, 로고 오남용 — 비공식 앱임을 프로필에 명시.
- "AI가 사람 직원을 대체" 류 일자리 자극 표현, 없는 기능(자동 수익·완전 무인 운영) 약속.
