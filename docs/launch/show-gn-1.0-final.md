## 내용

AI Office는 Claude Code와 Codex(GPT)를 개발자가 아니어도 쓸 수 있게 만든 오픈소스(MIT) 데스크톱 앱입니다(macOS Apple Silicon·Windows). 터미널과 개발 용어 대신 누구나 아는 '사무실'을 빌려 왔습니다. AI를 **직원**으로 고용해 말로 일을 맡기고, 파일 수정이나 명령 실행처럼 중요한 일은 **결재함에서 승인해야만** 실행됩니다. 끝나면 보고서로 결과를 받습니다. 직원이 일할수록 회사 레벨이 올라 사무실이 커지고, 번 자금으로 상점에서 가구·소품을 사 꾸밀 수 있습니다. 집 맥과 회사 PC처럼 내 다른 컴퓨터의 직원도 한 팀으로 불러와 같이 일하게 할 수 있습니다.

실제 화면: [움직이는 데모(GIF)](https://raw.githubusercontent.com/EngChooN/ai-office/main/docs/launch/gif/office-1.0.gif) · [소개 페이지](https://engchoon.github.io/ai-office/)

**만든 이유**: Claude Code와 Codex로 할 수 있는 일은 많은데, 검은 터미널 창과 "커밋", "권한 허용" 같은 말 때문에 개발을 모르는 사람은 시작조차 어렵습니다. 그래서 AI를 다루는 방법을 회사에서 사람에게 일을 맡기는 방식으로 바꿨습니다. 직원을 뽑고, 말로 일을 시키고, 중요한 일은 결재로 허락하고, 끝나면 보고를 받는 식입니다. 화면에 나오는 말도 개발 용어 대신 일상어로 풀었습니다. AI가 내 컴퓨터에서 무엇을 하는지 몰라도, 결재함만 보면 무엇을 하려는지 알고 멈출 수 있게 하는 것이 목표였습니다.

### 주요 기능
- **결재함**: 파일 변경과 명령은 먼저 결재함에 올라옵니다. 바꾼 내용은 버튼 한 번으로 되돌릴 수 있습니다. 앱을 껐다 켜도 7일 안의 결재·질문은 '이어 가기' 카드로 다시 뜨고, 승인하면 직원에게 새 지시로 전달됩니다.
- **다른 PC 직원과 함께 일하기**: 내 다른 컴퓨터의 AI Office와 12자리 코드로 짝지으면, 그쪽 직원이 이쪽 사무실에 '원격' 표시로 앉습니다. 팀장이 일을 맡기면 그 컴퓨터에서 실행되고, 진행은 실시간으로 보이며, 결재는 이쪽 화면에서 합니다. 파일 작업은 복사본에서 하고, 바뀐 부분만 돌아와 결재 카드로 뜹니다(git을 몰라도 됨). 상대 컴퓨터가 꺼져 있으면 '연결 대기'로 두었다가 켜지면 보냅니다.
- **사무실 성장·상점 꾸미기**: 직원이 일한 만큼 회사 레벨(20단계)이 오르고, 사무실 외관·층·회의실·휴게 공간이 좋아집니다. 번 자금으로 상점에서 벽지·바닥·가구·소품(100종 넘게, 등급·세트·시즌 한정)을 사 직접 배치합니다. 직원들은 가구를 쓰며 쉬고 대화합니다. 회사에 띄워 둘 때는 '업무 모드'로 게임 요소를 숨길 수 있습니다.
- **Claude와 GPT를 한 사무실에서**: 직원마다 Claude 또는 GPT를 고릅니다. 하나만 있어도 시작할 수 있습니다.
- **팀장에게 큰 일 맡기기**: 팀장이 계획을 세우고 일을 나눠 확인받은 뒤 보고합니다. 진행 상황은 업무 보드에서 봅니다.
- **일하는 중 지시 쌓아 두기**: 직원이 일하는 동안 보낸 말은 '대기 메시지'로 쌓였다가 하던 일이 끝나면 차례로 전해집니다. 급하면 '지금 보내기'로 끼어듭니다.
- **사무실 맵**: 누가 일하고 누가 기다리는지 한눈에 보입니다.
- **단체 대화·회의·예약 업무·보고서**: 대화방에서 @멘션으로 직원을 부르고, 담당이 없는 일은 맞는 직원이 가져갑니다.
- **안드로이드 앱**: PC 앱과 연결해 폰에서 결재와 지시를 합니다(기본 꺼짐).

기술: Electron + React. Claude 직원은 Agent SDK, GPT 직원은 Codex app-server로 돌립니다.

### 설치
- **macOS (Apple Silicon)**: `.dmg`를 열어 Applications 폴더로 옮깁니다. "확인되지 않은 개발자" 경고가 뜨면 **시스템 설정 › 개인정보 보호 및 보안 › "그래도 열기"**를 누릅니다.
- **Windows**: `AI-Office-win-x64-Setup.exe`를 실행합니다. 관리자 권한 없이 사용자 폴더에 설치됩니다. SmartScreen 경고가 뜨면 **"추가 정보 › 실행"**을 누릅니다.
- **Android**: `.apk`를 받아 설치합니다. PC 앱이 켜져 있어야 연결됩니다.

**필요한 것**: 이 컴퓨터에 **Claude Code 또는 ChatGPT(Codex)** 로그인이 되어 있어야 합니다. API 키는 필요 없습니다.

**데이터와 비용**: 별도 서버 없이 내 PC에서 돌고, 대화와 기록은 PC 안에 저장됩니다. 모델 호출은 로그인한 계정을 통해 각 회사로 가고, 사용량도 그 계정에 그대로 잡힙니다. 직원을 여러 명 동시에 돌리면 구독 한도를 빨리 씁니다. 앱은 사용 기록을 수집하지 않고, 앱이 직접 하는 외부 통신은 업데이트 확인과 내려받기뿐입니다.

### 알려진 한계
- 코드 서명과 공증이 없어 설치 때 OS 보안 경고가 뜹니다.
- 맥은 Apple Silicon만 지원합니다. Intel 맥과 Linux는 지원하지 않습니다.
- Windows에서는 외부 직원 알림·질문 처리(훅)와 화면 캡처가 아직 안 됩니다. 결과 검토(커밋·PR 확인)는 Git for Windows와 GitHub CLI가 필요하고, 충분히 검증하지 못했습니다.
- 다른 PC 협업은 내 컴퓨터끼리 쓰는 것을 전제로 만들었고, Tailscale로 연결합니다.
- 폰 연결은 기본으로 꺼져 있습니다. 켜면 Tailscale 주소로만 접속되는 방식이 기본이고, 같은 네트워크 전용이나 공유기 포트포워딩 방식도 고를 수 있습니다. 포트포워딩 방식은 외부에 포트가 열리니 안 쓸 때는 꺼 주세요. 폰 알림은 약 15분 간격으로 확인해서 늦을 수 있습니다.

### 피드백 받고 싶은 것
- 설치나 첫 업무에서 막힌 곳

- 여러 직원을 동시에 돌릴 때 결재가 감당되는지, 결재 흐름에서 불편한 부분
- 다른 PC 협업을 써 봤다면 짝짓기·파일 결재에서 헷갈린 부분
- 폰 연결 방식 중 어느 것을 썼고 어디서 막혔는지
