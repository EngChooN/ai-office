## 2. 뽑는 방법

**방문** — GoatCounter 대시보드 › 기간 "Last week" › Visits. **미집계(보류 결정)**. 대신 다운로드 수와 검색 클릭수를 유입 지표로 씁니다.

**설치** — `docs/analytics.md`의 gh 명령 사용. 플랫폼별 누적 합계를 매주 기록하고 이번 주−지난주로 주간 증가분을 계산합니다.
```sh
GH=~/.local/gh-cli/gh_2.103.2_macOS_arm64/bin/gh
$GH api repos/EngChooN/ai-office/releases --paginate \
  --jq '.[].assets[] | [.name,.download_count] | @tsv' \
  | awk '{n=$1; sub(/^(AI|Claude)-Office-/,"",n); s[n]+=$2} END{for(k in s) print k, s[k]}'
```
(이 누적 명령은 아직 실행 검증 전이므로 첫 사용 때 결과가 맞는지 확인)

**1주 재사용률** — 베타 기간은 설문으로 추정(`beta-launch.md` §6 권고). 정의: 설치 후 6~8일차에 업무를 1건 이상 다시 지시한 사용자 ÷ 최초 실행 사용자. 방법: 구글 폼 링크를 긱뉴스 글 댓글·앱 설문 안내에 두고 "지난주에 다시 쓰셨나요?" 응답 비율로 계산. 응답 수가 적으면 비율 대신 건수로 보고합니다. 측정 방식 최종 선택은 대표 결정 대기.

**검색 유입** — 구글 서치 콘솔 › 실적 › 검색결과 › 기간 "최근 7일" › 총 클릭수·총 노출수·평균 CTR·평균 게재순위. 네이버 서치어드바이저 › 검색 분석도 같이 확인. 두 곳 모두 대표님 계정으로 소유 확인(`docs/seo.md`)이 끝나야 보이며, 노출 데이터는 등록 후 며칠 뒤부터 쌓입니다. 쿼리 상위 10개는 키워드 조정용으로 따로 메모합니다.

**피드백** — `gh api repos/EngChooN/ai-office/issues --jq 'length'` 대신, 이번 주 생성분은 GitHub 이슈 목록에서 `created:>=YYYY-MM-DD` 검색으로 확인.
