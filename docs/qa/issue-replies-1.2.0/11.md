# #11 답글 초안 (게시하지 않음 — 대표 결재 후 게시)

안녕하세요, 의견 감사합니다. 늦게 답해 죄송해요.

1.1.3에서 아래와 같이 바뀝니다.

- 직원 브라우저는 한 번 로그인하면 다음에도 로그인이 유지돼요. (직원별 전용 프로필에 저장)
- 장비 화면에 왜 내 크롬과 나뉘어 있는지 설명을 넣었어요. 직원이 내 로그인·비밀번호를 마음대로 쓰지 못하게 하려는 보안 때문이에요.
- 새 스위치 "모든 직원이 같은 로그인 쓰기"를 켜면, 한 직원이 로그인한 사이트를 다른 직원도 이어 써요. 한 번에 한 직원만 브라우저를 쓸 수 있어요.

"내 크롬을 그대로 쓰기"는 Playwright의 확장 연결 방식으로 가능은 하지만, 내 모든 로그인에 직원이 접근하게 되는 위험이 있어 이번엔 넣지 않았어요. 필요한 범위를 정해 안전하게 넣을 방법을 더 살펴볼게요.

(패스키는 직원 전용 프로필에 따로 등록해야 해서, 지금은 일반 로그인 유지만 보장돼요.)
