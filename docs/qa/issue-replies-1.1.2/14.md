안녕하세요, 여러 가지를 꼼꼼히 알려 주셔서 감사합니다. **AI Office 1.1.2**에 반영했습니다.

- **Codex '연결 안 됨':** 1.1.0·1.1.1 맥 설치본에 Codex 구성 요소가 빠져 있었습니다. 1.1.2에서 다시 넣었고, 구성 요소가 없으면 업데이트 안내와 **다시 확인** 버튼이 나옵니다.
- **Claude 사용량 반영:** 사용량 옆에 '마지막 갱신 N분 전'을 표시해, 언제 값인지 알 수 있게 했습니다.
- **결재 요청이 너무 많음:** 새 직원의 기본 결재 방식을 '수정은 자율'로 바꾸고, 자동결재가 더 많은 명령을 스스로 판단하도록 다듬었습니다. 위험할 수 있는 명령(방금 고친 스크립트 실행 등)만 기다리고, 기다리는 이유를 한 줄로 보여 줍니다. 상단에 자동결재 상태도 표시합니다.

**업데이트 방법:** 앱의 업데이트 안내를 누르거나, [Releases](https://github.com/EngChooN/ai-office/releases/latest)에서 `AI-Office-mac-arm64.dmg`를 받아 설치해 주세요.

확인: 자동 검사와 실제 앱 시험(결재 대기·통과 여러 경우)을 거쳤습니다. 토큰 사용량은 이번에 직접 줄이지 못했습니다. 어떤 일에서 많이 쓰는지 알아야 정확히 고칠 수 있어서, 다음 내용을 알려 주시면 큰 도움이 됩니다.
- 많이 쓴 직원의 엔진(Claude·GPT)과 모델
- 주로 시킨 일(예: 긴 코드 수정, 여러 직원에게 나눠 맡기기, 예약 업무)
- 급여 명세서에서 많이 쓴 직원과 대략의 토큰 수

써 보시고 여전히 불편하면 이 이슈나 새 이슈로 알려 주세요.
